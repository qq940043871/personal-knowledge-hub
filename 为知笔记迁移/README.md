# 为知笔记迁移（历史笔记库）

本目录是从**为知笔记（WizNote）**导出的历史笔记快照，共 250 篇，作为归档保存，不再日常增补。原导出中 "My Notes"、"My Tasks"、"博客园" 等目录名已按内容主题重命名，目录结构见下表；如需追溯原名，可通过 git 历史查看。

> 📦 **2026-11-07 起本目录已从 `library/` 知识层移出，为顶层只读归档**，不再参与知识库站点（tree.json）构建；主库指向本目录的链接请以 `为知笔记迁移/` 为准。

> ⚠️ **全局说明——数字与配图缺失**：这批笔记当年从为知笔记导出为 Markdown 时，正文中的大量数字丢失（表现为词句间的空缺，如"Top 的风险""覆盖率只有 %"、命令中的参数残缺），配图也全部未随导出保留。数字无法从存档恢复，请勿把其中的命令直接复制执行；涉及配置与命令的文件顶部已单独加了警示。

新内容请勿写回本目录：技术类沉淀请进主库对应主题目录（如 `library/Linux学习指南/`、`library/Kafka学习指南/`），管理类沉淀请进 `library/技术文档体系/`。

## 二、整理记录

### 第一轮（2026-10 上旬）：目录重整

1. **目录改名**：`My Notes` → `技术专栏笔记`、`My Tasks` → `个人成长规划`、`博客园` → `面试基础整理`、`宝宝知道` → `育儿与家庭`、`炒股养家` → `投资与理财`；`微权力下的项目管理` 内部的 `My Notes` → `课程笔记`、`未分类` → `专题文章`。
2. **层级拍平**：`项目管理/工作记录/`（7 篇项目管理文章）上提一级，消除与顶层 `工作记录/` 的同名歧义。
3. **垃圾清理**：`投资与理财/投资笔记.md`、`运维常用/架构师/Docker学习笔记.md`、`个人成长规划/资产负债表.md` 三篇开头混入的为知笔记编辑器 JavaScript 脚本已删除。

### 第二轮（2026-10 中旬）：全量格式美化

对全部 250 篇做两遍处理：先脚本机械修复，再对扫描出的 41 篇重灾区逐篇深度重排。

**机械修复（全量）**：去除 240 篇的 BOM；247 篇首行提升为 `# 标题`（含 `| ` 前缀垃圾、`######` 深层级、标题粘连、重复标题去重）；收敛数字缺失留下的 3000+ 处双空格；修复 1394 处 `\_ \*` 转义残留、334 处空粗体、170 处 `](##)` 死链；删除 138 行公众号样板（微信号/功能介绍）；统一 UTF-8 无 BOM、LF、末尾单换行。

**深度重排（41 篇）**，按模式处理：

- 命令速查类 13 篇：命令包 ```bash 代码块、`//` 注释改 `#`、按场景分节、表格化，含缺失数字命令的文件加"不可直接执行"警示。
- 脑图/清单类 15 篇：脑图短行导出转嵌套列表与表格（资产负债表、投资笔记、书籍消费、百度脑图链接等）。
- 链接清单/段落墙类 13 篇：面试基础整理 7 篇按主题分组，长文拆 `##` 小节（web 安全 100 技恢复 1-100 编号、项目经理标准文档 14 种文档表格化）。

**内容丰富**：10 个课程专栏与 `微权力下的项目管理` 的 6 个子系列各生成 `00-总览.md` 讲次导航（从文件名提取讲次主题，含笔记链接）。

### 第三轮（2026-10 下旬）：SVG 插图补充

为弥补导出丢失的配图，按文章内容重绘了 **210 张内联 SVG 示意图**（覆盖 268 篇中的 210 篇，每篇恰好 1 张，直接嵌入 markdown，无需外部图片文件，三个查看器均可渲染）：

- **10 个技术专栏 + 微权力系列**：每篇一张内容示意图（架构分层图、流程图、左右对比、时间线、思维导图、循环闭环），节点文字全部取自原文概念，未发明原文没有的内容。
- **运维速查类**：补的是"排查思路流程图"（何时用哪条命令的决策路径），命令本身不进图。
- **特殊文件**：百度脑图失效链接补了主题思维导图、IT 架构师知识图谱补了领域导图、资产负债表补了 T 型结构图、API 网关/金融产品线补了架构图。
- **选择性跳过**（58 篇）：链接清单（面试基础整理）、00-总览、待办流水、消费记录、纯清单长文与营销软文等无可画结构的文件。
- 所有图均标注 `*图：XXX 示意（据原文重绘）*`，不冒充原文的"图N"；统一几何与配色规范，并经脚本校验（XML 合法、无文字溢出、单张 ≤15KB）。

### 第四轮（2026-11-07）：质量巡检修复

全量扫描（`tools/archive-quality-scan.mjs`）发现并修复两类硬伤：

- **断围栏 5 篇**（技术专栏笔记的 SkyWalking 02 讲、DevOps 10 讲、云原生 41 讲、运维 20 课、敏捷测试 30 讲）：导出时代码块的闭合 ``` 粘在内容行尾（如 `weight: ```），渲染器不识别导致其后整段正文被当代码渲染；已逐一拆行复位。
- **死图占位 37 处**（一个NB项目的上线过程、产品经理如何写好一份年终总结、0、为什么绝大多数项目经理在不断救火）：原文图片指向为知 memocast 图床（域名已失效）或旧机器绝对路径，图片本体已无法找回，已替换为 `〔原图片缺失〕` 占位标注，不再渲染裂图。

# 通俗理解质量管理

质量影响最大，先需要制定一个【质量规划】就是识别一些质量标准什么的，然后再开发过程中照着质量规划进行比对，就是【质量保证】，出了问题就进行【质量控制】，
质量规划，就先看看公司的前辈有什么经验教训【组织过程资产】，公司对质量有什么制度什么的【企业环境因素】，因为质量规划需要在项目开始的时候就需要制定，啥都没有就靠【项目章程】，有了整体的项目管理计划【整体管理计划】，也需要了解项目的范围【项目范围说明书】，质量规划不会在过程中出现在新的变更。有了这些东西后，然后对公司的质量参考 【质量基准】，对质量的成本效益分析下，是否划得来【成本效益分析】，用实验的方法，来统计下质量指标【实验设计】，有了这些手段足可以开始进行质量规划【项目质量计划】一张明细的所有质量指标的单子【质量检查单】每一个质量的完成目标：【质量指标】，有了这些的参考，项目管理计划也会完成或者更新【项目管理计划更新】。
在项目过程中需要按照质量管理计划进行质量保证，质量保证就是保证过程适用质量规划，保证就需要有依据，比如质量计划【质量管理计划】，需要照着表格对照【质量检查单】，质量有没有完成指标【质量指标】，这个时候公司的资产不管用了。总需要对完成的工作进行检查【工作绩效】还有一些过程中批准的一些需求【请求的质量标准变更】。就可以进行质量控制，控制了，如果有问题，则进行纠偏【建议的纠偏】，有发现需要变更的就【请求变更】，都没有，总是会出问题的，所以就需要更改计划【项目管理计划更新】，只要质量保证肯定有经验【组织过程资产更新】
项目过程中质量出问题了，就需要质量控制人员上场了， 通俗就是管理人员，你来控制，总是需要有些依据吧。比如看看计划有没有变化【项目质量管理计划】对比下检查表有没有问题【质量检查单】，质量标准有没有达到【质量指标】，质量控制一定是对完成的工作比如代码进行控制【工作绩效信息】，在过程中如果有批准的变更，也需要进行控制【批准的变更】不控制就跑偏了，只要控制一定是对结果进行控制【产品服务结果】有了这些基本可以进行控制了，但是需要有手段进行控制。最简单得就是照着检查【检查】，要不就是使用图标【控制图】通俗就是折线图，看看浮动大不，或者是统计抽样，都控制还是有成本的，所以抽样最得人心【抽样检查】，要不就是建个趋势线了，看看整体怎么样 【趋势图】，80%的问题是有20%的功能引起，二八原则【帕累托图】，要不就是建个流程图一步步检查，最费时，【流程图】，其他的办法随机想想【其他】有了这么多工具，在控制不住就完了，控制完成了总是有些建议【建议纠偏】【建议预防】【建议修改】，还有重新发现问题，请求变更【请求变更】，然后吧项目计划更新下【项目管理计划更新】，有经验了，就更新下【组织资产库】完事。

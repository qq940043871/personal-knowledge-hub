# 通俗理解成本管理

项目中领导最关心花钱问题，，需要多少人，多少资源，多少时间，换算成钱，就是【成本估算】，要想成本估算，总是先需要知道整个项目范围有多大【项目范围说明书】，需要知道项目具体的时间计划是啥【项目管理计划】，需要知道前辈们是怎么估算的【组织过程资产】，公司有没有什么制度【企业环境因素】，所有的工作都是怎么安排的，都有哪些具体的项目，才可以估算【WBS】【wbs字典】，有了这些材料，可以支撑估算了，但是需要用一些方法估算。比如参考下以往的项目【类比估算】，这些资源转换成钱，有没有费率【资源费率法】，是不是领导说了个总数，硬往下分摊【自上而下】，如果出了质量事故怎么办，预备一些成本吧【质量成本】，有没有一些预留【准备金】，如果公司有专门的系统，最好估算【项目管理系统】，有没客户的估算的分析数据【卖方的投票分析】，都考虑全了，就可以进行成本估算，估算完了，有个结果，大致有多少钱，【成本估算结果】，在过程中如果范围变化了，加钱了，【请求的成本变更】，范围变化了，钱变化了，计划总要变【项目管理计划更新】，有了这些，须有 有一个细节文件【成本相关支持性细节文件】
成本估算完了，总要加起来，看看总预算有多少，首先需要知道估算结果吧 【成本估算结果】，还需要知道细节文件【成本支持性细节】，项目的范围影响钱【项目范围说明书】，具体的工作由那些组成，领导也需要知道【WBS】【WBS字典】，钱都是怎么花掉的，什么时间投入多少钱，总是需要个计划【项目进度计划】有了这些就可以计算预算了，比如先建个参数模型【参数法】，比如再加一部分钱应对风险【管理储备】，怎么加减汇总起来，【成本汇总】，总需要合理化支出吧【合理化支出】，差不多可以得到预算了，知道总的需要 花多少了，领导知道了需要多少钱【资金需求】，大致知道最少花多少【成本基准】，如果中途变化有了，有风险了，还需要把计划更新下【项目管理计划更新】，如果预算完了，发现不对，需要变更下【请求的变更】。
钱是个大事情，花不好，会出事情的，需要监控下，就是【成本控制】。控制需要先知道最低标准，不能乱控制【成本基准】，知道最近需要多少钱【项目资金需求】，我最近花了多少完成了多少工作【工作绩效】，是不是按照计划进行的，如果按照计划都很好就不用控制了【项目管理计划】，发现有问题了，批准了，才会引起钱变化，才 会提出控制【批准的变更】，有了这些东西，就可以进行成本控制了，具体怎么控制呢？有的大公司有控制系统【成本变更控制系统】，有的人考预测【预测技术】，有的人对偏差进行分析后，发觉需要控制【偏差分析】，大多数是对完成的工作不满意才控制【项目绩效测量】，控制了，总是需要有结果，变化，那么最低标准就变化了【成本基准更新】最初的成本估算也就变化【成本估算更新】有好的经验共享【组织过程资产】，也完善了一些制度【企业环境因素】，也提出了一些纠偏措施【推荐的纠正措施】，控制完发现有些地方的计划是需要变更的【请求的变更】

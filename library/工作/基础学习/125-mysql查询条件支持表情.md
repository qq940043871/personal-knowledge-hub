# MySQL查询条件支持表情

1. word转pdf时候提示空指针异常

  是由于word占位符{FIRMID}不是一个整体导致，此时在文本编辑中处理后复制到word模板即可

2. pdf中中文汉字不展示

  是由于linux操作系统中没有该字体导致的

3. mysql查询条件支持表情

  修改name字段的排序规则为utf8mb4_bin

4. 虚拟机vmware复制导致的网卡找不到问题，调整为我移动即可
5. -Djava.library.path中的多个目录

  - D

6. 打包class文件为jar包

jar -cvf notice-1.0.jar com

# 业务场景与技术架构

以下是常用业务场景对应的开发架构与组件推荐，结合实际需求和技术选型逻辑整理：

## 1. 小型企业内部OA系统（低并发、功能单一）
+ **推荐架构**：单体架构 + 分层架构（表现层、业务层、数据层）
+ **核心组件**：
    - 后端框架：Spring Boot（快速开发）
    - 前端框架：Vue.js + Element UI（轻量易维护）
    - 数据库：MySQL（单机部署，满足小型数据存储）
    - 部署工具：Jenkins（简单CI/CD流程）

## 2. 电商平台（高并发、多模块、复杂业务）
+ **推荐架构**：微服务架构 + 云原生架构
+ **核心组件**：
    - 服务治理：Spring Cloud Alibaba（Nacos服务注册发现、Sentinel限流熔断）
    - 容器编排：Docker + Kubernetes（弹性伸缩、故障自愈）
    - 数据存储：MySQL主从复制（核心业务）、Redis集群（缓存）、Elasticsearch（商品搜索）
    - 消息队列：RocketMQ/Kafka（解耦订单、库存等模块，削峰填谷）
    - 链路追踪：SkyWalking（微服务调用监控）

## 3. 实时直播/短视频平台（高并发、低延迟、海量数据）
+ **推荐架构**：分布式架构 + 事件驱动架构
+ **核心组件**：
    - 流媒体服务：SRS/FFmpeg（视频推流、转码）
    - 缓存与存储：Redis Cluster（用户状态、弹幕缓存）、MinIO（视频文件存储）
    - 消息队列：Kafka（实时消息分发，如弹幕、点赞通知）
    - 实时计算：Flink（用户行为分析、实时推荐）
    - 负载均衡：Nginx + LVS（分流高并发请求）

## 4. 金融支付系统（高可用、强一致性、安全可靠）
+ **推荐架构**：微服务架构 + 服务网格架构
+ **核心组件**：
    - 服务网格：Istio（统一管控服务通信，加密传输）
    - 分布式事务：Seata（保证跨服务数据一致性，如订单与支付）
    - 数据库：MySQL集群（主从同步+分库分表）、TiDB（分布式数据库，满足高可用）
    - 安全组件：Shiro/Spring Security（权限控制）、HTTPS + 签名机制（防篡改）
    - 监控告警：Prometheus + Grafana（实时监控系统状态）

## 5. 物联网设备管理平台（多设备接入、实时数据采集）
+ **推荐架构**：微内核架构 + 分布式架构
+ **核心组件**：
    - 设备接入：MQTT协议 + EMQ X（物联网消息服务器）
    - 内核框架：OSGi（插件化管理设备适配模块）
    - 数据存储：InfluxDB（时序数据存储，如设备监控指标）、MongoDB（非结构化设备数据）
    - 远程控制：CoAP协议（轻量级设备控制指令传输）
    - 可视化：ECharts（设备状态仪表盘）

## 6. 内容管理系统（CMS，快速迭代、多终端适配）
+ **推荐架构**：单体架构（初期）/ 微服务架构（后期扩展）
+ **核心组件**：
    - 后端框架：Spring Boot + MyBatis-Plus（快速开发CRUD接口）
    - 前端框架：React + Ant Design（多终端适配，如PC、移动端）
    - 内容存储：MySQL（结构化内容）、七牛云/OOS（图片、文件存储）
    - 编辑器组件：TinyMCE/CKEditor（富文本编辑）
    - 缓存：Redis（热点内容缓存，提升访问速度）

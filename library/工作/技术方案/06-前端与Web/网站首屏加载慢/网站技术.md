## 🏆 首选框架：**Nuxt 3**（+ SSG 模式）

> ✅ 最适合企业官网的 Vue 框架

### 🔍 为什么选择 Nuxt 3？

| 特性 | 说明 |
|-|-|
| ✅ **支持静态生成（SSG）** | 预渲染所有页面为 HTML，首屏加载极快，无需服务器 |
| ✅ **SEO 友好** | 服务端直出 HTML，搜索引擎友好 |
| ✅ **Vue 生态官方支持** | 由 Vue 团队维护，稳定、文档全、生态丰富 |
| ✅ **开发体验优秀** | 自动路由、模块化架构、支持 TypeScript、Markdown |
| ✅ **图片优化内置** | 通过 `@nuxt/image` 自动压缩、转 WebP、懒加载 |
| ✅ **部署简单** | 构建为静态文件，可部署到 Vercel、Netlify、GitHub Pages 等 CDN 平台 |
| ✅ **可扩展性强** | 未来可轻松升级支持博客系统、多语言、表单提交等 |

---

### 🧰 推荐技术组合（企业官网最佳实践）

```Plain Text
Nuxt 3 + Vue 3 + TypeScript + Tailwind CSS / UnoCSS + @nuxt/image
```

#### 各组件作用：

- **Nuxt 3**：核心框架，负责路由、SSG、SEO
- **Vue 3**：组件化开发，Composition API 提升可维护性
- **TypeScript**：类型安全，适合团队协作
- **Tailwind CSS 或 UnoCSS**：快速构建响应式 UI，打包体积小
- **@nuxt/image**：自动优化图片（适合 banner、团队照片等）

---

### 🚀 构建一个企业官网的典型流程

1. **创建项目**

   ```Bash
   npx nuxi init my-company-website
   ```
2. **配置为静态站点（SSG）**

在 `nuxt.config.ts` 中：

```TypeScript
export default defineNuxtConfig({
  target: 'static', // 静态生成
  ssr: true,
  modules: [
    '@nuxtjs/tailwindcss',
    '@nuxt/image'
  ],
  // 优化图片
  image: {
    provider: 'ipx'
  }
})
```

1. **编写页面**

   - `pages/index.vue` —— 首页
   - `pages/about.vue` —— 关于我们
   - `pages/services.vue` —— 服务
   - `pages/contact.vue` —— 联系方式
2. **构建并部署**输出 `dist/` 目录，上传到：

   ```Bash
   npm run build
   ```

   - [Vercel](https://vercel.com)
   - [Netlify](https://netlify.com)
   - [Cloudflare Pages](https://pages.cloudflare.com)
   - GitHub Pages（配合 `gh-pages`）

# 17年技术经验总结

> 从业时间：2009年入行（软件 4 年 + 其他行业 13 年 = 17 年）｜整理时间：2026年3月
> 一份从计算机基础到架构设计的完整技术知识库，涵盖 17 年一线开发经验的核心沉淀。

## 核心知识主干

计算机组成 → 操作系统 → Web技术 → 虚拟化 → MySQL → Redis → 消息队列 → 架构实践，按「基础 → 中间件 → 架构」递进。

## 学习路径建议

- **基础阶段**：01-计算机组成原理 → 02-操作系统
- **应用阶段**：03-浏览器与Web技术 → 05-MySQL数据库 → 06-Redis中间件
- **进阶阶段**：04-虚拟化与容器 → 07-消息中间件 → 08-架构设计与工程实践

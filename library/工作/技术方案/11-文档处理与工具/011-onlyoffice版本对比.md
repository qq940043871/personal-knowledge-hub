# ONLYOFFICE 版本对比

ONLYOFFICE主要有社区版、企业版和开发版三个版本，以下是它们的详细对比：

## 许可与成本
+ **社区版**：免费，采用GNU AGPL v.3许可证，源代码可在GitHub上获取。
+ **企业版**：商业许可，需要购买，价格根据不同的定价方案而定，提供基础、增强、高级等不同等级的技术支持选项。
+ **开发版**：商业许可，价格根据具体需求和定价方案确定，同样提供不同等级的技术支持。

## 功能特性
+ **基础编辑功能**：三个版本均具备文档、表格、幻灯片、表单创建程序、PDF查看器和转换器等基础编辑功能，支持多种主流文件格式，如DOCX、PPTX、XLSX等。
+ **协同编辑功能**：社区版、企业版和开发版都支持多人实时协同编辑，提供自动和手动两种共同编辑模式，可跟踪变化、查看版本历史、进行文档比较等。
+ **安全性能**：
    - **社区版**：提供基本的安全功能，如HTTPS流量加密。
    - **企业版**：相比社区版，企业版通常会提供更高级的安全功能，如更严格的访问控制、数据加密、审计日志等，以满足企业对数据安全的高要求。还支持私密房间功能，提供更安全的协作空间。
    - **开发版**：安全功能与企业版类似，可根据开发需求进行定制化配置，以满足不同应用场景的安全要求。
+ **定制化与集成**：
    - **社区版**：有一定的定制化能力，但相对有限。
    - **企业版**：支持更多的定制化选项，企业可以根据自身需求对界面、功能等进行定制。同时，更易于与企业现有的系统和工作流程进行集成，如与企业的身份验证系统、文件存储系统等无缝对接。
    - **开发版**：侧重于为开发者提供丰富的API和工具，方便将ONLYOFFICE的在线编辑器功能集成到网页版应用程序中，实现自定义的文档编辑、协作等功能。还可能提供更多的插件和扩展功能，以满足不同开发需求。
+ **性能**：
    - **社区版**：适用于小型团队或个人使用，在处理少量文档和低并发访问时表现良好。
    - **企业版**：针对企业级应用进行了性能优化，能够处理大量文档和高并发访问，确保系统在企业环境中的稳定性和响应速度。
    - **开发版**：性能方面与企业版类似，可根据集成的应用场景和需求进行优化。

## 使用限制
+ **社区版**：同时连接数最多为20个，推荐用户数最多为20个。达到连接上限后，后续文档将以只读模式打开。
+ **企业版**：根据所选定价方案确定同时连接数和用户数量限制，可支持成千上万的用户，具有更高的可扩展性。
+ **开发版**：同时连接数和用户数量限制根据具体的定价方案而定，可根据开发需求进行灵活配置。

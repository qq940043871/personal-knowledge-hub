## 三、技术选型（高并发 + 信创全兼容）
### 1）基础设施（信创）
+ **芯片**：鲲鹏、飞腾、海光、龙芯
+ **OS**：银河麒麟、统信 UOS
+ **容器**：Docker + K8s（国产发行版）
+ **云平台**：华为云 Stack、阿里云专有云、浪潮云

### 2）接入/网关
+ **API 网关**：Spring Cloud Gateway、国产微服务网关
+ **负载均衡**：Nginx（国产优化）、F5 替代
+ **CDN**：阿里云 CDN、腾讯云、白山（信创）

### 3）微服务体系（Java 主流）
+ **开发框架**：Spring Boot + Spring Cloud Alibaba
+ **服务注册/发现**：Nacos（信创兼容）
+ **配置中心**：Nacos / Apollo（国产）
+ **分布式事务**：Seata（信创适配）
+ **消息队列**：RocketMQ（阿里信创）、 Kafka 国产版

+ **本地缓存**：**基本不用**（异构系统一致性灾难）
+ **缓存更新**：CDC（监听高斯DB binlog） + 规则中心配置表

### 5）数据库（信创重点，你用高斯DB 非常标准）

+ **分库分表**：ShardingSphere（国产）
+ **搜索**：Elasticsearch（国产优化）
+ **分析库**：ClickHouse、华为 GaussDB AP
+ **缓存 DB**：Redis

### 6）中间件（信创）
+ **应用服务器**：东方通 TongWeb、金蝶 Apusic
+ **ETL**：DataX、国产 DataService
+ **任务调度**：XXL-Job、国产 Scheduler

### 7）安全（信创 + 等保 3）
+ **加密**：国密 SM2/SM3/SM4
+ **认证**：OAuth2.0、OIDC、企业微信/钉钉免登
+ **WAF**：启明星辰、天融信、阿里云 WAF
+ **审计**：全链路操作日志、数据脱敏

## 四、高并发、高可用、安全怎么处理（B2B 关键）
### 1）高并发
+ **读写分离**：交易写主库，查询走从库/只读实例
+ **热点缓存**：商品、订单、用户全量缓存
+ **异步化**：消息队列削峰（下单 → 扣库存 → 通知 → 物流）
+ **分库分表**：订单/用户/商品 水平分片
+ **限流降级**：Sentinel 限流、降级、熔断

### 2）高可用
+ **无状态服务**：全微服务可水平扩展
+ **K8s 自愈**：故障自动重启、迁移
+ **数据库主从+强一致**：高斯DB 支持强一致
+ **双活数据中心**：RPO=0，RTO<30s
+ **熔断降级**：核心链路 99.99% 可用

### 3）一致性（你最痛的点）
+ **最终一致优先**：消息队列 + 重试 + 幂等
+ **分布式事务**：Seata 处理订单-库存-支付
+ **CDC 缓存更新**：DB 变更 → 自动清 Redis
+ **规则中心统一管理**：一张表维护所有缓存key规则

### 4）安全（B2B 强需求）
+ **身份强认证**：企业认证 + 法人实名 + 双因子
+ **数据权限**：行级/列级数据隔离
+ **传输加密**：HTTPS + 国密 SM2/SM4
+ **存储加密**：敏感字段加密（手机号、金额）
+ **审计日志**：全链路不可篡改日志

## 跨域请求
1. web访问验证refer
2. app访问验证提前设置的header,比如token
3. **API 密钥**：为每个合法的调用方分配唯一的 API 密钥，后端服务在接收到请求时验证该密钥
4. **令牌（Token）**：如 JWT（JSON Web Token），客户端获取并携带令牌进行请求，后端验证令牌的有效性和合法性
5. **时间戳和 nonce**：请求中包含时间戳，后端检查时间戳是否在合理范围内以防止重放；同时结合 nonce（一次性随机数），确保每次请求的唯一性
6. **IP 限制**：限制可以访问后端服务的 IP 地址范围
7. **请求签名**：对请求的关键参数进行签名，后端验证签名是否正确
8. **验证码**：在关键操作时要求用户输入验证码，增加恶意调用的难度
9. **限流**：限制单位时间内某个客户端或 IP 的请求次数，防止恶意频繁调用
10. **时间戳的签名算法**：比如google验证器

### 具体整改方案：
1. **API 密钥**：为每个合法的调用方分配唯一的 API 密钥，后端服务在接收到请求时验证该密钥

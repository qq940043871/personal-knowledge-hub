# 金融领域跨平台安全助手
## 完整可交付PRD产品需求文档（含落地排期）
### 一、文档基础信息
1. **产品名称**：金融全域终端安全智能防护助手
2. **产品版本**：V1.0 正式交付版
3. **适用范围**：银行、证券、基金、期货全行业内部办公终端、交易终端、线上客户终端
4. **交付对象**：产品团队、研发团队（前后端+客户端）、测试团队、安全合规部、运维部署部
5. **运行环境**：Windows10/11、macOS、统信UOS、麒麟国产操作系统（全平台兼容）
6. **开发框架定稿**
客户端：Tauri 跨平台原生框架（Rust内核+Vue3），轻量化、高安全、防篡改；服务端：Spring Cloud Alibaba 微服务集群，支持高并发金融级吞吐；加密底座：国密SM2/SM3/SM4全链路合规加密，符合金融等保2.0。

### 二、产品背景与业务痛点
#### 2.1 行业背景
金融机构核心交易系统、资金划转系统、客户理财系统全部属于等保三级以上核心涉密系统，当前网络攻击、账号劫持、异地盗登、终端木马渗透、交易报文篡改攻击呈常态化高发态势。单一账号密码登录、普通防火墙防护，已无法满足监管合规与实际风控要求。

#### 2.2 现存核心业务痛点
1. 无终端可信绑定，员工私用电脑、外网设备随意登录内部金融系统，溯源难、管控难。
2. 业务报文明文/弱加密传输，存在中间人窃听、恶意篡改交易指令风险。
3. 无实时智能风控模型，异地登录、批量同IP登录、多账号同设备登录无法秒级拦截。
4. 跨终端适配差，传统安全工具只能用Windows，无法适配国产办公系统。
5. 全链路操作无标准化审计日志，监管抽查无法快速出具合规台账。

#### 2.3 产品核心价值
1. 筑牢终端可信边界，一机一密、一账号一设备指纹，从源头封堵非法接入。
2. 全业务链路国密加密，满足央行、银保监会密码合规强制要求。
3. 毫秒级智能风控研判，自动拦截高危操作、自动冻结异常会话。
4. 一套代码全平台部署，适配国产化信创改造全场景。
5. 自动生成合规审计报表，一键对接监管平台，降低合规人力成本。

### 三、产品整体目标与验收标准
#### 3.1 功能目标
完成终端可信采集、国密安全通信、双因子可信登录、实时风控预警、全链路审计台账、后台运维管控六大核心闭环能力。

#### 3.2 性能目标
1. 客户端启动耗时≤1.5秒，内存常驻占用≤80MB，不影响金融交易软件延时。
2. 接口响应峰值≤20ms，支持万级终端同时在线并发。
3. 风控研判单次计算≤5ms，无业务卡顿。

#### 3.3 安全合规目标
1. 全程无明文传输、无敏感信息本地缓存泄露风险。
2. 完全符合金融等保2.0、国密算法应用规范、金融数据安全生命周期管理办法。
3. 客户端防调试、防Hook、防逆向篡改，后台接口防刷、防重放、防越权。

#### 3.4 验收上线标准
全功能联调通过、压力测试达标、第三方安全渗透测试无高危漏洞、合规部审核盖章、全终端灰度试运行7天无告警事故。

### 四、核心用户角色与使用场景
#### 4.1 核心用户角色
1. 内部金融员工：办公、后台账务审核、系统运维人员。
2. 一线交易员：高频行情查看、实时资金交易操作人员。
3. 安全管理员：后台查看风控告警、管理可信设备、导出审计日志。
4. 合规审计人员：按月导出安全台账、对接监管检查。

#### 4.2 高频核心使用场景
场景一：员工日常内网登录金融核心业务系统，安全助手自动核验设备指纹，无感完成可信鉴权。
场景二：异地临时办公登录系统，自动触发二次人脸核验+风险弹窗，后台实时记录轨迹。
场景三：大批量终端集中批量上线，运维后台一键批量准入设备白名单。
场景四：出现疑似盗号攻击，系统自动熔断会话、锁定账号、推送运维告警短信。
场景五：月末合规自查，一键导出全月登录日志、风控台账、加密链路日志。

### 五、整体产品架构（落地版）
全域端侧安全采集层→Tauri跨平台客户端层→国密加密通信网关层→微服务业务能力层→智能风控引擎层→运维审计管控后台层→数据合规存储层。
全程独立隔离部署，不侵入原有金融核心交易系统，零改造对接。

### 六、核心功能详细需求（全量可开发）
## 模块一：跨平台终端可信采集模块（必做）
1. 自动静默采集终端硬件唯一信息：主板序列号、CPU硬件ID、硬盘唯一SN、网卡真实MAC地址、内网固定IP、外网出口IP、终端操作系统版本。
2. 本地Rust算法加密合成**不可篡改全局设备指纹**，不上传原始硬件明文。
3. 实时监测终端环境：是否存在木马进程、是否远程被控、是否虚拟机伪装环境。
4. 异常环境直接拦截所有金融系统登录请求，弹窗提示环境不安全。
5. 权限要求：仅首次安装申请本地设备读取权限，后台无隐私采集。

## 模块二：国密全链路安全加密通信模块（合规核心）
1. 登录报文、交易心跳、运维指令全部采用SM2非对称加密+SM4会话加密组合方案。
2. 实行一客一密钥、一会话一刷新，密钥自动24小时轮换。
3. 所有接口请求强制时间戳+随机串双重防重放签名。
4. 自动适配金融内网专线、外网VPN双网络链路加密。
5. 加密失败自动断开链路，禁止弱网、非法链路接入业务系统。

## 模块三：双因子可信登录与会话管理模块
1. 账号密码+设备指纹双重强制核验，缺一不可登录。
2. 常用设备免核验，陌生设备强制二次短信/企业微信核验。
3. 登录成功后自动建立加密长心跳会话，30秒一次后台保活。
4. 主动下线、异地挤线、长时间闲置自动销毁会话密钥。
5. 后台可手动强制批量下线高危终端，一键熔断权限。

## 模块四：AI多维度智能风控实时预警模块
1. 多维风控规则引擎：异地IP跨省登录、同一MAC多账号登录、短时间频繁切号、凌晨非常规时段登录、境外代理IP接入。
2. 风险分级处置：低风险弹窗提醒、中风险二次核验、高风险直接锁号断连。
3. 全告警实时推送后台运维大屏、推送短信、推送企业微信机器人。
4. 自动生成风控研判报告，留存溯源证据。
5. 支持管理员后台自定义新增风控规则，灵活适配业务调整。

## 模块五：全链路合规审计日志台账模块
1. 自动留存：登录地点、登录设备、操作时间、加密链路编号、风控判定结果、下线原因全字段日志。
2. 日志加密存储90天以上，不可删除、不可篡改。
3. 支持按人员、按部门、按时间段、按风险等级多条件检索。
4. 一键导出PDF/Excel合规台账，直接对接监管检查。
5. 日志异常自动备份，防止服务器故障丢失数据。

## 模块六：运维管理后台管控模块
1. 可信设备白名单批量导入、单条新增、批量移除。
2. 全终端在线状态实时大屏监控，可视化运维。
3. 权限分级管理：普通运维、安全管理员、超级管理员三权分立。
4. 客户端远程静默升级，无需员工手动操作。
5. 全局一键关停、全局一键放行应急管控能力。

### 七、页面交互与弹窗规范
1. 客户端主界面极简设计，后台自动运行，无多余操作，不干扰办公交易。
2. 安全告警弹窗红底高亮，不可绕过，必须手动确认。

## 配套：金融安全助手全套接口设计文档（可直接对接开发）
### 一、接口通用规范
1. 协议：HTTPS + 国密TLS加密，内网专线优先。
2. 数据格式：全部JSON，禁止XML明文。
3. 签名规则：每个接口必带timestamp时间戳+nonce随机串+SM2业务签名。
4. 编码：UTF-8，统一字段驼峰命名。
5. 错误码：全局统一规范，便于前端异常弹窗。
6. 权限：所有接口必须携带会话Token+设备指纹双重鉴权。

### 二、全局统一返回格式
{
  "code": 200, //200成功、401未鉴权、403权限不足、500服务异常、601设备非法
  "msg": "操作成功",
  "data": {},
  "sign": "后台SM2签名串"
}

### 三、核心业务接口清单（全量）
#### 接口1：客户端初始化采集设备信息接口
接口地址：/api/device/collect
请求方式：POST
接口描述：客户端启动后静默上报合规设备特征，合成指纹，不上传原始隐私数据
请求参数：无Header自动携带终端系统标识
返回字段：deviceFingerprint（设备唯一指纹）、envRiskLevel（环境安全等级）

#### 接口2：国密账号可信登录接口
接口地址：/api/auth/safe-login
请求方式：POST
业务核心：双因子核验核心接口
请求入参：username账号、sm4Pwd加密密码、deviceFingerprint设备指纹、clientTime时间戳
业务逻辑：后台校验账号合法性+校验设备白名单+实时风控打分
返回内容：sessionToken会话密钥、userRealName脱敏姓名、riskTips风险提示文案

#### 接口3：客户端30秒心跳保活接口
接口地址：/api/session/heartbeat
请求方式：POST
接口作用：维持在线、实时监测终端是否掉线、是否异地切网
入参：sessionToken、deviceFingerprint、currentNetworkIp
返回：keepAliveResult保活状态、networkRisk网络风险等级

#### 接口4：主动下线销毁会话接口
接口地址：/api/session/logout
请求方式：POST
场景：员工退岗、手动退出系统
入参：sessionToken
返回：logoutTime下线时间、sessionDestroy状态

#### 接口5：陌生设备二次核验下发接口
接口地址：/api/risk/send-verify-code
请求方式：POST
场景：异地/新设备登录触发
入参：phone脱敏手机号、riskOrderId风控单号
返回：sendResult下发成功与否、expireTime验证码有效期

#### 接口6：风控结果实时查询接口
接口地址：/api/risk/query-real-time
请求方式：GET
入参：userId、loginTime
返回：riskLevel高/中/低、riskReason风控原因、handleSuggest处置建议

#### 接口7：运维后台查询全量在线终端接口
接口地址：/api/admin/online-device-list
请求方式：GET
权限：仅安全管理员
返回：在线终端列表、属地IP、部门、实时风险状态

#### 接口8：后台批量新增可信设备白名单接口
接口地址：/api/admin/device-batch-add
请求方式：POST
入参：batchDeviceFingerprintList批量指纹数组、operatorAdmin操作管理员账号
返回：successNum成功条数、failNum失败条数、failReason失败明细

#### 接口9：全链路审计日志分页查询接口
接口地址：/api/audit/log-page-list
请求方式：GET
入参：startTime、endTime、userId、riskLevel
返回：分页日志列表、操作轨迹、加密链路编号

#### 接口10：审计台账一键导出接口
接口地址：/api/audit/export-report
请求方式：POST
入参：exportCondition导出条件、fileTypePDF/Excel
返回：fileUrl加密台账下载地址、expireUrl链接有效期

#### 接口11：客户端静默升级检测接口
接口地址：/api/client/check-update
请求方式：GET
入参：clientVersion当前版本、systemType操作系统类型
返回：needUpdate是否升级、updatePackageUrl升级包、updateNote安全优化说明

#### 接口12：后台强制熔断高危会话接口
接口地址：/api/admin/force-kick-session
请求方式：POST
高危应急接口
入参：sessionToken、kickReason应急原因
返回：kickResult强制下线结果、alarmRecord告警归档编号

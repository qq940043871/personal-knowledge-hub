# 交收规则

| 交收规则 | 结算方式 | 交收顺序 |
| --- | --- | --- |
| 组织交收 | 付款交割 | 付款-发货-收货-收款 |
|  | 先款后货 | 付款-收款-发货-收货 |
| | 先货后款 | 发货-收货-付款-收款 |
| 自主交收 | | 直接申请释放保证金结束 |
| 自由交收 | | 无固定流程限制，付款和货物没有先后顺序 |
| | | |

| **组织交收的分支流程** | | | | |
| :--- | --- | --- | --- | --- |
| **一级：交收类型** | **二级：配货类型** | **三级：提货类型** | **流程终点 / 后续子流程** | **适用场景** |
| 线下交收 | -（无需细分） | -（线下协商） | 流程结束 | 买卖双方线下直接对接货物（如本地小额交易、定制化商品） |
| 线上交收 | 线下配货 | -（线下对接） | 流程结束 | 线上确认交易，线下卖方直接向买方配货（如卖方无固定仓库） |
| 线上交收 | 仓单配货 | 自提 | 进入 “自提流程” | 买方到指定仓库凭仓单提取货物（如大宗商品、批量采购） |
| 线上交收 | 仓单配货 | 配送 | 进入 “配货流程” | 仓库根据指令将货物配送至买方指定地点（如异地采购、零售订单） |
| 线上交收 | 仓单配货 | 转入库 | 进入 “转入库流程” | 货物从当前仓库转入买方指定的其他仓库（如库存调拨、跨仓管理） |

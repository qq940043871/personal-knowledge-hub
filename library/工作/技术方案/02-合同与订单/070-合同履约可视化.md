# 合同交收履约流程可视化配置方案
## （可直接落地、可进文档、支持低代码拖拽配置）
我给你的是**国内头部 B2B 平台、供应链平台真实在用的标准方案**，
能做到：
**可视化拖拽流程 → 配置每个节点干什么（付款/短信/开票/资金/验收）→ 运行时自动执行**
不用写代码，业务人员也能配。

---

## 一、整体设计思路（一句话）
### **把合同履约过程，抽象成一套“可配置的流程引擎 + 节点动作库”，
流程画图配，动作选着用，数据自动流转。**

你看到的效果就像：

+ 钉钉/企业微信审批流程
+ 低代码平台流程设计器
+ 电商售后流程配置

但你们是 **B2B 合同交收 + 资金 + 物流 + 票据 + 消息** 一体化。

---

## 二、核心模型：四件套
### 1. 流程模板（Process Template）
一个合同类型对应一个流程模板
例如：

+ 现货采购流程
+ 合同长期履约流程
+ 招投标流程
+ 集采分批发货流程

### 2. 流程节点（Node）
每个节点代表一个“业务环节”，例如：

+ 下单提交
+ 审批通过
+ 预付款支付
+ 发货
+ 收货验收
+ 对账
+ 开票
+ 尾款支付
+ 完成归档

### 3. 节点动作库（Action Library）
**节点上可以挂载“要干什么事”，全部预制，不用写代码。**

你关心的所有内容都在这里：

+ 触发支付（预付款/尾款/分期）
+ 发送短信/站内信/邮件
+ 自动开票
+ 生成对账单
+ 资金冻结/解冻/结算
+ 库存扣减/释放
+ 合同状态变更
+ 通知第三方系统（ERP/WMS）

### 4. 流转规则（Rule）
+ 条件判断：金额 > 100 万 → 需总经理审批
+ 自动流转：验收通过 → 自动进入开票节点
+ 超时规则：72 小时未支付 → 自动关闭
+ 回退规则：可驳回至任意前序节点

## 三、可视化设计器前端呈现（你要的可视化）
前端使用流程设计器（类似 bpmn.js / activiti designer / 低代码流程画布）

界面布局：

1. 左侧：**节点库**
    - 审批节点
    - 支付节点
    - 消息节点
    - 开票节点
    - 验收节点
    - 条件节点
    - 同步第三方节点
2. 中间：**画布**
拖拽连线，形成流程图：

```plain
   合同创建 → 审批节点 → 【支付预付款】 → 发货 → 验收 → 【自动开票】 → 【支付尾款】 → 完成
```

3. 右侧：**节点配置面板**
点哪个节点，配哪个节点：
    - 节点名称
    - 处理人/角色
    - 触发动作（发短信/生成支付单/开票）
    - 超时时间
    - 自动通过条件
    - 字段权限控制

## 四、节点动作详细配置（你最关心的部分）
### 1. 付款动作配置（资金处理）
在任意节点上可挂载：

+ 支付类型：预付款 / 阶段性付款 / 尾款 / 分期
+ 支付方式：对公转账 / 在线支付 / 账期 / 预付款抵扣
+ 金额规则：
    - 合同金额 × 20%
    - 固定金额
    - 按发货比例自动计算
+ 自动创建支付单
+ 支付完成自动进入下一节点
+ 支付超时自动回退/关闭

### 2. 短信/消息通知配置
+ 触发时机：节点进入 / 节点审批通过 / 节点驳回
+ 接收人：企业管理员 / 经办人 / 供应商
+ 内容模板：
`您的合同【${contractNo}】已进入付款环节，请及时处理。`
+ 渠道：短信 + 站内信 + 微信公众号 + 邮件

### 3. 开票配置
+ 开票时机：验收通过 / 阶段完成 / 全部履约完成
+ 开票类型：增值税专票 / 普票
+ 金额：按实际发货 / 按合同金额
+ 自动生成开票申请
+ 对接税控系统 / 电子发票平台

### 4. 资金处理配置
+ 冻结保证金
+ 释放保证金
+ 结算给供应商
+ 生成对账凭证
+ 对接银企直联
+ 自动形成财务凭证

### 5. 条件分支配置（最强大）
例如：

+ 金额 < 10 万 → 自动审批
+ 金额 ≥ 10 万 → 二级审批
+ 金额 ≥ 100 万 → 三级审批
+ 账期客户 → 跳过支付节点

## 五、后端技术实现（可直接落地）
### 1. 流程引擎选型
+ Flowable（推荐，Spring 全家桶，支持信创）
+ Camunda 国产版
+ 自研轻量状态机（简单场景）

### 2. 动作执行器（Action Executor）
每个动作对应一个 Java 实现类：

+ `PayAction.java` // 创建支付单
+ `SmsAction.java` // 发短信
+ `InvoiceAction.java` // 开票
+ `AccountAction.java` // 对账
+ `ErpSyncAction.java` // 同步ERP

流程引擎执行到节点 → 自动调用对应 Action。

### 3. 运行时流程实例
+ 一个合同 = 一个流程实例（ProcessInstance）
+ 每步执行记录日志
+ 支持暂停、驳回、撤销、终止
+ 支持查看“流转图”

### 4. 高并发可靠执行
+ 节点执行异步化（MQ）
+ 失败重试
+ 幂等保障
+ 异常进入死信队列 + 人工处理

## 七、这套架构的优势（你可以写进方案）

## 合同交收履约可视化流程设计器原型图+架构图描述
### 一、合同交收履约流程设计器原型图详细描述
#### 1. 整体页面布局（PC端后台管理系统）
页面采用**三栏固定布局**，顶部为操作栏，左侧节点物料栏、中间流程画布栏、右侧属性配置栏，整体风格简洁专业，适配B端后台操作，支持拖拽、连线、缩放、保存等操作。

##### 1.1 顶部操作栏（通栏）
+ 左侧：流程模板名称输入框、模板类型下拉选择（现货采购/长期合同/集采/招投标）、模板状态（启用/禁用）切换
+ 中间：流程画布操作按钮（放大、缩小、居中对齐、清空画布、撤销、重做）
+ 右侧：保存模板、预览流程、发布模板、导出配置、帮助说明按钮

##### 1.2 左侧节点物料栏（固定宽度侧边栏）
分为**基础节点、业务节点、动作节点、条件节点**四大分类，可折叠展开，节点支持鼠标拖拽至中间画布：

1. **基础节点**
    - 开始节点：圆形绿色图标，标识流程启动
    - 结束节点：圆形红色图标，标识流程终止
    - 人工审批节点：方形图标，标注“审批”，支持多级审批配置
2. **业务节点**
    - 合同创建节点：关联合同信息，流程起始业务节点
    - 发货履约节点：标识货物交收、物流发货环节
    - 收货验收节点：标识收货、质检、验收确认环节
    - 对账确认节点：生成对账单、双方确认环节
3. **动作节点（核心配置节点）**
    - 付款处理节点：标注“资金付款”，配置支付规则、支付方式
    - 短信通知节点：标注“消息推送”，配置通知渠道、内容模板
    - 自动开票节点：标注“票据开具”，配置开票类型、金额规则
    - 资金结算节点：标注“资金处理”，配置保证金、结算、对账
4. **条件节点**
    - 条件分支节点：菱形图标，支持金额、角色、合同类型等条件判断
    - 并行节点：支持多环节同时执行
    - 回退节点：支持流程驳回至指定前置节点

##### 1.3 中间流程画布栏（主操作区）
+ 画布支持自由拖拽、网格对齐、节点连线、节点删除/复制
+ 节点间通过**有向连线**关联，标识流程执行顺序，连线可编辑、删除
+ 流程示例呈现：
`开始节点 → 合同创建节点 → 审批节点 → 付款处理节点 → 发货履约节点 → 收货验收节点 → 条件分支节点 → 自动开票节点 → 资金结算节点 → 结束节点`
+ 节点高亮：选中节点时边框高亮，区分未选中状态；连线标注执行条件（如“审批通过”“支付完成”）

##### 1.4 右侧属性配置栏（固定宽度侧边栏）
选中任意节点后，自动加载对应配置面板，分tab展示配置项：

1. **基础配置**：节点名称、节点编码、执行顺序、超时时间、是否自动执行
2. **权限配置**：处理角色、处理人、审批层级、数据查看权限
3. **动作配置**（核心）
    - 付款配置：支付类型（预付款/阶段性付款/尾款）、金额比例、支付方式、自动生成支付单、超时关闭规则
    - 通知配置：通知对象、通知渠道（短信/站内信/邮件）、消息模板、触发时机
    - 开票配置：开票类型、开票金额规则、对接税控系统、发票推送方式
    - 资金配置：保证金冻结/释放、资金结算对象、对账规则、财务凭证生成
4. **流转配置**：下一执行节点、回退节点、条件判断规则、异常处理方式

#### 2. 交互逻辑
1. 左侧物料节点**拖拽**至画布，松开完成节点添加
2. 鼠标悬停节点，拖拽连线至目标节点，完成流程关联
3. 单击节点，右侧加载配置面板，完成参数配置
4. 支持条件分支节点拖拽，配置分支判断规则
5. 保存后可预览完整流程，发布后生效，关联对应合同类型

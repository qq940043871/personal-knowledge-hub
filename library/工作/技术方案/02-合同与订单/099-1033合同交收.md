# 1033合同交收

组织交收：

交收类型：线上交收；线下交收

配货类型：仓单配货；线下配货

提货类型：自提；配送；转入库

线下交收-》流程结束

线上交收-》线下配货-》流程结束

线上交收-》仓单配货-》自提-》自提流程

线上交收-》仓单配货-》配送-》配货流程

线上交收-》仓单配货-》转入库-》转入库流程

卖方收款节点：

买方付款时卖方收款

买方收货时卖方收款

卖方收款时卖方收款

卖方保证金释放节点：

买方收货时释放

卖方收款时释放

买方收票时释放

付款方式：

余额类；银行类；线下类；

余额类：可以实现上述所有卖方收款节点和卖方保证金释放节点；

银行类：是否可以实现以上所有流程

线下类：是否可以使用所有

如何使用银行类支付履约保证金，银行类支付货款，如何实现履约金转货款这种方式

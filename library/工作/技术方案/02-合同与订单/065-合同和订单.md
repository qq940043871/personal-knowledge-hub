# 合同 vs 订单：区别与业务先后顺序
## 一、核心区别
| 对比项 | 合同 | 订单 |
| --- | --- | --- |
| **法律性质** | 正式法律文件，约束双方长期/整体合作关系 | 交易执行凭证，基于合同的单次/批量采购指令 |
| **内容范围** | 约定合作框架、价格区间、质量标准、违约责任、合作期限等 | 明确单次交易的**具体品名、数量、单价、交货期、收货信息** |
| **约束力** | 强，违约直接按合同追责 | 弱，通常以对应合同为依据，无合同则订单效力不足 |
| **使用场景** | 合作开始前签订，长期有效 | 每次采购/发货时生成，单次有效 |
| **形式要求** | 书面盖章，条款严谨 | 可书面/系统生成，审批即可 |

## 二、业务产生先后顺序
**常规标准流程：**

1. **先签合同**
确立双方合作关系、定价规则、质量、账期、违约责任等基础规则。
2. **后下订单**
基于已签订的合同，发起具体采购/销售指令，确定本次交易明细。

---

### 特殊情况
+ 无框架合同，直接下订单并约定条款：此时**订单视同简易合同**，顺序为先订单后履约。
+ 框架合同到期后仍沿用旧单：业务上仍按“先合同、后订单”逻辑规范，否则存在合规风险。

简单总结：**合同定规则，订单做执行；先有合同，后有订单**。

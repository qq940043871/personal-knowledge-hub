# 四大业务模块接口文档与表结构梳理
## 说明
基于现有主合同表结构，补充各业务模块所需的扩展字段；针对合同转让、国内代采等核心流程，梳理对应的接口信息（含请求参数、响应参数）及新增关联表结构，确保业务流程与数据存储、接口交互全链路贯通。

## 一、核心基础：主合同表结构扩展
在现有主合同表（假设表名：t_main_contract）中新增以下字段，支撑四大业务模块的核心配置需求：

| **字段名** | **数据类型** | **字段说明** | **关联业务模块** | **可选值/默认值** |
| --- | --- | --- | --- | --- |
| allow_transfer | tinyint(1) | 是否允许合同转让 | 合同转让 | 0-不允许，1-允许；默认0 |
| transfer_status | varchar(20) | 合同转让状态 | 合同转让 | INIT-未转让，TRANSFERRING-转让中，TRANSFERRED-已转让，CANCEL-转让取消；默认INIT |
| procurement_status | varchar(20) | 代采状态 | 国内代采 | INIT-未代采，APPLYING-申请中，CONFIRMED-代采确认，COMPLETED-代采完成，CANCEL-代采取消；默认INIT |
| is_chain_settlement | tinyint(1) | 是否为链式交收合同 | 链式交收 | 0-否，1-是；默认0 |
| batch_no | varchar(50) | 链式交收批次号（非链式合同为空） | 链式交收 | 格式示例：CHAIN_YYYYMMDDXXXX |
| warehouse_receipt_owner_type | varchar(30) | 仓单所属方类型 | 货物代采 | ORDINARY-普通主体，INTERNATIONAL_TRADER-国际贸易商；默认ORDINARY |
| original_contract_id | varchar(20) | 原合同ID（转让/代采合同关联原合同） | 合同转让、国内代采 | 无原合同则为0 |

## 二、各业务模块接口文档
### 模块1：合同转让
#### 1.1 核心接口：合同转让申请接口
| **接口信息** | **详情** |
| --- | --- |
| 接口名称 | contract/transfer/apply |
| 请求方式 | POST |
| 接口描述 | 提交合同转让申请，更新原合同转让状态，生成转让记录及新的转让合同 |
| 请求参数（JSON） | `{   `` "mainContractId": 123456, // 必选，原主合同ID   `` "transferorId": 789, // 必选，转让方（原卖方）ID   `` "transfereeId": 1011, // 必选，受让方（新卖方）ID   `` "transferPrice": 10000.00, // 必选E，转让价格   `` "transferRemark": "合同转让", // 可选，转让备注   `` "operateUserId": 1213 // 必选，操作人ID   ``}` |
| 响应参数（JSON） | `{   `` "code": 200, // 200-成功，500-失败   `` "message": "转让申请提交成功",   `` "data": {   `` "transferRecordId": 5678, // 转让记录ID   `` "newContractId": 123457, // 新生成的转让合同ID（关联原合同）   `` "transferStatus": "TRANSFERRING" // 最新转让状态   `` }   ``}` |
| 特殊规则校验 | 1. 校验原合同allow_transfer是否为1（允许转让）；2. 校验转让价格，若低于原合同价格，触发卖方盈亏资金冻结逻辑；3. 校验转让方是否为原合同卖方 |

#### 1.2 辅助接口：转让状态查询接口
| **接口信息** | **详情** |
| --- | --- |
| 接口名称 | contract/transfer/queryStatus |
| 请求方式 | GET |
| 请求参数（URL参数） | mainContractId=123456（原合同ID） |
| 响应参数 | `{   `` "code": 200,   `` "message": "查询成功",   `` "data": {   `` "mainContractId": 123456,   `` "transferStatus": "TRANSFERRED",   `` "transferRecordId": 5678,   `` "transferTime": "2025-08-01 14:30:00"   `` }   ``}` |

### 模块2：国内代采
#### 2.1 核心接口：代采申请提交接口
| **接口信息** | **详情** |
| --- | --- |
| 接口名称 | contract/procurement/apply |
| 请求方式 | POST |
| 接口描述 | 买方提交代采申请，生成代采记录，更新主合同代采状态为申请中 |
| 请求参数（JSON） | `{   `` "mainContractId": 123459, // 必选，原主合同ID   `` "buyerId": 1314, // 必选，买方ID（代采申请人）   `` "procurerId": 1516, // 必选，代采方ID（需在国内代采人列表中）   `` "procurementPrice": 10500.00, // 必选，买方与代采方的合同价格（需≥原合同价格）   `` "originalPrice": 10000.00, // 必选，原合同价格（代采方与卖方的合同价格）   `` "procurementRemark": "国内代采", // 可选，代采备注   `` "operateUserId": 1213 // 必选，操作人ID   ``}` |
| 响应参数（JSON） | `{   `` "code": 200,   `` "message": "代采申请提交成功",   `` "data": {   `` "procurementRecordId": 7890, // 代采记录ID   `` "procurementContractId": 123460, // 代采方与买方的新合同ID   `` "procurementStatus": "APPLYING"   `` }   ``}` |
| 特殊规则校验 | 1. 校验代采方是否在国内代采人列表中；2. 校验procurementPrice≥originalPrice（仅允许加价）；3. 原合同需未处于代采状态 |

#### 2.2 核心接口：代采确认接口
| **接口信息** | **详情** |
| --- | --- |
| 接口名称 | contract/procurement/confirm |
| 请求方式 | POST |
| 请求参数（JSON） | `{   `` "procurementRecordId": 7890, // 必选，代采记录ID   `` "procurerId": 1516, // 必选，代采方ID   `` "confirmResult": 1, // 必选，确认结果：1-同意，2-拒绝   `` "rejectReason": "", // 可选，拒绝原因（confirmResult=2时必填）   `` "operateUserId": 1718 // 必选，操作人ID   ``}` |
| 响应参数 | `{   `` "code": 200,   `` "message": "代采确认成功",   `` "data": {   `` "procurementStatus": "CONFIRMED",   `` "mainContractId": 123459   `` }   ``}` |

### 模块3：链式交收
#### 3.1 核心接口：链式交收批次创建接口
| **接口信息** | **详情** |
| --- | --- |
| 接口名称 | chainSettlement/batch/create |
| 请求方式 | POST |
| 接口描述 | 创建链式交收批次，生成批次号，关联相关转让/代采合同 |
| 请求参数（JSON） | `{   `` "contractIds": [123456,123457,123460], // 必选，参与链式交收的合同ID列表（含原合同、转让/代采合同）   `` "finalBuyerId": 1920, // 必选，最终端买方ID   `` "batchRemark": "链式交收批次", // 可选，批次备注   `` "operateUserId": 1213 // 必选，操作人ID   ``}` |
| 响应参数 | `{   `` "code": 200,   `` "message": "链式交收批次创建成功",   `` "data": {   `` "batchNo": "CHAIN_202508010001",   `` "batchId": 2122,   `` "contractCount": 3   `` }   ``}` |

#### 3.2 核心接口：链式交收提货申请接口
| **接口信息** | **详情** |
| --- | --- |
| 接口名称 | chainSettlement/pickup/apply |
| 请求方式 | POST |
| 请求参数（JSON） | `{   `` "batchNo": "CHAIN_202508010001", // 必选，链式交收批次号   `` "finalBuyerId": 1920, // 必选，最终端买方ID   `` "paymentProof": "XXX.pdf", // 必选，货款支付凭证（文件地址）   `` "pickupPerson": "张三", // 必选，提货人   `` "pickupTel": "13800138000", // 必选，提货人电话   `` "operateUserId": 1920 // 必选，操作人ID（最终买方用户）   ``}` |
| 响应参数 | `{   `` "code": 200,   `` "message": "提货申请提交成功，待审核",   `` "data": {   `` "pickupApplyId": 2324,   `` "auditStatus": "PENDING_AUDIT"   `` }   ``}` |
| 特殊规则校验 | 1. 校验申请人是否为批次对应的最终端买方；2. 校验最终买方是否已完成货款支付；3. 参与批次的合同需均处于有效状态 |

### 模块4：货物代采
#### 4.1 核心接口：仓单挂牌代采结算接口
| **接口信息** | **详情** |
| --- | --- |
| 接口名称 | goodsProcurement/warehouseReceipt/settle |
| 请求方式 | POST |
| 接口描述 | 针对仓单挂牌且仓单所属方为国际贸易商的场景，完成保证金转货款、生成结算账单 |
| 请求参数（JSON） | `{   `` "mainContractId": 123461, // 必选，主合同ID   `` "warehouseReceiptId": 2526, // 必选，仓单ID   `` "settleAmount": 11000.00, // 必选，结算金额（保证金金额）   `` "isBatchDelivery": 1, // 必选，是否分批交付：1-是，0-否   `` "batchNo": "DELIVER_20250801001", // 可选，分批交付批次号（isBatchDelivery=1时必填）   `` "operateUserId": 1213 // 必选，操作人ID   ``}` |
| 响应参数 | `{   `` "code": 200,   `` "message": "代采结算成功",   `` "data": {   `` "settleId": 2728,   `` "sellerBillId": 2930, // 卖方程结算单ID   `` "overseasProcurerBillId": 3132, // 海外代采商结算单ID   `` "fundStatus": "TRANSFERRED" // 资金状态：已划转   `` }   ``}` |
| 特殊规则校验 | 1. 校验仓单所属方类型（warehouse_receipt_owner_type）是否为INTERNATIONAL_TRADER；2. 校验合同是否为仓单挂牌类型；3. 校验保证金金额是否足额 |

## 三、新增关联表结构
除主合同表扩展字段外，新增以下关联表存储各业务模块的详细记录，支撑流程追溯与数据关联：

### 3.1 合同转让记录表（t_contract_transfer_record）
| **字段名** | **数据类型** | **字段说明** | **主键/外键** |
| --- | --- | --- | --- |
| id | varchar(20) | 转让记录ID | 主键（自增） |
| main_contract_id | varchar(20) | 原主合同ID | 外键（关联t_main_contract.id） |
| new_contract_id | varchar(20) | 新转让合同ID | 外键（关联t_main_contract.id） |
| transferor_id | varchar(20) | 转让方ID | 外键（关联t_user.id） |
| transferee_id | varchar(20) | 受让方ID | 外键（关联t_user.id） |
| transfer_price | decimal(18,2) | 转让价格 | - |
| original_price | decimal(18,2) | 原合同价格 | - |
| profit_freeze_amount | decimal(18,2) | 冻结盈亏金额（转让价<原价时非空） | - |
| transfer_status | varchar(20) | 转让状态（同主合同transfer_status） | - |
| transfer_time | datetime | 转让完成时间 | - |
| operate_user_id | varchar(20) | 操作人ID | - |
| remark | varchar(500) | 备注 | - |

### 3.2 国内代采记录表（t_contract_procurement_record）
| **字段名** | **数据类型** | **字段说明** | **主键/外键** |
| --- | --- | --- | --- |
| id | varchar(20) | 代采记录ID | 主键（自增） |
| main_contract_id | varchar(20) | 原主合同ID | 外键（关联t_main_contract.id） |
| procurement_contract_id | varchar(20) | 代采方与买方的合同ID | 外键（关联t_main_contract.id） |
| buyer_id | varchar(20) | 买方ID（代采申请人） | 外键（关联t_user.id） |
| procurer_id | varchar(20) | 代采方ID | 外键（关联t_user.id） |
| original_price | decimal(18,2) | 原合同价格（代采方-卖方） | - |
| procurement_price | decimal(18,2) | 代采价格（买方-代采方） | - |
| procurement_status | varchar(20) | 代采状态（同主合同procurement_status） | - |
| apply_time | datetime | 申请时间 | - |
| confirm_time | datetime | 确认时间（确认后非空） | - |
| reject_reason | varchar(500) | 拒绝原因（拒绝时非空） | - |
| operate_user_id | varchar(20) | 操作人ID | - |

### 3.3 链式交收批次表（t_chain_settlement_batch）
| **字段名** | **数据类型** | **字段说明** | **主键/外键** |
| --- | --- | --- | --- |
| id | varchar(20) | 批次ID | 主键（自增） |
| batch_no | varchar(50) | 批次号（唯一） | - |
| final_buyer_id | varchar(20) | 最终端买方ID | 外键（关联t_user.id） |
| contract_count | int(11) | 参与合同数量 | - |
| batch_status | varchar(20) | 批次状态：INIT-初始化，PROCESSING-处理中，COMPLETED-完成，CANCEL-取消 | - |
| create_time | datetime | 创建时间 | - |
| remark | varchar(500) | 备注 | - |

### 3.4 链式交收合同关联表（t_chain_settlement_contract_rel）
| **字段名** | **数据类型** | **字段说明** | **主键/外键** |
| --- | --- | --- | --- |
| id | varchar(20) | 关联ID | 主键（自增） |
| batch_id | varchar(20) | 链式交收批次ID | 外键（关联t_chain_settlement_batch.id） |
| contract_id | varchar(20) | 参与合同ID | 外键（关联t_main_contract.id） |
| contract_type | varchar(20) | 合同类型：ORIGINAL-原合同，TRANSFER-转让合同，PROCUREMENT-代采合同 | - |

### 3.5 货物代采结算表（t_goods_procurement_settle）
| **字段名** | **数据类型** | **字段说明** | **主键/外键** |
| --- | --- | --- | --- |
| id | varchar(20) | 结算ID | 主键（自增） |
| main_contract_id | varchar(20) | 主合同ID | 外键（关联t_main_contract.id） |

| seller_id | varchar(20) | 卖方ID | 外键（关联t_user.id） |

| settle_amount | decimal(18,2) | 结算金额（保证金转货款金额） | - |
| is_batch_delivery | tinyint(1) | 是否分批交付 | - |
| batch_no | varchar(50) | 分批交付批次号 | - |
| fund_status | varchar(20) | 资金状态：PENDING-待划转，TRANSFERRING-划转中，TRANSFERRED-已划转，FAILED-划转失败 | - |
| seller_bill_id | varchar(20) | 卖方程结算单ID | 外键（关联t_bill.id） |
| overseas_bill_id | varchar(20) | 海外代采商结算单ID | 外键（关联t_bill.id） |
| settle_time | datetime | 结算时间 | - |

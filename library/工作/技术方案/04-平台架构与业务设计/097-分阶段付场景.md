# 分阶段付场景

在贸易合同管理系统中，付款、发货、收款、开票环节需严格遵循合同条款（如付款比例、交付时间、结算方式等），并通过系统实现流程自动化跟踪、凭证关联和风险监控。以下以**“国内大宗商品采购合同”**为例，说明具体业务流程：

## **场景背景**
某制造企业（买方）与供应商（卖方）签订采购合同：

+ 商品：100吨钢材，单价5000元/吨，总金额50万元。
+ 付款条款：预付款30%（15万元），发货前付50%（25万元），验收合格后付尾款20%（10万元）。
+ 交付条款：收到第二笔款项后3日内发货，买方收到货后7日内完成验收。
+ 开票条款：每笔付款后10日内，卖方开具对应金额的增值税专用发票。

## **一、付款环节（买方操作）**
**核心目标**：按合同约定向卖方支付款项，系统同步记录付款凭证，触发后续环节（如发货）。

1. **预付款支付**
    - 合同生效后，系统自动生成“预付款待支付”任务（关联合同条款“30%预付款”），推送给买方财务人员。
    - 财务人员核对合同，通过企业网银向卖方支付15万元，获取银行转账凭证（电子版）。
    - 在系统中上传转账凭证，标记“预付款已支付”，系统自动记录付款时间、金额、凭证编号，并关联至合同。
    - 系统触发通知：向卖方推送“预付款到账提醒”，同时更新履约节点状态为“预付款已完成”。
2. **发货前付款（第二笔）**
    - 卖方确认收到预付款后，准备发货前，系统根据合同条款“发货前付50%”，向买方财务推送“第二笔款项待支付”任务。
    - 买方财务支付25万元，上传转账凭证，系统标记“第二笔款已支付”，并触发“允许发货”信号（关联发货环节）。

## **二、发货环节（卖方操作）**
**核心目标**：卖方按约定发货，系统跟踪物流状态，同步至买方，作为后续验收和付款的依据。

1. **发货准备**
    - 卖方收到第二笔款项后，系统自动解锁“发货节点”，向卖方仓储/物流部门推送“待发货”任务，提示“3日内完成发货”。
    - 卖方安排物流，生成发货单（含合同号、商品规格、数量、物流单号），在系统中上传发货单，标记“已发货”。
2. **物流跟踪**
    - 系统对接物流平台（如顺丰、货拉拉），自动同步物流轨迹（如“已揽件”“在途”“即将送达”）。
    - 买方可在系统中实时查看物流状态，系统在“预计送达时间”前1天向买方采购部推送“到货提醒”。
3. **买方收货**
    - 买方收到钢材后，在系统中确认“已收货”，上传签收单（需注明数量是否相符、是否有破损）。

## **三、验收与尾款支付（买方操作）**
**核心目标**：买方确认商品合格后支付尾款，完成资金结算闭环。

1. **验收流程**
    - 买方收到货后，系统按合同“7日内验收”条款，向质检部门推送“待验收”任务。
    - 质检部门检测钢材质量，在系统中填写验收报告（如“合格”“不合格及整改要求”）：
        * 若合格：标记“验收通过”，系统自动触发“尾款待支付”任务（10万元）。
        * 若不合格：系统冻结尾款支付，向卖方推送“验收异议通知”，待双方协商（如补货、降价）后，通过“合同变更流程”更新验收结果。
2. **尾款支付**
    - 验收合格后，买方财务支付10万元尾款，上传转账凭证，系统标记“尾款已支付”，合同资金流全部完成。

## **四、开票环节（卖方操作）**
**核心目标**：卖方按付款金额开具发票，买方确认后归档，作为财务入账凭证。

1. **分批次开票**
    - 每笔付款完成后，系统按合同“10日内开票”条款，向卖方财务推送“待开票”任务：
        * 预付款到账后：需开具15万元发票。
        * 第二笔款到账后：需开具25万元发票。
        * 尾款到账后：需开具10万元发票。
2. **发票上传与确认**
    - 卖方开具增值税专用发票后，在系统中上传发票扫描件（含发票代码、金额、税额等信息），标记“已开票”。
    - 系统自动校验发票信息（如金额与付款记录是否一致），校验通过后推送给买方财务。
    - 买方财务核对发票无误后，在系统中确认“发票已接收”，并关联至对应付款记录，完成财务归档。
3. **异常处理**
    - 若发票金额与付款不符（如多开/少开），买方可在系统中发起“发票异议”，卖方重新开票后更新系统记录。

## **系统在流程中的核心作用**
1. **自动化触发**：按合同条款自动推送待办任务（如付款提醒、发货时限），减少人工干预。
2. **凭证关联**：付款凭证、发货单、验收报告、发票等全链路关联，支持一键追溯（如“查看某笔发票对应的付款记录”）。
3. **风险监控**：
    - 逾期预警：如卖方未在10日内开票，系统自动向卖方推送预警。
    - 逻辑校验：如买方未支付第二笔款却尝试确认“已发货”，系统拦截并提示“未满足发货条件”。
4. **数据沉淀**：所有环节数据汇总为“合同履约档案”，支持后续统计分析（如该供应商的平均发货时效、开票及时率）。

通过以上流程，贸易合同管理系统实现了“付款-发货-收款-开票”的全链路数字化管理，确保各环节按合同执行，降低履约风险，提升协同效率。

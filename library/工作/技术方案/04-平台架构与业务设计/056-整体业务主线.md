# 整体业务主线

下面给你一套**可直接落地的 B2B 大宗商品交易平台**架构设计，按你要求的 5 大中心：
**商品中心 + 订单中心 + 合同中心 + 支付中心 + 方案中心**
偏向大宗、挂牌摘牌、多客户差异化定价、参数化组合场景，结构清晰、可做 PRD / 架构图。

---

## 一、整体业务主线（大宗 B2B 版）
1. 客户在**方案中心**选/配置专属产品组合（参数+价格+交收）
2. 进入**商品中心**锁定具体货品、品级、仓单、质量指标
3. 平台挂牌/摘牌 → 生成**合同中心**电子交易合同
4. 根据合同发起**订单中心**执行单（交货/分批/补单）
5. **支付中心**完成保证金、货款、结算、开票

## 二、商品中心（大宗商品版）
### 核心定位
统一货品主数据，支撑挂牌、摘牌、合同、订单、仓单、质量溯源。

### 核心模块
1. **品类与品种管理**
    - 一级品类：能源/化工/金属/农产品/建材等
    - 品种：螺纹钢、煤炭、原油、PVC、玉米等
    - 计量单位：吨、立方米、桶、件
    - 计价货币：CNY/USD
2. **货品属性与质量标准**
    - 固定属性：品级、规格、牌号、产地、品牌
    - 质检指标：含水率、硫含量、强度、粘度等
    - 质量异议条款、检验机构
3. **SKU 与批次管理（大宗不叫 SKU，叫**批次/仓单**）**
    - 仓单号、库存位置、仓库、垛位
    - 生产日期、入库日期、有效期
    - 可用数量、锁定数量、在途数量
4. **价格体系**
    - 基准价、挂牌价、成交价
    - 升贴水：品级/区域/物流/付款方式
    - 汇率、税费、仓储费、物流费
5. **库存与仓单中心**
    - 可挂牌库存
    - 仓单质押、冻结、解押
    - 交收仓库管理

### 对外能力
+ 提供货品信息、库存、价格查询
+ 支撑挂牌时快速选择货品

---

## 三、方案中心（客户专属参数组合）
### 核心定位
B2B 关键差异化能力：**按客户/行业/合同给出定制化参数组合包**
解决：不同客户不同参数、不同价格、不同交收方式、不同账期。

### 核心模块
1. **客户分层体系**
    - 客户等级：VIP/战略/普通/临时
    - 行业：钢厂、电厂、贸易商、加工厂
    - 信用等级、账期额度、保证金比例
2. **参数组合模板（方案）**
一个方案 = 一组可售卖的“配置包”
    - 允许货品范围（哪些品种可买）
    - 参数约束：品级范围、最小起订量、最大采购量
    - 价格策略：基准价+升贴水、协议价、一口价
    - 交收方式：库内自提、配送、厂发、港口交收
    - 物流方案：线路、承运商、运费承担方
    - 付款方案：现款、账期、分批付款、票据
    - 质量允许偏差、复检规则
3. **方案绑定关系**
    - 客户 ↔ 方案（一对一/一对多）
    - 方案 ↔ 合同（框架协议绑定方案）
    - 方案 ↔ 商品（限定可选购货品）
4. **版本与有效期**
    - 方案版本管理
    - 生效/失效时间
    - 调价记录

### 业务场景
+ 挂牌时自动带出该客户允许的参数
+ 摘牌时校验是否在方案允许范围内
+ 生成合同时自动带入方案条款

---

## 四、合同中心（大宗挂牌摘牌核心）
### 核心定位
**唯一法律生效文件**，所有订单、支付、交收都必须依附合同。

### 合同类型
1. **框架协议（主合同）**
    - 合作期限、年度量、定价机制、账期、违约
    - 绑定客户方案
2. **电子交易合同（摘牌即生成）**
来源：挂牌 + 摘牌
必备条款：
    - 品种、批次、仓单、质量
    - 数量、单价、总价
    - 交收时间、地点、方式
    - 付款方式、保证金
    - 违约责任、争议解决
    - 质量标准、检验方式
3. **补充协议**
    - 延期交收、数量变更、价格调整

### 核心能力
+ 摘牌自动生成电子合同
+ 合同状态：待履约 / 履约中 / 部分交收 / 完成 / 违约
+ 合同与订单一对多（分批交货）
+ 合同与支付一对多（多次付款）
+ 合同与发票一对多

### 关键规则
+ 无合同不允许创建执行订单
+ 挂牌摘牌成交 = 合同成立
+ 合同不可随意撤销，需双方同意或平台裁决

---

## 五、订单中心（执行层，非法律层）
### 核心定位
**合同的执行单据**，用于内部发货、物流、仓储、质检、签收。

### 订单类型
1. **主订单**：对应合同整单
2. **交货单/分批订单**：合同拆单多次交货
3. **补单**：数量补差、重量补差
4. **退货/换货单**：质量异议处理

### 订单结构
+ 关联合同 ID
+ 关联商品/批次/仓单
+ 实际发货数量、磅单数量
+ 物流信息、司机、车辆、运输单
+ 收货确认、质检结果
+ 入库签收单

### 订单状态
待发货 → 已发货 → 在途 → 已签收 → 已质检 → 完成

### 与合同关系
+ 合同：1 对 N 订单
+ 订单不能脱离合同存在

---

## 六、支付中心（大宗贸易版）
### 核心定位
保证金、货款、结算、票据、退款、对账。

### 核心模块
1. **保证金账户**
    - 交易前冻结保证金
    - 违约扣除、履约释放
2. **货款支付**
    - 线上支付、银企直连
    - 信用证、保理、票据支付
    - 分批支付、预付/尾款
3. **结算中心**
    - 合同结算、订单结算
    - 实际磅单与合同数量补差
    - 仓储费、物流费、手续费自动计算
4. **发票管理**
    - 开票抬头、税号
    - 专票/普票、开票金额
    - 发票与合同/订单关联
5. **风控规则**
    - 客户可用额度
    - 账期控制
    - 欠款预警、冻结交易

---

## 七、五中心数据流（最关键）
1. **方案中心** → 给客户限定可买商品、参数、价格
2. **商品中心** → 提供可交易货品与库存
3. 挂牌 + 摘牌 → **合同中心**生成电子合同
4. **合同中心** → 推单到**订单中心**生成执行单
5. **订单中心** 履约完成 → **支付中心**结算开票

一句话关系：
**方案管准入，商品管货，合同管法律，订单管执行，支付管钱。**

---

## 八、可直接用于 PRD 的核心用例
1. 客户登录 → 加载专属方案
2. 查看商品与可挂牌库存
3. 摘牌成交 → 自动生成电子合同
4. 系统创建交货订单
5. 支付保证金 → 发货 → 签收 → 结算尾款 → 开票

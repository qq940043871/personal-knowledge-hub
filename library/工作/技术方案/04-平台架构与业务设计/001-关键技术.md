## 技术创新点
+ 区块链技术应用：
+ 弱中心的可信计算（异构多活、高可用）
+ 数据完整性、一致性、透明、可追溯、可审计
+ 金融级加密安全性（不可逆、不可篡改）
+ 基于智能合约的个性化服务
+ 大数据技术应用
+ 票据验证、定时抓取票据信息数据、实时对上传到平台的票据进行验真、保证票据的真实性
+ 大数据融资、反欺诈、用户画像、精准定位客户
+ 移动互联网技术
+ SDK与API
+ 移动支付
+ 中登网技术对接
+ 手机盾、CA等技术对接
+ 采用生物识别、电子签章的办法、保证交易的真实性和不可抵赖性
+ 人工智能技术应用：
+ 弱人工智能的应用、智能客户、远程身份验证、智能化运维
+ 云计算技术
+ Saas平台
+ 法院老赖信息的对接和智能识别
+ 采用开发工具链、代码自动生成、加快开发效率
+ 部署简单、部分程序docker化部署、提高运维效率
+ 代码模块化

## 技术路线
+ 设计原理
+ 采用微服务的设计思想、实现异构多活、根据不同服务的特点、实现不同的需求、如资金系统需要高可用和高可靠、灵活增加服务器等。
+ 技术要点
+ 部分应用docker化、实现方便部署和运维
+ 基础服务
+ Kafka消息队列
+ Zookeeper服务发现
+ ethereum以太坊区块链
+ 自主研发datashare实现kafka和zookpeeper的聚集、方便开发
+ 自主研发midserver实现H5和后台服务的架构分层、保证后端服务的安全性
+ 图像识别技术进行发票验真
+ 人脸识别技术实现客户线上远程开户
+ 手机盾、CA实现线上PDF生成和线上签章
+ 后端IO型程序、采用多线程的方式进行处理
+ 基于socket的微服务架构
+ 基于layui、Echarts的前端技术展示
+ zdcore核心jar包、实现对于请求数据的校验和返回结果封装
+ H5采用websocket与midserver进行通信
+ 采用多种加密算法DES和AES
+ 第三方平台对接提供简单API封装和和数据链路的安全保证

# 低代码开发思路

1. 原工程中存在的业务组件进行梳理，同时进行文件扫描解析；生成物料列表（组件映射关系）
2. 首页装修只实现组件之间的布局关系（应用包含的页面）
3. 页面装修需要定义的数据结构（样式，属性，路由）--暂时不需要
4. 物料扩展是否处理组件的样式和数据来源（应用级别数据源）
5. 参考阿里的低代码引擎+阿里AntV+X6引擎完成流程设计（需要对业务代码进行重构）
6. 报表设计考虑引用积木报表
7. 表单设计使用Vform
8. 页面装修采用AntV+X6引擎 （需要对业务组件进行梳理，业务组件是否需要定义绑定的数据，方便装修时查看）；业务组件进行分类处理，规划好目录，根据页面的schema进行页面渲染
9. 阿里AntV是个好东西

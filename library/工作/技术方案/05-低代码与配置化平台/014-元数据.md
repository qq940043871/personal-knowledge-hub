# 元数据统一组件方案

好的！以下是一个**轻量级、可落地的元数据统一组件方案草案**，专为「多端动态页面搭建」场景设计，兼顾**前端工程化规范**（适配你作为高级前端工程师的技术栈），支持 Web（Vue 3）为主、可扩展至小程序（Taro/uni-app）的运行时架构。

---

## 🧩 一、核心设计原则
| 原则 | 说明 |
| --- | --- |
| **Schema 与运行时解耦** | 元数据不绑定具体实现，仅描述“是什么” |
| **渐进式扩展** | 基础能力最小化，通过 `plugins` 扩展高级功能（如动画、联动） |
| **Type 优先** | 全链路 TypeScript 支持，提升可维护性与协作效率 |
| **渲染性能可控** | 支持懒加载、虚拟滚动、组件级 memo |

## 📄 二、元数据 Schema 设计（精简版）
```typescript
// types/schema.ts
export type ComponentName = 'Text' | 'Image' | 'Button' | 'Container' | 'Grid' | string;

export interface ComponentProps {
  [key: string]: any; // 具体组件定义自己的 props interface（通过 zod/ajv 校验）
}

export interface ComponentNode {
  id: string;               // 唯一 ID，用于 diff/update
  type: ComponentName;      // 组件类型
  props?: ComponentProps;   // 属性（响应式绑定支持）
  children?: ComponentNode[]; // 子节点（仅容器类组件有）
  // ↓ 可选扩展 ↓
  condition?: string;       // 表达式：如 "user.vipLevel > 2"
  events?: Record<string, string>; // 事件映射：{ "click": "handleClick" }
  style?: Record<string, string | number>;
}

export interface PageSchema {
  version: '1.0';
  root: ComponentNode;      // 根节点（通常为 Container）
  global?: {
    data?: Record<string, any>;     // 全局初始 data（如 API 返回的变量）
    methods?: Record<string, string>; // 方法体字符串（沙箱执行 or 注册名）
  };
}
```

> ✅ 示例：
>

```json
{
  "version": "1.0",
  "root": {
    "id": "c1",
    "type": "Container",
    "props": { "padding": "16px" },
    "children": [
      {
        "id": "c2",
        "type": "Text",
        "props": { "content": "{{ title }}" },
        "style": { "fontSize": "18px", "color": "#333" }
      }
    ]
  },
  "global": {
    "data": { "title": "欢迎光临" }
  }
}
```

## ⚙️ 三、Web 端运行时实现（Vue 3 + Composition API）
### 1️⃣ 核心渲染器：`DynamicRenderer.vue`
```vue
<!-- components/DynamicRenderer.vue -->
<template>
  <component
    :is="resolveComponent(node.type)"
    v-bind="mergedProps"
    :style="mergedStyle"
    v-on="eventHandlers"
  >
    <template v-for="child in node.children" :key="child.id">
      <DynamicRenderer :node="child" :context="context" />
    </template>
  </component>
</template>
<script setup lang="ts">
import { computed, inject } from 'vue';
import type { ComponentNode, ComponentProps } from '@/types/schema';
import { RendererContextKey } from '@/symbols';

interface Props {
  node: ComponentNode;
  context?: Record<string, any>;
}

const props = defineProps<Props>();

// 从上下文注入（支持嵌套数据流）
const globalContext = inject(RendererContextKey, {});

// 合并 props：支持 {{ expr }} 插值 & 函数式 props
const mergedProps = computed<ComponentProps>(() => {
  const ctx = { ...globalContext, ...props.context };
  return Object.entries(props.node.props || {}).reduce((acc, [key, val]) => {
    acc[key] = typeof val === 'string' && val.startsWith('{{') && val.endsWith('}}')
      ? evalExpression(val.slice(2, -2), ctx) // ⚠️ 生产需用 safe-eval/expr-eval
      : val;
    return acc;
  }, {} as ComponentProps);
});

// 合并样式
const mergedStyle = computed(() => ({
  ...props.node.style,
}));

// 绑定事件（映射为方法调用）
const eventHandlers = computed(() => {
  const handlers: Record<string, Function> = {};
  for (const [event, methodRef] of Object.entries(props.node.events || {})) {
    if (globalContext.methods?.[methodRef]) {
      handlers[event] = (...args: any[]) => globalContext.methods![methodRef](...args);
    }
  }
  return handlers;
});

// 组件注册表（按需 import，支持 tree-shaking）
const componentMap = {
  Text: () => import('./components/Text.vue'),
  Image: () => import('./components/Image.vue'),
  Container: () => import('./components/Container.vue'),
  // ...
};

function resolveComponent(type: string) {
  return componentMap[type as keyof typeof componentMap] || 'div';
}

// 简易表达式求值（生产建议用 expr-eval）
function evalExpression(expr: string, ctx: Record<string, any>): any {
  try {
    // eslint-disable-next-line no-new-func
    return new Function(...Object.keys(ctx), `return (${expr})`)(...Object.values(ctx));
  } catch {
    return expr; // fallback
  }
}
</script>

```

### 2️⃣ 上下文注入：`RendererProvider.vue`
```vue
<!-- components/RendererProvider.vue -->
<script setup lang="ts">
import { provide, reactive } from 'vue';
import type { PageSchema } from '@/types/schema';
import { RendererContextKey } from '@/symbols';

const props = defineProps<{ schema: PageSchema }>();

const context = reactive({
  data: props.schema.global?.data || {},
  methods: props.schema.global?.methods 
    ? Object.fromEntries(
        Object.entries(props.schema.global.methods).map(([name, body]) => [
          name,
          // 方法注册：支持字符串体 or 预注册函数名
          typeof body === 'string'
            ? new Function('context', `return ${body}`)(context)
            : body,
        ])
      )
    : {},
});

provide(RendererContextKey, context);
</script>
<template>
  <DynamicRenderer :node="schema.root" />
</template>

```


## 🔄 四、多端扩展思路
| 端 | 扩展方式 | 关键点 |
| --- | --- | --- |
| **小程序（Taro）** | 复用 `DynamicRenderer` 逻辑层，UI 层重写为 Taro 组件 | • 使用 `@tarojs/components` 映射   • `v-if` → `wx:if` 编译时转换   • 事件名转驼峰（`onClick` → `bindtap`） |
| **React Native** | 提供 `ReactDynamicRenderer`，用 `React.createElement` | • Props 类型对齐   • Style 转换：`{ fontSize: 18 }` → `{ fontSize: 18 }`（RN 兼容） |
| **Server Render (SSR)** | 在 Node 端预渲染为 HTML 字符串 | • 屏蔽浏览器 API   • 异步组件 fallback |

> 🔧 工程建议：用 `@/platforms/web/renderer.ts`、`@/platforms/taro/renderer.ts` 实现平台适配层，统一入口由构建工具（Vite plugin / Webpack alias）切换。

## 📦 五、进阶优化方向（按需开启）
| 方向 | 方案 |
| --- | --- |
| **Schema 校验** | 用 [Zod](https://zod.dev/) 定义强类型 Schema，构建时校验 |
| **表达式安全** | 替换 `new Function` 为 [expr-eval](https://github.com/soney/expr-eval) + 白名单函数 |
| **性能优化** | + `node.id` 作为 `key`，提升 diff 效率 + 组件级 `memo`（Vue `v-memo` / React `memo`） + 图片懒加载指令 |
| **调试支持** | 开发时注入 `devtools`：点击组件高亮对应 schema 节点 |

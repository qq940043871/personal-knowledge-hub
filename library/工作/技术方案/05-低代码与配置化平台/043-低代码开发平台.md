# 低代码开发平台

## 表单设计器
表单设计器实现思路：

1. 根据表结构获取基础的表单数据信息
2. 支持表单数据信息重新排列顺序
3. 支持表单中的元素定义事件内容
4. 支持表单中的元素自定义布局
5. 元素之间的级联关系，需要在表单设计器中增加代码编辑器，用于编写js代码处理关联
6. vue中根据后端返回的js代码动态创建watch，用于处理js代码关联
7. 参考阿里formily.js
8. vue.component根据后端代码动态创建组件

```json
{
  "template": "<div>后端返回的组件模板</div>",
  "script": "export default { data() { return {}; }, methods: {}; }",
  "style": "/* 后端返回的组件样式 */"
}
```

```javascript
// 模拟后端接口
fetchComponentCode().then(response => {
  const componentCode = response.json();
  Vue.component(componentCode.name, {
    template: componentCode.template,
    script: componentCode.script,
    style: componentCode.style
  });
});
```

9. vue.$watch根据后端代码动态创建watch

```javascript
// 在 Vue 实例创建后执行
created() {
  // 动态创建 watch 监听属性
  this.$watch(dynamicScript, (newValue, oldValue) => {
    // 处理关联逻辑
    console.log(`newValue: ${newValue}, oldValue: ${oldValue}`);
  });
}
```

## 流程设计器
流程设计器实现思路：

1. 需要支持业务流程编排，多业务节点可以自定义顺序，意味着需要把状态判断的节点处理成可配置的，不能硬编码
2. 节点需要配置是否生成资金、是否释放资金、是否发送站内信、短信，是否生成支付合同
3. 前端流程组件采用AntV
4. 后端Flowable+Flowableui+jsFlow
5. LogicFlow

流程引擎

1. 需要确保各函数的出参入参一致，消除各功能函数的差异性
2. 简单组件采用AntV
3. 后端liteFlow

业务系统改造思路

1. 业务流程节点定义
    1. 组织交收(申请交收-确认-付款-发货-收货-收款-开票-收票)
        1. 先货后款
        2. 先款后货
    2. 协议交收
    3. 自由交收
2. 业务流程节点编排liteflow
    1. 合同申请量控制
    2. 付款规则控制
3. 业务节点多层审批处理flowable
    1. 多级审批

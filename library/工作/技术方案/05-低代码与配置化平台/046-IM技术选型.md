# IM技术选型

## 乐天 IM
+ **功能**：可能具备基本的即时通讯功能，如单聊、群聊，视频聊天等。
    - 支持web端
+ **Vue 版本**：vue3。
+ **开源**：部分开源，商业授权。采用ruo-yi框架开发，t-io通讯框架。

## 盒子 IM
+ **功能**：
    - 支持私聊、群聊，能发送语音、图片、文件、emoji 表情等。
    - 聊天窗口有已读未读显示，群聊支持 @功能。
    - 支持音视频通话（基于 WebRTC 实现，但需要 SSL 证书）。
    - 支持移动端和 web 端同时在线，多端消息同步。
+ **Vue 版本**：vue2 。
+ **开源**：盒子 IM 是开源的，
    - 后端技术栈主要是 Spring Boot、MyBatis-Plus、Netty、MySQL
    - 前端使用 Vue、UniApp
    - Netty通讯框架

## 野火 IM
+ **功能**：
    - 提供能力库和 UI 库，支持单聊、群聊、聊天室、频道（类似微信的公众号）和机器人。
    - 支持 Server API，提供用户信息、好友关系和群组信息托管。
    - 支持常见消息类型和自定义消息。
    - 提供音视频通话能力，支持音视频会议功能，高级音视频功能强大，支持 9 人以上的群组视频通话，支持 1080p 视频，支持会议模式，支持百人以上会议，支持服务器端录制。
    - 全平台客户端，支持 Android、iOS、Web、小程序、UniApp、Flutter、Windows、macOS、Linux 等。
    - 四端同时在线（移动端，PC 端，Web 端和小程序端），数据和状态多端完美同步。
    - 支持国产化，支持国产化操作系统、芯片和国产操作系统，支持国密加密。
    - 拥有应用开放平台，可以开发和创建自建应用，扩展工作台。
    - API 丰富，方便与其他服务系统对接。
    - 拥有机器人和频道功能，免费的频道（公众号）管理后台。
    - 超级群组功能，可支持万人大群。
    - 支持多个 IM 服务组网互通，打破孤岛，适用于集团公司下多个分公司互联互通。
+ **Vue 版本**：有 Vue3。
+ **开源**：野火 IM 是开源的，提供完整的即时通讯和实时音视频解决方案，以及丰富的周边生态系统，代码开源率高，二次开发简单。

## OIM
+ **功能**：
    - 是一套即时通讯的聊天系统，包含服务端（java 语言开发，spring cloud 微服务架构）、网页版客户端、移动端（vue + ts 实现，可通过 Cordova 打包成安卓和 iOS）等。
    - 可用于公司内网、外网通讯、客服系统等。
+ **Vue 版本**：移动端使用 Vue2 进行开发。
+ **开源**：OIM 是开源的，采用 Apache-2.0 协议。

综上所述，从功能丰富度来看，

野火 IM 相对更为强大，提供了众多特色功能且支持全平台；

盒子 IM 功能也较为全面，在开源项目中表现突出；

OIM 则提供了较为完整的即时通讯系统解决方案，且移动端使用 Vue 开发。

在选择时，你可以根据项目需求、对功能的侧重点以及开发技术栈等因素进行综合考量。

如果对 Vue 版本有特定要求，盒子 IM 的前端和 OIM 的移动端都涉及 Vue 开发，

野火 IM 也有相关 Vue demo 可供参考。

同时，开源的特性使得这些项目在一定程度上可以根据自身需求进行定制和扩展。

建议选择**盒子IM**（开源，方便扩展，技术架构也符合，缺点是功能不够强大，页面表现的简单-基本开源的都很简单）

或者**采用自研IM**（目前的核心模块基本符合，可能需要简单调整，扩展功能缺少，需要逐步完善）。

## 八、阅读器与索引

### 8.1 三套互不共享代码的阅读器

| 阅读器 | 技术栈 | 入口 |
|--------|--------|------|
| 静态阅读器 | `marked` + `highlight.js`（CDN），读 `tree.json` | `index.html` |
| Flask 阅读器 | Flask 后端 + marked 前端 | `python app.py` → `python.html`，端口 5000 |
| 自包含站点 | 独立 `index.html` + `md-viewer.html?file=pages/...` | `技术/17年技术经验总结/09-技术知识库/index.html` |

共同限制：Markdown 被渲染进阅读器页面本身，没有 `<base>` 也没有链接重写，正文里的**相对图片/链接按阅读器页面所在目录解析**，不按 `.md` 所在目录——成品库因此多用内联 SVG。

### 8.2 tree.json 生成管线

- `build_tree.py` 扫描磁盘，只收录 `.md` / `.markdown` / `.pptx`，跳过隐藏目录、`__pycache__`/`node_modules` 等技术目录，以及被 `.gitignore` 忽略的目录（逐层 `git check-ignore --no-index`，结果缓存；git 不可用时退回 `FALLBACK_IGNORED_DIRS`）。
- 数据形态三层嵌套：`{库: [文件] | {子目录: [文件] | {子子目录: [文件]}}}`，目录直属文件放在 `_files` 键下；更深的层级折叠成 `父/子` 标签。
- `start.bat` 每次启动自动重建（写临时文件后 `os.replace` 原子替换）；手工重建：`python library/build_tree.py`。

### 8.3 `SKIP_DIRS` 滞后问题（2026-11-13 已修复）

此前 `build_tree.py` 手抄了一份写死在 `SKIP_DIRS` 里的私有目录名单，与 `.gitignore` 长期漂移：2026-11-13 解除排除的一批**已入 git 的公开目录**仍留在名单里，`tree.json` 只有 984 篇，约 674 篇公开文档在侧边栏看不到（`投资/02-交易心理与悟道`~`07-新手学习路线`、`工作/基础学习`/`技术方案`/`求职与面试`/`团队管理`、`考证/软考-架构师`/`软考-管理师`、`技术/从0到1设计计算机`）。同时存在名称漂移（名单里的 `微权力下的项目管理` 与磁盘 `微权力项目管理` 对不上）。

现在改为**唯一事实源**：`list_dirs()` 对每层候选目录批量执行 `git check-ignore --no-index -z --stdin`，命中的才剪掉，`SKIP_DIRS` 只保留与版本控制无关的技术目录。修复后 `tree.json` 收录 4 个公开库共 **1643 篇**；2026-11-13 清理 `工作/基础学习` 的 9 篇冗余文档后为 1634 篇；2026-11-15 迁入面试题库与快速学习手册后为 1729 篇；同日新增 4 篇企业级文章后为 1733 篇；同日第二批新增 4 篇（上下文工程、A2A与ANP、GRPO与AgenticRL、多推理引擎对比）后为 1737 篇；同日三线收敛清理 10-面试题库 18 篇重复旧版后为 **1719 篇**。只有 git 不可用时才退回 `FALLBACK_IGNORED_DIRS`（`家庭`/`隐私`/`01-我的实盘与成长史`/`客户跟踪`），因此新增私有目录必须同步根 `.gitignore` 与 `library/.gitignore`。

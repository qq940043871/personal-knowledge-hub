## 世界观速览

- **代码大陆（CodeLand）**：由数据流构成的世界。硬件是山川，操作系统是地脉，网络是江河，各大语言是城邦。
- **熵魔·混沌**：最终 BOSS。它没有形状——它就是"无序"本身：每一次线上事故、每一个内存泄漏、每一张坏账，都是它的分身。
- **Bug 魔王**：熵魔的头号爪牙，会随着主角的境界不断进化（空指针妖 → 死锁双子 → OOM 巨兽 → 缓存三头龙 → 脑裂魔王 → 熵之化身）。
- **老码**：神秘导师，游历大陆 17 年的老侠客，随身带着一本写了一半的《通关秘籍》。
- **境界体系**：见习码农 → 搬砖码农 → 联网码农 → Java 剑士 → 数据守护者 → 分布式棋手 → 造物者 → 云上将军 → AI 探险家 → 工程大师 → 架构圣者。

### 5.1.2 构建 RMSNorm

`RMSNorm`可以用如下的数学公式表示：

\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{n}\sum_{i=1}^{n}x_i^2 + \epsilon}} \cdot \gamma

其中：

- x_i 是输入向量的第 i 个元素
- \gamma 是可学习的缩放参数（对应代码中的 `self.weight`）
- n 是输入向量的维度数量
- \epsilon 是一个小常数，用于数值稳定性（以避免除以零的情况）

这种归一化有助于通过确保权重的规模不会变得过大或过小来稳定学习过程，这在具有许多层的深度学习模型中特别有用。

我们可以通过如下代码实现`RMSNorm`：

```
<code>class RMSNorm(nn.Module):<br/>    def __init__(self, dim: int, eps: float):<br/>        super().__init__()<br/>        # eps是为了防止除以0的情况<br/>        self.eps = eps<br/>        # weight是一个可学习的参数，全部初始化为1<br/>        self.weight = nn.Parameter(torch.ones(dim))<br/><br/>    def _norm(self, x):<br/>        # 计算RMSNorm的核心部分<br/>        # x.pow(2).mean(-1, keepdim=True)计算了输入x的平方的均值<br/>        # torch.rsqrt是平方根的倒数，这样就得到了RMSNorm的分母部分，再加上eps防止分母为0<br/>        # 最后乘以x，得到RMSNorm的结果<br/>        return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)<br/><br/>    def forward(self, x):<br/>        # forward函数是模型的前向传播<br/>        # 首先将输入x转为float类型，然后进行RMSNorm，最后再转回原来的数据类型<br/>        # 最后乘以weight，这是RMSNorm的一个可学习的缩放因子<br/>        output = self._norm(x.float()).type_as(x)<br/>        return output * self.weight</code>
```

#### 5.1.3.1 repeat_kv

在 LLaMA2 模型中，我们需要将键和值的维度扩展到和查询的维度一样，这样才能进行注意力计算。我们可以通过如下代码实现`repeat_kv`：

```
<code>def repeat_kv(x: torch.Tensor, n_rep: int) -&gt; torch.Tensor:<br/>    # 获取输入张量的形状：批量大小、序列长度、键/值对头的数量、每个头的维度大小<br/>    bs, slen, n_kv_heads, head_dim = x.shape<br/>    <br/>    # 如果重复次数为1，则不需要重复，直接返回原始张量<br/>    if n_rep == 1:<br/>        return x<br/>    <br/>    # 对张量进行扩展和重塑操作以重复键值对<br/>    return (<br/>        x[:, :, :, None, :]  # 在第四个维度（头的维度前）添加一个新的维度<br/>        .expand(bs, slen, n_kv_heads, n_rep, head_dim)  # 将新添加的维度扩展到n_rep大小，实现重复的效果<br/>        .reshape(bs, slen, n_kv_heads * n_rep, head_dim)  # 重新塑形，合并键/值对头的数量和重复次数的维度<br/>    )</code>
```

在上述代码中：

- 首先，获取输入张量的形状：首先，代码通过 x.shape 获取输入张量的形状，包括批量大小（bs）、序列长度（slen）、键/值对头的数量（n_kv_heads）以及每个头的维度大小（head_dim）。
- 然后，检查重复次数：接着，代码检查重复次数 n_rep 是否为1。如果是1，则说明不需要对键和值进行重复，直接返回原始张量 x。
- 最后，扩展和重塑张量：在第三个维度（即键/值对头的维度）之后添加一个新的维度，形成 `x[:, :, :, None, :]`。
- 使用 `expand` 方法将新添加的维度扩展到 `n_rep` 大小，实现键/值对的重复效果。
- 最后，通过 reshape 方法重新塑形，将扩展后的维度合并回键/值对头的数量中，即 `x.reshape(bs, slen, n_kv_heads * n_rep, head_dim)`，这样最终的张量形状就达到了与查询维度一致的效果。

#### 5.1.3.2 旋转嵌入

接着我们来实现旋转嵌入，旋转嵌入是 LLaMA2 模型中的一个重要组件，它可以为注意力机制提供更强的上下文信息，从而提高模型的性能。

首先，我们要构造获得旋转嵌入的实部和虚部的函数：

```
<code># 注意：此处的dim应为 dim//n_head，因为我们是对每个head进行旋转嵌入<br/>def precompute_freqs_cis(dim: int, end: int, theta: float = 10000.0):<br/>    # torch.arange(0, dim, 2)[: (dim // 2)].float()生成了一个从0开始，步长为2的序列，长度为dim的一半<br/>    # 然后每个元素除以dim，再取theta的倒数，得到频率<br/>    freqs = 1.0 / (theta ** (torch.arange(0, dim, 2)[: (dim // 2)].float() / dim))<br/>    # 生成一个从0到end的序列，长度为end<br/>    t = torch.arange(end, device=freqs.device)<br/>    # 计算外积，得到一个二维矩阵，每一行是t的元素乘以freqs的元素<br/>    freqs = torch.outer(t, freqs).float()<br/>    # 计算频率的余弦值，得到实部<br/>    freqs_cos = torch.cos(freqs)<br/>    # 计算频率的正弦值，得到虚部<br/>    freqs_sin = torch.sin(freqs)<br/>    return freqs_cos, freqs_sin</code>
```

- 计算频率序列：`torch.arange(0, dim, 2)[: (dim // 2)].float()` 生成了一个从0开始，步长为2的序列，其长度为`dim`的一半。
- 每个元素除以`dim`后取`theta`的倒数，得到一个频率序列 `freqs`。这一步是为了生成适合旋转嵌入的频率。
- 生成时间序列：`t = torch.arange(end, device=freqs.device)` 生成一个从`0`到`end`的序列，长度为`end`。`end`通常是序列的最大长度。
- 计算频率的外积`freqs = torch.outer(t, freqs).float()` 计算时间序列 `t` 和频率序列 `freqs` 的外积，得到一个二维矩阵 `freqs`。每一行是时间序列 `t` 的元素乘以频率序列 `freqs` 的元素。
- 计算实部和虚部`freqs_cos = torch.cos(freqs)` 计算频率矩阵 `freqs` 的余弦值，得到旋转嵌入的实部。
- `freqs_sin = torch.sin(freqs)` 计算频率矩阵 `freqs` 的正弦值，得到旋转嵌入的虚部。

最终，该函数返回两个矩阵 `freqs_cos` 和 `freqs_sin`，分别表示旋转嵌入的实部和虚部，用于后续的计算。

接着，我们来构造调整张量形状的`reshape_for_broadcast`函数，这个函数的主要目的是调整 `freqs_cis` 的形状，使其在进行广播操作时与 `x` 的维度对齐，从而能够进行正确的张量运算。

```
<code>def reshape_for_broadcast(freqs_cis: torch.Tensor, x: torch.Tensor):<br/>    # 获取x的维度数<br/>    ndim = x.ndim<br/>    <br/>    # 断言，确保1在x的维度范围内<br/>    assert 0 &lt;= 1 &lt; ndim<br/>    <br/>    # 断言，确保freqs_cis的形状与x的第二维和最后一维相同<br/>    assert freqs_cis.shape == (x.shape[1], x.shape[-1])<br/>    <br/>    # 构造一个新的形状，除了第二维和最后一维，其他维度都为1，这样做是为了能够将freqs_cis与x进行广播操作<br/>    shape = [d if i == 1 or i == ndim - 1 else 1 for i, d in enumerate(x.shape)]<br/>    <br/>    # 将freqs_cis调整为新的形状，并返回<br/>    return freqs_cis.view(shape)</code>
```

最后，我们可以通过如下代码实现旋转嵌入：

```
<code>def apply_rotary_emb(<br/>    xq: torch.Tensor,<br/>    xk: torch.Tensor,<br/>    freqs_cos: torch.Tensor,<br/>    freqs_sin: torch.Tensor<br/>) -&gt; Tuple[torch.Tensor, torch.Tensor]:<br/><br/>    # 将查询和键张量转换为浮点数，并重塑形状以分离实部和虚部<br/>    xq_r, xq_i = xq.float().reshape(xq.shape[:-1] + (-1, 2)).unbind(-1)<br/>    xk_r, xk_i = xk.float().reshape(xk.shape[:-1] + (-1, 2)).unbind(-1)<br/><br/>    # 重新塑形频率张量以进行广播<br/>    freqs_cos = reshape_for_broadcast(freqs_cos, xq_r)<br/>    freqs_sin = reshape_for_broadcast(freqs_sin, xq_r)<br/><br/>    # 应用旋转，分别计算旋转后的实部和虚部<br/>    xq_out_r = xq_r * freqs_cos - xq_i * freqs_sin<br/>    xq_out_i = xq_r * freqs_sin + xq_i * freqs_cos<br/>    xk_out_r = xk_r * freqs_cos - xk_i * freqs_sin<br/>    xk_out_i = xk_r * freqs_sin + xk_i * freqs_cos<br/><br/>    # 将最后两个维度合并，并还原为原始张量的形状<br/>    xq_out = torch.stack([xq_out_r, xq_out_i], dim=-1).flatten(3)<br/>    xk_out = torch.stack([xk_out_r, xk_out_i], dim=-1).flatten(3)<br/><br/>    return xq_out.type_as(xq), xk_out.type_as(xk)</code>
```

#### 5.1.3.3 组装 LLaMA2 Attention

在上面我们已经完成了旋转嵌入的实现，接下来我们就可以构建 LLaMA2 Attention 模块了。

```
<code>class Attention(nn.Module):<br/>    def __init__(self, args: ModelConfig):<br/>        super().__init__()<br/>        # 根据是否指定n_kv_heads，确定用于键（key）和值（value）的头的数量。<br/>        self.n_kv_heads = args.n_heads if args.n_kv_heads is None else args.n_kv_heads<br/>        # 确保总头数可以被键值头数整除。<br/>        assert args.n_heads % self.n_kv_heads == 0<br/><br/>        # 模型并行处理大小，默认为1。<br/>        model_parallel_size = 1<br/>        # 本地计算头数，等于总头数除以模型并行处理大小。<br/>        self.n_local_heads = args.n_heads // model_parallel_size<br/>        # 本地键值头数，等于键值头数除以模型并行处理大小。<br/>        self.n_local_kv_heads = self.n_kv_heads // model_parallel_size<br/>        # 重复次数，用于扩展键和值的尺寸。<br/>        self.n_rep = self.n_local_heads // self.n_local_kv_heads<br/>        # 每个头的维度，等于模型维度除以头的总数。<br/>        self.head_dim = args.dim // args.n_heads<br/><br/>        # 定义权重矩阵。<br/>        self.wq = nn.Linear(args.dim, args.n_heads * self.head_dim, bias=False)<br/>        self.wk = nn.Linear(args.dim, self.n_kv_heads * self.head_dim, bias=False)<br/>        self.wv = nn.Linear(args.dim, self.n_kv_heads * self.head_dim, bias=False)<br/>        # 输出权重矩阵。<br/>        self.wo = nn.Linear(args.n_heads * self.head_dim, args.dim, bias=False)<br/><br/>        # 定义dropout。<br/>        self.attn_dropout = nn.Dropout(args.dropout)<br/>        self.resid_dropout = nn.Dropout(args.dropout)<br/>        # 保存dropout概率。<br/>        self.dropout = args.dropout<br/><br/>        # 检查是否使用Flash Attention（需要PyTorch &gt;= 2.0）。<br/>        self.flash = hasattr(torch.nn.functional, 'scaled_dot_product_attention')<br/>        if not self.flash:<br/>            # 若不支持Flash Attention，则使用手动实现的注意力机制，并设置mask。<br/>            print("WARNING: using slow attention. Flash Attention requires PyTorch &gt;= 2.0")<br/>            # 创建一个上三角矩阵，用于遮蔽未来信息。<br/>            mask = torch.full((1, 1, args.max_seq_len, args.max_seq_len), float("-inf"))<br/>            mask = torch.triu(mask, diagonal=1)<br/>            # 注册为模型的缓冲区<br/>            self.register_buffer("mask", mask)<br/><br/>    def forward(self, x: torch.Tensor, freqs_cos: torch.Tensor, freqs_sin: torch.Tensor):<br/>        # 获取批次大小和序列长度，[batch_size, seq_len, dim]<br/>        bsz, seqlen, _ = x.shape<br/><br/>        # 计算查询（Q）、键（K）、值（V）。<br/>        xq, xk, xv = self.wq(x), self.wk(x), self.wv(x)<br/>        # 调整形状以适应头的维度。<br/>        xq = xq.view(bsz, seqlen, self.n_local_heads, self.head_dim)<br/>        xk = xk.view(bsz, seqlen, self.n_local_kv_heads, self.head_dim)<br/>        xv = xv.view(bsz, seqlen, self.n_local_kv_heads, self.head_dim)<br/><br/>        # 应用旋转位置嵌入（RoPE）。<br/>        xq, xk = apply_rotary_emb(xq, xk, freqs_cos, freqs_sin)<br/><br/>        # 对键和值进行扩展以适应重复次数。<br/>        xk = repeat_kv(xk, self.n_rep)<br/>        xv = repeat_kv(xv, self.n_rep)<br/><br/>        # 将头作为批次维度处理。<br/>        xq = xq.transpose(1, 2)<br/>        xk = xk.transpose(1, 2)<br/>        xv = xv.transpose(1, 2)<br/><br/>        # 根据是否支持Flash Attention，选择实现方式。<br/>        if self.flash:<br/>            # 使用Flash Attention。<br/>            output = torch.nn.functional.scaled_dot_product_attention(xq, xk, xv, attn_mask=None, dropout_p=self.dropout if self.training else 0.0, is_causal=True)<br/>        else:<br/>            # 使用手动实现的注意力机制。<br/>            scores = torch.matmul(xq, xk.transpose(2, 3)) / math.sqrt(self.head_dim)<br/>            assert hasattr(self, 'mask')<br/>            scores = scores + self.mask[:, :, :seqlen, :seqlen]<br/>            scores = F.softmax(scores.float(), dim=-1).type_as(xq)<br/>            scores = self.attn_dropout(scores)<br/>            output = torch.matmul(scores, xv)<br/><br/>        # 恢复时间维度并合并头。<br/>        output = output.transpose(1, 2).contiguous().view(bsz, seqlen, -1)<br/><br/>        # 最终投影回残差流。<br/>        output = self.wo(output)<br/>        output = self.resid_dropout(output)<br/>        return output</code>
```

### 5.1.4 构建 LLaMA2 MLP模块

相对于前面我们实现的LLaMA2 Attention模块，LLaMA2 MLP模块的实现要简单一些。我们可以通过如下代码实现`MLP`：

```
<code>class MLP(nn.Module):<br/>    def __init__(self, dim: int, hidden_dim: int, multiple_of: int, dropout: float):<br/>        super().__init__()<br/>        # 如果没有指定隐藏层的维度，我们将其设置为输入维度的4倍<br/>        # 然后将其减少到2/3，最后确保它是multiple_of的倍数<br/>        if hidden_dim is None:<br/>            hidden_dim = 4 * dim<br/>            hidden_dim = int(2 * hidden_dim / 3)<br/>            hidden_dim = multiple_of * ((hidden_dim + multiple_of - 1) // multiple_of)<br/>        # 定义第一层线性变换，从输入维度到隐藏维度<br/>        self.w1 = nn.Linear(dim, hidden_dim, bias=False)<br/>        # 定义第二层线性变换，从隐藏维度到输入维度<br/>        self.w2 = nn.Linear(hidden_dim, dim, bias=False)<br/>        # 定义第三层线性变换，从输入维度到隐藏维度<br/>        self.w3 = nn.Linear(dim, hidden_dim, bias=False)<br/>        # 定义dropout层，用于防止过拟合<br/>        self.dropout = nn.Dropout(dropout)<br/><br/>    def forward(self, x):<br/>        # 前向传播函数<br/>        # 首先，输入x通过第一层线性变换和SILU激活函数<br/>        # 然后，结果乘以输入x通过第三层线性变换的结果<br/>        # 最后，通过第二层线性变换和dropout层<br/>        return self.dropout(self.w2(F.silu(self.w1(x)) * self.w3(x)))</code>
```

我们着重观察一下`forward`函数的实现，首先，输入 `x` 通过第一层线性变换 `self.w1` 和 `SILU` 激活函数，然后，结果乘以输入 `x` 通过第三层线性变换 `self.w3` 的结果，最后，通过第二层线性变换 `self.w2` 和 `dropout` 层，得到最终输出。

### 5.1.5 LLaMA2 Decoder Layer

到这里，我们已经实现了`LLaMA2`模型的`Attention`模块和`MLP`模块，接下来我们就可以构建`LLaMA2`的`Decoder Layer`了。

```
<code>class DecoderLayer(nn.Module):<br/>    def __init__(self, layer_id: int, args: ModelConfig):<br/>        super().__init__()<br/>        # 定义多头注意力的头数<br/>        self.n_heads = args.n_heads<br/>        # 定义输入维度<br/>        self.dim = args.dim<br/>        # 定义每个头的维度，等于输入维度除以头数<br/>        self.head_dim = args.dim // args.n_heads<br/>        # 定义LLaMA2Attention对象，用于进行多头注意力计算<br/>        self.attention = Attention(args)<br/>        # 定义LLaMAMLP对象，用于进行前馈神经网络计算<br/>        self.feed_forward = MLP(<br/>            dim=args.dim,<br/>            hidden_dim=args.hidden_dim,<br/>            multiple_of=args.multiple_of,<br/>            dropout=args.dropout,<br/>        )<br/>        # 定义层的ID<br/>        self.layer_id = layer_id<br/>        # 定义注意力计算的归一化层<br/>        self.attention_norm = RMSNorm(args.dim, eps=args.norm_eps)<br/>        # 定义前馈神经网络计算的归一化层<br/>        self.ffn_norm = RMSNorm(args.dim, eps=args.norm_eps)<br/><br/>    def forward(self, x, freqs_cos, freqs_sin):<br/>        # 前向传播函数<br/>        # 首先，输入x经过注意力归一化层，然后进行注意力计算，结果与输入x相加得到h<br/>        # 然后，h经过前馈神经网络归一化层，然后进行前馈神经网络计算，结果与h相加得到输出<br/>        h = x + self.attention.forward(self.attention_norm(x), freqs_cos, freqs_sin)<br/>        out = h + self.feed_forward.forward(self.ffn_norm(h))<br/>        return out</code>
```

`DecoderLayer`就是把我们上面完成的`Attention`模块和`MLP`模块组合在一起，实现了一个完整的`Transformer`模块。

### 5.1.6 构建 LLaMA2 模型

好了，我们已经完了上述所有的模块的实现，接下来就是激动人心的时刻，我们可以构建`LLaMA2`模型了。，`LLaMA2`模型就是将`DecoderLayer`模块堆叠起来，构成一个完整的`Transformer`模型。

```
<code>class Transformer(PreTrainedModel):<br/>    config_class = ModelConfig  # 配置类<br/>    last_loss: Optional[torch.Tensor] # 记录最后一次计算的损失<br/><br/>    def __init__(self, args: ModelConfig = None):<br/>        super().__init__(args)<br/>        # 初始化模型参数<br/>        self.args = args<br/>        # 词汇表大小<br/>        self.vocab_size = args.vocab_size<br/>        # 层数<br/>        self.n_layers = args.n_layers<br/><br/>        # 词嵌入层<br/>        self.tok_embeddings = nn.Embedding(args.vocab_size, args.dim)<br/>        # 归一化层<br/>        self.norm = RMSNorm(args.dim, eps=args.norm_eps)<br/>        # 输出层<br/>        self.output = nn.Linear(args.dim, args.vocab_size, bias=False)<br/><br/>        # 将词嵌入层的权重与输出层的权重共享<br/>        self.tok_embeddings.weight = self.output.weight <br/><br/>        # 预计算相对位置嵌入的频率<br/>        freqs_cos, freqs_sin = precompute_freqs_cis(self.args.dim // self.args.n_heads, self.args.max_seq_len)<br/>        self.register_buffer("freqs_cos", freqs_cos, persistent=False)<br/>        self.register_buffer("freqs_sin", freqs_sin, persistent=False)<br/><br/>        # 初始化所有权重<br/>        self.apply(self._init_weights)<br/>        # 对残差投影进行特殊的缩放初始化<br/>        for pn, p in self.named_parameters():<br/>            if pn.endswith('w3.weight') or pn.endswith('wo.weight'):<br/>                torch.nn.init.normal_(p, mean=0.0, std=0.02/math.sqrt(2 * args.n_layers))<br/><br/>        # 初始化最后一次前向传播的损失属性<br/>        self.last_loss = None<br/>        self.OUT = CausalLMOutputWithPast()  # 输出容器<br/>        self._no_split_modules = [name for name, _ in self.named_modules()]  # 不分割的模块列表<br/><br/>    def _init_weights(self, module):<br/>        # 初始化权重的函数<br/>        if isinstance(module, nn.Linear):<br/>            torch.nn.init.normal_(module.weight, mean=0.0, std=0.02)<br/>            if module.bias is not None:<br/>                torch.nn.init.zeros_(module.bias)<br/>        elif isinstance(module, nn.Embedding):<br/>            torch.nn.init.normal_(module.weight, mean=0.0, std=0.02)<br/>    <br/>    def forward(self, tokens: torch.Tensor, targets: Optional[torch.Tensor] = None, **keyargs) -&gt; torch.Tensor:<br/>        """<br/>        - tokens: Optional[torch.Tensor], 输入 token 张量。<br/>        - targets: Optional[torch.Tensor], 目标 token 张量。<br/>        - kv_cache: bool, 是否使用键值缓存。<br/>        - keyargs: 其他关键字参数。<br/><br/>        - self.OUT: CausalLMOutputWithPast, 包含 logits 和损失。<br/>        """<br/><br/>        if 'input_ids' in keyargs:<br/>            tokens = keyargs['input_ids']<br/>        if 'attention_mask' in keyargs:<br/>            targets = keyargs['attention_mask']<br/><br/>        # 前向传播函数<br/>        _bsz, seqlen = tokens.shape<br/>        # 通过词嵌入层和Dropout层<br/>        h = self.tok_embeddings(tokens)<br/>        h = self.dropout(h)<br/>        # 获取相对位置嵌入的频率<br/>        freqs_cos = self.freqs_cos[:seqlen]<br/>        freqs_sin = self.freqs_sin[:seqlen]<br/><br/>        # 通过Decoder层<br/>        for layer in self.layers:<br/>            h = layer(h, freqs_cos, freqs_sin)<br/>        # 通过归一化层<br/>        h = self.norm(h)<br/><br/>        if targets is not None:<br/>            # 如果给定了目标，计算损失<br/>            logits = self.output(h)<br/>            self.last_loss = F.cross_entropy(logits.view(-1, logits.size(-1)), targets.view(-1), ignore_index=0, reduction='none')<br/>        else:<br/>            # 推理时的小优化：只对最后一个位置的输出进行前向传播<br/>            logits = self.output(h[:, [-1], :]) <br/>            self.last_loss = None<br/><br/>        # 设置输出<br/>        self.OUT.__setitem__('logits', logits)<br/>        self.OUT.__setitem__('last_loss', self.last_loss)<br/>        return self.OUT<br/><br/>    <br/>    @torch.inference_mode()<br/>    def generate(self, idx, stop_id=None, max_new_tokens=256, temperature=1.0, top_k=None):<br/>        """<br/>        给定输入序列 idx（形状为 (bz,seq_len) 的长整型张量），通过多次生成新 token 来完成序列。<br/>        在 model.eval() 模式下运行。效率较低的采样版本，没有使用键k/v cache。<br/>        """<br/>        index = idx.shape[1]<br/>        for _ in range(max_new_tokens):<br/>            # 如果序列上下文过长，截断它到最大长度<br/>            idx_cond = idx if idx.size(1) &lt;= self.args.max_seq_len else idx[:, -self.args.max_seq_len:]<br/>            <br/>            # 前向传播获取序列中最后一个位置的 logits<br/>            logits = self(idx_cond).logits<br/>            logits = logits[:, -1, :] # 只保留最后一个时间步的输出<br/>            <br/>            if temperature == 0.0:<br/>                # 选择最有可能的索引<br/>                _, idx_next = torch.topk(logits, k=1, dim=-1)<br/>            else:<br/>                # 缩放 logits 并应用 softmax<br/>                logits = logits / temperature<br/>                if top_k is not None:<br/>                    v, _ = torch.topk(logits, min(top_k, logits.size(-1)))<br/>                    logits[logits &lt; v[:, [-1]]] = -float('Inf')<br/>                probs = F.softmax(logits, dim=-1)<br/>                idx_next = torch.multinomial(probs, num_samples=1)<br/>            <br/><br/>            if idx_next == stop_id:<br/>                break<br/><br/>            # 将采样的索引添加到序列中并继续<br/>            idx = torch.cat((idx, idx_next), dim=1)<br/><br/>        return idx[:, index:] # 只返回生成的token</code>
```

## 5.2 训练 Tokenizer

在自然语言处理 (NLP) 中，Tokenizer 是一种将文本分解为较小单位（称为 token）的工具。这些 token 可以是词、子词、字符，甚至是特定的符号。Tokenization 是 NLP 中的第一步，直接影响后续处理和分析的效果。不同类型的 tokenizer 适用于不同的应用场景，以下是几种常见的 tokenizer 及其特点。

### 5.2.1 Word-based Tokenizer

**Word-based Tokenizer** 是最简单和直观的一种分词方法。它将文本按空格和标点符号分割成单词。这种方法的优点在于其简单和直接，易于实现，且与人类对语言的直觉相符。然而，它也存在一些明显的缺点，如无法处理未登录词（OOV，out-of-vocabulary）和罕见词，对复合词（如“New York”）或缩略词（如“don't”）的处理也不够精细。此外，Word-based Tokenizer 在处理不同语言时也会遇到挑战，因为一些语言（如中文、日文）没有显式的单词分隔符。

示例：

```
<code>Input: "Hello, world! There is Datawhale."<br/>Output: ["Hello", ",", "world", "!", "There", "is", "Datawhale", "."]</code>
```

在这个例子中，输入的句子被分割成一系列单词和标点符号，每个单词或标点符号都作为一个独立的 token。

### 5.2.2 Character-based Tokenizer

**Character-based Tokenizer** 将文本中的每个字符视为一个独立的 token。这种方法能非常精细地处理文本，适用于处理拼写错误、未登录词或新词。由于每个字符都是一个独立的 token，因此这种方法可以捕捉到非常细微的语言特征。这对于一些特定的应用场景，如生成式任务或需要处理大量未登录词的任务，特别有用。但是，这种方法也会导致 token 序列变得非常长，增加了模型的计算复杂度和训练时间。此外，字符级的分割可能会丢失一些词级别的语义信息，使得模型难以理解上下文。

示例：

```
<code>Input: "Hello"<br/>Output: ["H", "e", "l", "l", "o"]</code>
```

在这个例子中，单词“Hello”被分割成单个字符，每个字符作为一个独立的 token。这种方法能够处理任何语言和字符集，具有极大的灵活性。

### 5.2.3 Subword Tokenizer

**Subword Tokenizer** 介于词和字符之间，能够更好地平衡分词的细粒度和处理未登录词的能力。Subword Tokenizer 的关键思想是将文本分割成比单词更小的单位，但又比字符更大，这样既能处理未知词，又能保持一定的语义信息。常见的子词分词方法包括 BPE、WordPiece 和 Unigram。

#### （1）Byte Pair Encoding (BPE)

**BPE** 是一种基于统计方法，通过反复合并频率最高的字符或字符序列对来生成子词词典。这种方法的优点在于其简单和高效，能够有效地处理未知词和罕见词，同时保持较低的词典大小。BPE 的合并过程是自底向上的，逐步将频率最高的字符对合并成新的子词，直到达到预定的词典大小或不再有高频的字符对。

示例：

```
<code>Input: "lower"<br/>Output: ["low", "er"]<br/><br/>Input: "newest"<br/>Output: ["new", "est"]</code>
```

在这个例子中，单词“lower”被分割成子词“low”和“er”，而“newest”被分割成“new”和“est”。这种方法有效地处理了词干和词缀，保持了单词的基本语义结构。

#### （2）WordPiece

**WordPiece** 是另一种基于子词的分词方法，最初用于谷歌的 BERT 模型。与 BPE 类似，WordPiece 通过最大化子词序列的似然函数来生成词典，但在合并子词时更注重语言模型的优化。WordPiece 会优先选择能够最大化整体句子概率的子词，使得分词结果在语言模型中具有更高的概率。

示例：

```
<code>Input: "unhappiness"<br/>Output: ["un", "##happiness"]</code>
```

在这个例子中，单词“unhappiness”被分割成子词“un”和“##happiness”，其中“##”表示这是一个后缀子词。通过这种方式，WordPiece 能够更好地处理复合词和派生词，保留更多的语义信息。

#### （3）Unigram

**Unigram** 分词方法基于概率模型，通过选择具有最高概率的子词来分割文本。Unigram 词典是通过训练语言模型生成的，可以处理多种语言和不同类型的文本。Unigram 模型会为每个子词分配一个概率，然后根据这些概率进行最优分割。

示例：

```
<code>Input: "unhappiness"<br/>Output: ["un", "happiness"]<br/><br/>Input: "newest"<br/>Output: ["new", "est"]</code>
```

在这个例子中，单词“unhappiness”被分割成子词“un”和“happiness”，而“newest”被分割成“new”和“est”。这种方法通过概率模型有效地处理了子词分割，使得分割结果更符合语言使用习惯。

每种 Tokenizer 方法都有其特定的应用场景和优缺点，选择适合的 Tokenizer 对于自然语言处理任务的成功至关重要。

在以上代码和图5.3可以看出，`Pretrain Dataset` 主要是将 `text` 通过 `tokenizer` 转换成 `input_id`，然后将 `input_id` 拆分成 `X` 和 `Y`，其中 `X` 为 `input_id` 的前 n-1 个元素，`Y` 为 `input_id` 的后 n-1 `个元素。loss_mask` 主要是用来标记哪些位置需要计算损失，哪些位置不需要计算损失。

#### SFTDataset

`SFTDataset` 其实是一个多轮对话数据集，我们的目标是让模型学会如何进行多轮对话。在这个阶段我们的输入是上一轮的对话内容，输出是当前轮的对话内容。

```
<code>class SFTDataset(Dataset):<br/>    def __init__(self, data_path, tokenizer, max_length=512):<br/>        super().__init__()<br/>        self.data_path = data_path<br/>        self.tokenizer = tokenizer<br/>        self.max_length = max_length<br/>        self.padding = 0<br/>        with open(data_path, 'r', encoding='utf-8') as f:<br/>            self.data = f.readlines()<br/><br/>    def __len__(self):<br/>        return len(self.data)<br/><br/>    def generate_loss_mask(self, input_ids):<br/>        # 生成 loss mask, 0 表示不计算损失, 1 表示计算损失<br/>        mask = [0] * len(input_ids)<br/>        a_sequence = [3, 1074, 537, 500, 203]  # &lt;|im_start|&gt;assistant\n<br/>        a_length = len(a_sequence)<br/>        n = len(input_ids)<br/>        i = 0<br/>        <br/>        while i &lt;= n - a_length:<br/>            # 检查当前位置是否匹配目标子序列<br/>            match = True<br/>            for k in range(a_length):<br/>                if input_ids[i + k] != a_sequence[k]:<br/>                    match = False<br/>                    break<br/>            if match:<br/>                # 从子序列结束的位置开始查找第一个4, 4 为 &lt;|im_end|&gt; EOS id<br/>                j = None<br/>                for idx in range(i + a_length, n):<br/>                    if input_ids[idx] == 4:<br/>                        j = idx<br/>                        break<br/>                if j is not None:<br/>                    start = i + a_length<br/>                    end = j  # 结束位置设为j（包含4）<br/>                    # 标记区间为1（包括start到end）<br/>                    if start &lt;= end:<br/>                        for pos in range(start, end + 1):<br/>                            if pos &lt; ```
```

在 SFT 阶段，这里使用的是多轮对话数据集，所以就需要区分哪些位置需要计算损失，哪些位置不需要计算损失。在上面的代码中，我使用了一个 `generate_loss_mask` 函数来生成 `loss_mask`。这个函数主要是用来生成 `loss_mask`，其中 `loss_mask` 的生成规则是：当遇到 `|assistant\n` 时，就开始计算损失，直到遇到 `|` 为止。这样就可以保证我们的模型在 SFT 阶段只计算当前轮的对话内容，如图5.4所示。

可以看到，其实 SFT Dataset 和 Pretrain Dataset 的 `X` 和 `Y` 是一样的，只是在 SFT Dataset 中我们需要生成一个 `loss_mask` 来标记哪些位置需要计算损失，哪些位置不需要计算损失。 图中 `Input ids` 中的蓝色小方格就是AI的回答，所以是需要模型学习的地方。所以在 `loss_mask` 中，蓝色小方格对应的位置是黄色，其他位置是灰色。在代码 `loss_mask` 中的 1 对应的位置计算损失，0 对应的位置不计算损失。

### 5.3.4 预训练

在数据预处理完成后，我们就可以开始训练模型了。我们使用的模型是一个和LLama2结构一样的 Decoder only Transformer模型，使用Pytorch实现。相关代码在`code/k_model.py`文件中。此处不再赘述，源码中有详细的中文注释，且我们在之前的文章中也有详细的介绍。

在模型这一部分可以重点看一下生成式模型是如何实现生成token的，可以查看`k_model.py`文件中的`Transforerm`类中的`generate`方法。

```
<code>@torch.inference_mode()<br/>    def generate(self, idx, stop_id=None, max_new_tokens=256, temperature=1.0, top_k=None):<br/>        """<br/>        给定输入序列 idx（形状为 (bz,seq_len) 的长整型张量），通过多次生成新 token 来完成序列。<br/>        在 model.eval() 模式下运行。效率较低的采样版本，没有使用键k/v cache。<br/>        """<br/>        index = idx.shape[1]<br/>        for _ in range(max_new_tokens):<br/>            # 如果序列上下文过长，截断它到最大长度<br/>            idx_cond = idx if idx.size(1) &lt;= self.args.max_seq_len else idx[:, -self.args.max_seq_len:]<br/>            <br/>            # 前向传播获取序列中最后一个位置的 logits<br/>            logits = self(idx_cond).logits<br/>            logits = logits[:, -1, :] # 只保留最后一个时间步的输出<br/>            <br/>            if temperature == 0.0:<br/>                # 选择最有可能的索引<br/>                _, idx_next = torch.topk(logits, k=1, dim=-1)<br/>            else:<br/>                # 缩放 logits 并应用 softmax<br/>                logits = logits / temperature<br/>                if top_k is not None:<br/>                    v, _ = torch.topk(logits, min(top_k, logits.size(-1)))<br/>                    logits[logits &lt; v[:, [-1]]] = -float('Inf')<br/>                probs = F.softmax(logits, dim=-1)<br/>                idx_next = torch.multinomial(probs, num_samples=1)<br/>            <br/><br/>            if idx_next == stop_id:<br/>                break<br/><br/>            # 将采样的索引添加到序列中并继续<br/>            idx = torch.cat((idx, idx_next), dim=1)<br/><br/>        return idx[:, index:] # 只返回生成的token</code>
```

在 `generate` 方法中，我们首先获取序列中最后一个位置的 `logits`，然后基于这些 `logits` 生成新的 `token`。接着，生成的新 `token` 会被添加到序列中，模型随后会继续生成下一个 `token`。通过这种迭代过程，我们能够生成完整的文本。

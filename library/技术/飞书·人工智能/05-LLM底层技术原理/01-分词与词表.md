## 1. 为什么需要分词

神经网络无法直接处理文本字符串，必须将文本映射为离散的 token ID 序列。分词方案的核心权衡在于粒度的选择：

| 粒度 | 示例 | 特点 |
|-|-|-|
| **字符级** | u, n, h, a, p, p, i, n, e, s, s | 词表极小（\~256），序列极长 |
| **词级** | unhappiness | 序列短，但词表爆炸（百万级） |
| **子词级** | un + happiness | 折中方案：词表适中（32K\~100K） |

子词级分词是当前主流方案。**词表越大**，embedding 层参数越多，但每个 token 携带的信息更丰富；**词表越小**，参数效率更高，但序列变长，增加计算负担。

## 2. BPE (Byte Pair Encoding)

BPE 最初是数据压缩算法，由 Sennrich et al. (2016) 引入 NLP，成为 GPT 系列的标准分词方法。

**训练过程**（从字符开始，迭代合并最高频 pair）：

1. 将训练语料中所有单词拆分为字符序列
2. 统计所有相邻字符 pair 的出现频率
3. 将频率最高的 pair 合并为新 token，加入词表
4. 重复步骤 2-3，直到达到目标词表大小

**编码过程**（贪心匹配）：对输入文本按训练好的合并规则，从左到右依次应用，优先匹配最长的已知 token。

## 3. WordPiece

WordPiece 由 Google 提出，是 BERT 的标准分词方法。与 BPE 的核心区别在于**合并策略**：BPE 选择频率最高的 pair，而 WordPiece 选择使训练语料似然增益最大的 pair。

形式化地，对于候选合并 (a, b) → ab，WordPiece 选择最大化以下分数的 pair：

$$\text{score}(a, b) = \frac{\text{freq}(ab)}{\text{freq}(a) \times \text{freq}(b)}$$

这等价于选择互信息（PMI）最高的 pair。WordPiece 使用 **## 前缀**标记非词首子词，例如 "unrelated" 分词为 ["un", "##relat", "##ed"]。

## 4. SentencePiece / Unigram

SentencePiece (Kudo & Richardson, 2018) 是一个分词框架，核心方法是 **Unigram 语言模型**。与 BPE/WordPiece 的"自底向上合并"相反，Unigram 采用**自顶向下剪枝**：

1. 初始化一个足够大的候选词表
2. 用 EM 算法估计每个 token 的概率
3. 计算移除每个 token 后整体似然的损失
4. 移除损失最小的一批 token
5. 重复直到词表缩小到目标大小

SentencePiece 的关键创新是**直接处理原始文本**，不依赖预分词。它将空格视为普通字符，用特殊符号 ▁（U+2581）标记词首。LLaMA、T5、ALBERT 均采用 SentencePiece。

## 5. Byte-level BPE

GPT-2 引入了 **Byte-level BPE**，直接在 UTF-8 字节级别进行 BPE 合并。

**优势**：

- **天然支持任何语言和符号**：UTF-8 可以编码所有 Unicode 字符
- **完全消除 UNK token**：任何输入都可以被分解为字节序列
- **简化预处理**：不需要 Unicode 规范化等预处理步骤

GPT-4、LLaMA 3、Mistral 等现代模型均采用字节级 BPE。

## 6. 词表设计的影响

| 模型 | 分词方法 | 词表大小 | 备注 |
|-|-|-|-|
| BERT-base | WordPiece | 30,522 | ## 前缀标记 |
| GPT-2 | Byte-level BPE | 50,257 | 首次引入字节级 BPE |
| T5 | SentencePiece (Unigram) | 32,100 | 直接处理原始文本 |
| LLaMA | SentencePiece (BPE) | 32,000 | 字节级 BPE |
| GPT-4 | Byte-level BPE | 100,256 | cl100k_base 编码 |
| LLaMA 3 | Byte-level BPE | 128,256 | 大幅扩充多语言覆盖 |
| Qwen-2 | Byte-level BPE | 151,936 | 中英文优化词表 |

**词表大小与参数量的关系**：embedding 层参数 = 词表大小 × 隐藏维度。以隐藏维度 4096 为例，词表从 32K 扩大到 128K 时，embedding 参数从 1.34 亿增至 5.37 亿。

**中文分词的特殊挑战**：中文没有自然的词边界（无空格），且单个汉字在 UTF-8 中占 3 字节。在以英文为主训练的词表中，中文字符往往需要更多 token 来表示相同信息量。

**多语言词表的平衡**：常见策略包括按语料比例采样合并、对低资源语言过采样、或像 LLaMA 3 那样直接大幅扩充词表至 128K。

## 7. 关键论文

1. **Sennrich et al. (2016)** — *Neural Machine Translation of Rare Words with Subword Units*。首次将 BPE 引入 NLP。
2. **Kudo (2018)** — *Subword Regularization*。提出 Unigram 语言模型方法。
3. **Kudo & Richardson (2018)** — *SentencePiece*。SentencePiece 工具的系统论文。
4. **Radford et al. (2019)** — *Language Models are Unsupervised Multitask Learners*（GPT-2）。引入 Byte-level BPE。
5. **Wu et al. (2016)** — *Google's Neural Machine Translation System*。WordPiece 在大规模 NMT 中的应用。

## 1. 为什么需要位置编码

Self-Attention 的计算方式为：给定查询矩阵 Q、键矩阵 K 和值矩阵 V，注意力输出为 softmax(QK^T / √d_k) · V。这一计算过程对输入 token 的排列顺序完全不敏感——将序列中 token 任意重排，只要 Q、K、V 的对应关系不变，输出也仅做相应重排，单个 token 的表示不变。

这意味着，如果不引入位置信息，模型无法区分"猫追狗"和"狗追猫"这两句话。两者包含完全相同的 token 集合，仅顺序不同，但语义截然相反。**位置编码正是为了解决这一根本性缺陷而设计的。**

## 2. 绝对位置编码

### 2.1 正弦位置编码 (Sinusoidal)

原始 Transformer 论文（Vaswani et al., 2017）提出了基于正弦和余弦函数的固定位置编码。对于位置 pos 和维度索引 i，编码定义为：

PE(pos, 2i) = sin(pos / 10000^(2i/d_model))

PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

其中 d_model 为模型隐藏维度，pos 为 token 在序列中的绝对位置。每一维度对应一个不同频率的正弦波：低维度频率较高（变化快），高维度频率较低（变化慢）。这种多频率设计使得模型可以从"精细局部位置"到"粗略全局位置"多个粒度感知 token 的所在。

**为什么用不同频率？**类比二进制编码的低位和高位——低位变化快，编码细粒度差异；高位变化慢，编码粗粒度差异。正弦位置编码通过不同频率的连续函数实现了类似效果，且具有平滑性和有界性。

**外推能力：**理论上正弦编码可以外推到训练时未见过的更长位置，因为函数定义域是连续的。但实际上，模型从未在这些位置上训练过，外推效果有限，性能会显著下降。

### 2.2 可学习位置编码 (Learned Positional Embedding)

GPT 系列（GPT-1/2/3）和 BERT 采用了可学习的位置编码：初始化一个位置嵌入矩阵 P ∈ R^(L×d)，其中 L 为最大序列长度，每一行对应一个绝对位置的嵌入向量，在训练过程中通过反向传播学习。

**优点：**灵活性强，模型可以自适应地学习最优的位置表示。

**缺点：**(1) 无法外推到超过最大长度 L 的位置，因为没有对应的学习参数；(2) 参数量随最大长度线性增长；(3) 不同位置之间的关系完全依赖模型隐式学习，缺乏显式的结构化先验。

## 3. 相对位置编码

相对位置编码的核心直觉是：在自然语言中，token 之间的**相对距离**往往比**绝对位置**更重要。例如，"主语在谓语之前"这一规律与句子在文档中的绝对位置无关，只与两者的相对顺序有关。

Transformer-XL（Dai et al., 2019）提出了一种经典的相对位置编码方案。它将注意力 logits 从原始的 q_i · k_j 拆解为四项：

q_i · k_j = q_i · (k_j + r\_{i-j}) = q_i^T · E_w · x_j + q_i^T · E_r · R\_{i-j} + u^T · (E_w · x_j) + v^T · R\_{i-j}

其中 R\_{i-j} 是基于相对距离 i-j 的正弦编码，E_r 和 u、v 是可学习参数。这一分解将内容相关项和位置相关项显式分离，使模型能够更高效地利用相对位置信息。

## 4. RoPE (旋转位置编码)

### 核心思想

RoPE（Rotary Position Embedding, Su et al., 2021）是当前主流大语言模型最广泛采用的位置编码方案。其核心思想是：通过旋转矩阵将位置信息注入到 query 和 key 向量中，使得注意力内积自然地只依赖于相对位置。

### 公式推导

对于 d 维向量，RoPE 将其视为 d/2 个二维子空间。在位置 m 处，向量 q 的编码方式为：

f(q, m) = R\_{Θ,m} · q

其中 R\_{Θ,m} 为分块对角旋转矩阵，每个 2×2 块的形式为：

[[cos(m·θ_i), -sin(m·θ_i)], [sin(m·θ_i), cos(m·θ_i)]]

其中 θ_i = 10000^(-2i/d)。这意味着每一维子空间以不同角频率进行旋转。

### 为什么能编码相对位置

设 q 在位置 m，k 在位置 n，则注意力分数中的内积为：

f(q,m)^T · f(k,n) = (R\_{Θ,m} · q)^T · (R\_{Θ,n} · k) = q^T · R\_{Θ,m}^T · R\_{Θ,n} · k = q^T · R\_{Θ,n-m} · k

由于旋转矩阵的正交性 R\_{Θ,m}^T · R\_{Θ,n} = R\_{Θ,n-m}，**注意力内积仅依赖于相对位置 n-m，完美实现了相对位置编码的效果**。

### 主流应用与长度外推

RoPE 被 LLaMA、Mistral、Qwen、DeepSeek 等主流开源大模型广泛采用。然而，基础 RoPE 在超出训练长度时性能急剧下降。为此，社区提出了多种长度外推方法：

- **NTK-aware Scaling：**不均匀缩放不同频率分量，高频保持不变以保留局部位置信息，低频拉伸以覆盖更远位置。
- **YaRN (Yet another RoPE extensioN)：**结合 NTK-aware 缩放与注意力温度校正，实现了更平滑的长度外推，在多种长度下表现稳定。
- **Dynamic NTK：**根据实际序列长度动态调整缩放因子，无需预先知道目标长度。

## 5. ALiBi (Attention with Linear Biases)

ALiBi（Press et al., 2022）采用了一种极为简洁的方案：完全不修改 token embedding，而是直接在注意力分数上施加与距离成正比的线性偏置：

Attention(Q, K) = softmax(QK^T / √d_k + m · [-(i-j)])

其中 m 是每个注意力头不同的固定斜率（按 2^(-8/n), 2^(-16/n), ... 取值，n 为头数），[-(i-j)] 表示距离的负值矩阵。距离越远的 token，注意力分数被惩罚得越多。

**核心优势：**(1) 无需引入额外的位置嵌入参数；(2) 天然支持长度外推——模型在短序列上训练的偏置斜率，可以直接应用到长序列上，因为线性函数的外推性质良好；(3) 计算简单高效。

ALiBi 被 BLOOM、MPT 等模型采用，在长度外推任务上展现了优异性能。

## 6. 对比总结

| 方案 | 类型 | 是否支持外推 | 计算开销 | 代表模型 |
|-|-|-|-|-|
| Sinusoidal | 绝对 | 理论可行，实际差 | 极低 | 原始 Transformer |
| Learned | 绝对 | 不支持 | 极低 | GPT、BERT |
| RoPE | 相对（旋转） | 需配合 NTK/YaRN | 低 | LLaMA、Mistral、Qwen |
| ALiBi | 相对（偏置） | 天然支持 | 极低 | BLOOM、MPT |

当前大语言模型的主流选择是 **RoPE**，因其在表达能力和工程实现之间取得了良好平衡。ALiBi 以极简设计在外推场景中也有一席之地。绝对位置编码由于外推能力不足，在长上下文需求日益增长的趋势下已逐渐被取代。

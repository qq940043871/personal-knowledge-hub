# 向量表示与嵌入

> 🧠 嵌入（Embedding）是将离散符号（词语、句子、图像等）映射到连续向量空间的技术。它是大语言模型（LLM）理解语言的基础：计算机无法直接处理"词"或"句"，必须先将它们转换为高维实数向量，再通过向量间的距离和方向关系来度量语义相似性。本文从经典方法到前沿技术，系统梳理嵌入技术的发展脉络与核心原理。

## 1. 从 One-Hot 到分布式表示

在深度学习之前，文本的最常见表示方式是 **One-Hot 编码**：构建一个与词表等长的向量，目标词对应位置为 1，其余为 0。这种方式存在两个根本性缺陷：

- **高维稀疏**：词表大小通常在数万至数十万量级，导致向量维度极高且几乎全部为零，浪费存储和计算资源
- **无语义关系**：任意两个不同词的 One-Hot 向量正交（余弦相似度为 0），无法度量语义相似性——"猫"和"狗"的距离与"猫"和"经济"的距离完全相同

突破来自语言学的一个深刻洞察。语言学家 J.R. Firth (1957) 提出了著名的**分布式假设**："You shall know a word by the company it keeps"——一个词的含义由其上下文决定。这意味着，如果两个词经常出现在相似的上下文中，它们的语义就应该相近。

基于这一假设，研究者开始学习**分布式表示**（Distributed Representation），将每个词映射到一个低维（通常 100-300 维）的稠密实数向量。这种表示的一个经典性质是**向量代数关系**：

**king - man + woman ≈ queen**

这说明嵌入空间中的方向编码了语义关系——"king"到"queen"的方向近似于"man"到"woman"的方向，性别关系被编码为一个稳定的平移向量。类似的类比关系还包括：Paris - France + Italy ≈ Rome（国家-首都关系）。

## 2. 静态词嵌入

### 2.1 Word2Vec

2013 年，Mikolov 等人提出 Word2Vec，是分布式词嵌入的里程碑。它包含两种训练架构：

- **CBOW（连续词袋）**：用上下文窗口内的词向量均值来预测中心词。目标函数最大化 $P(w_t | w_{t-c}, ..., w_{t-1}, w_{t+1}, ..., w_{t+c})$，其中 c 为窗口大小。训练完成后，隐藏层权重矩阵即为词嵌入矩阵
- **Skip-gram**：方向相反，用中心词预测上下文中的每个词。目标函数最大化 $\sum_{-c \leq j \leq c, j \neq 0} \log P(w_{t+j} | w_t)$。Skip-gram 在小规模数据集上表现更优，对低频词的表示质量更高

朴素的 softmax 计算需要遍历整个词表（归一化分母），代价极大。Word2Vec 引入了**负采样**（Negative Sampling）加速策略：将多分类问题转化为二分类——对正样本（真实上下文对）最大化概率，对随机采样的 K 个负样本（噪声词对）最小化概率。这将每步更新的计算量从 O(V) 降低到 O(K)，其中 K 通常取 5-20。

### 2.2 GloVe

2014 年，Pennington 等人提出 GloVe（Global Vectors），从另一个角度构建词嵌入。其核心思想是直接对**词共现矩阵**进行分解：

- 首先统计全局语料中任意两个词在指定窗口内共同出现的次数，构建共现矩阵 X
- 学习词向量使 $w_i^T w_j + b_i + b_j = \log X_{ij}$，即向量点积拟合共现概率的对数
- 损失函数按共现次数加权：高频词对的拟合权重更大，但设有上限避免常见词对主导训练

GloVe 的优势在于同时利用了**全局统计信息**（整个语料的共现模式）和**局部上下文窗口**（类似 Word2Vec 的局部信息），在词类比和命名实体识别等任务上表现优异。

## 3. 上下文嵌入

Word2Vec 和 GloVe 为每个词生成一个**固定向量**，无论出现在什么语境中。这导致了一个根本问题：**一词多义**无法被表达。例如"bank"在"river bank"（河岸）和"investment bank"（投资银行）中含义完全不同，却共享同一个向量。

**ELMo**（Embeddings from Language Models, 2018）首次实现了上下文相关的嵌入。它使用双向 LSTM 语言模型，对每个词的前向和后向隐状态进行加权求和，生成依赖于具体句子的动态表示。实验表明，ELMo 在六个 NLP 基准任务上带来了 1-2% 的提升。

**Transformer 时代**将上下文嵌入推向了新高度。BERT（2018）使用掩码语言模型（MLM）预训练——随机遮盖 15% 的词并预测它们，学习深度双向表示。GPT 系列则采用自回归语言模型，逐步预测下一个词。两者都基于 Transformer 架构，利用自注意力机制让每个位置都能直接关注整个序列的所有位置。

Transformer 的一个重要特性是**分层表示**：不同层捕获不同层次的语言特征。底层主要编码词法和句法信息（词性、依存关系），中间层混合语法和语义，高层则聚焦于语义理解（语义角色、共指消解）。这种层次化特性使得同一模型的不同层可以服务于不同的下游任务。

## 4. 句子/文档嵌入

词嵌入之外，如何将整个句子或文档编码为一个固定维度的向量，是检索和聚类等任务的核心问题。主流方法包括：

- **平均池化**：对句子中所有词的嵌入取均值，简单但有效。适用于对计算效率要求高的场景
- **[CLS] token**：BERT 在输入序列开头插入一个特殊标记 [CLS]，其最终隐状态用作句子级表示。但未经微调的 [CLS] 表示质量较差
- **Sentence-BERT (2019)**：采用孪生网络（Siamese Network）结构，用共享权重的 BERT 分别编码两个句子，再通过余弦相似度比较。推理速度比原生 BERT 快约 1000 倍（1000 句的 50 万对比较从 65 小时降至 5 秒）
- **SimCSE (2021)**：无监督对比学习方法——对同一句子过两次 BERT（利用 dropout 的随机性产生不同表示）作为正样本对，同 batch 内其他句子作为负样本。这一简洁策略在 STS 基准上将 Spearman 相关系数从 Sentence-BERT 的 78.69 提升至 84.31

嵌入质量的评估通常采用 STS（语义文本相似度）基准测试，计算模型预测的相似度与人类标注之间的 Spearman 相关系数。在检索任务中，则通过 MRR（Mean Reciprocal Rank）和 NDCG（Normalized Discounted Cumulative Gain）等指标评估排名质量。

## 5. 嵌入空间的几何性质

理解嵌入空间的几何特性对于选择相似度度量和优化检索效果至关重要：

- **余弦相似度 vs 欧氏距离**：余弦相似度度量向量夹角（方向相似性），值域 [-1, 1]；欧氏距离度量向量端点的绝对距离。当向量已归一化（||v|| = 1）时，两者等价：$||a - b||^2 = 2(1 - \cos\theta)$。实践中，归一化后用内积等价于余弦相似度，且计算更高效
- **各向异性问题（Anisotropy）**：Ethayarajh (2019) 发现，BERT 和 GPT 的词向量并非均匀分布在整个空间中，而是聚集在一个狭窄的锥体区域内。这意味着随机两个词的平均余弦相似度显著大于 0，削弱了语义区分能力。后续研究提出了后处理归一化或各向同性约束等缓解方案
- **聚类结构**：嵌入空间呈现自然的语义聚类——同义词、上位词、反义词分别占据不同的子区域。这种结构支撑了词向量的类比推理能力和最近邻检索的有效性
- **维度灾难与降维**：随着维度增加，高维空间中点之间的距离趋于等距（集中效应），最近邻和最远邻的距离比值趋向 1。PCA（主成分分析）和 t-SNE 等降维方法不仅能用于可视化，还能通过去除噪声维度提升下游任务性能。研究表明，嵌入的有效维度远低于其名义维度

## 6. RAG 中的嵌入应用

检索增强生成（Retrieval-Augmented Generation, RAG）是当前 LLM 应用的核心架构之一，而嵌入在其中扮演着**语义检索**的关键角色。

RAG 的基本流程：将知识库文档切分为 chunk，通过嵌入模型将每个 chunk 编码为向量存入向量数据库；用户查询时，将问题编码为向量，在数据库中检索最相似的 top-k 个 chunk 作为上下文，拼入 prompt 交给 LLM 生成回答。嵌入的质量直接决定了检索的相关性，进而决定生成质量。

**查询-文档相似度计算**的核心是将查询向量与所有文档向量做内积或余弦相似度比较。为加速这一过程，工程上采用近似最近邻（ANN）算法：HNSW（分层可导航小世界图）和 IVF（倒排文件索引）是两种最常用的索引结构。

主流**向量数据库**对比：

| 产品 | 特点 | 适用场景 |
|-|-|-|
| FAISS | Facebook 开源，支持 GPU 加速，单机性能极强 | 大规模单机检索 |
| Milvus | 分布式架构，支持标量+向量混合过滤 | 企业级生产环境 |
| Pinecone | 全托管 SaaS，零运维 | 快速原型与中小规模 |
| Weaviate | 支持混合搜索（向量 + BM25 关键词） | 需要关键词召回补充的场景 |

**嵌入模型选型**（2024-2025 年主流）：

- **OpenAI text-embedding-3-large**：3072 维，MTEB 排行榜领先，支持 Matryoshka（可截断维度降低存储）
- **BGE 系列（BAAI）**：中英文双语优化，在中文检索任务上表现优异，开源可私有部署
- **E5（Microsoft）**：统一 "query:" 和 "passage:" 前缀的对比学习范式，泛化能力强
- **GTE（Alibaba）**：大规模弱监督预训练，支持多语言和超长文本

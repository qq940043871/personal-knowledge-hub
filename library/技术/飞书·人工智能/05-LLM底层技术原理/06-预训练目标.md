# 预训练目标

> 📌 **预训练（Pre-training）**是大语言模型获取语言知识的核心阶段。模型通过在海量文本上进行**自监督学习（Self-Supervised Learning）**，从原始语料中习得语法、语义、世界知识与推理能力。预训练目标的设计直接决定了模型的能力边界——它定义了模型"如何理解语言"以及"如何使用语言"。本节将系统梳理主流预训练目标的技术细节、适用架构及其演进脉络。

## 1. 因果语言建模（Causal Language Modeling, CLM）

因果语言建模是 GPT 系列模型的核心训练目标，也是当前绝大多数大语言模型所采用的预训练范式。其核心思想极为简洁：**给定前文，预测下一个 token**。

**损失函数**：模型通过最小化交叉熵损失进行训练：

$$L = -\sum_{t=1}^{T} \log P(x_t \mid x_1, x_2, \ldots, x_{t-1})$$

其中 $x_t$ 表示序列中第 $t$ 个 token，$T$ 为序列总长度。模型在每个位置上独立地对词表进行 softmax 分布预测，训练目标是最大化真实下一个 token 的对数概率。

**Teacher Forcing 策略**：在训练过程中，无论模型在前一步的预测是否正确，输入始终使用真实的 ground-truth token 而非模型自身的预测结果。这一策略确保了训练的稳定性，避免了错误在序列中的累积传播。然而，这也导致了**曝光偏差（Exposure Bias）**问题——训练时模型看到的是完美前文，推理时则必须依赖自身的（可能错误的）输出。

**自回归生成的天然匹配**：CLM 的单向因果注意力机制与自回归解码过程完全一致。模型在生成每个 token 时，仅能看到左侧上下文（left context），这与人类书写和阅读的自然顺序相吻合。这种设计使得 CLM 训练出的模型无需任何架构修改即可直接用于文本生成任务。

**核心技术细节**：

- **因果注意力掩码（Causal Attention Mask）**：通过上三角掩码矩阵确保位置 $t$ 的 token 仅能关注位置 $1$ 到 $t$ 的 token，严格阻止信息从未来泄漏到过去
- **Next-Token Prediction 的涌现能力**：尽管训练目标仅是预测下一个 token，但当模型规模和数据量足够大时，会涌现出上下文学习（In-Context Learning）、思维链推理（Chain-of-Thought）等高级能力
- **代表模型**：GPT-2/3/4、LLaMA 系列、Mistral、Qwen、DeepSeek 等均采用 CLM 作为主训练目标

## 2. 掩码语言建模（Masked Language Modeling, MLM）

掩码语言建模由 BERT（2018）提出，其核心思想是：**随机遮盖输入序列中的部分 token，让模型根据双向上下文预测被遮盖的内容**。

**80/10/10 遮盖策略**：BERT 在训练时随机选择 15% 的 token 进行遮盖，对这 15% 的 token 采用如下处理方式：

- **80%** 替换为特殊符号 `[MASK]`
- **10%** 替换为随机 token
- **10%** 保持不变

这种混合策略的设计意图是：如果所有被选中的 token 都替换为 `[MASK]`，模型在微调阶段永远看不到 `[MASK]` 符号，导致训练与推理的分布不一致。通过引入随机替换和保持不变的情况，模型被迫学习每个位置的真实语义表征，而非仅依赖 `[MASK]` 这一特殊信号。

**双向上下文 vs 单向上下文**：MLM 的最大优势在于能够同时利用左侧和右侧的上下文信息。BERT 使用全注意力（Full Attention）机制，每个 token 可以关注序列中的所有其他 token（被遮盖的位置除外）。这使得 MLM 在需要深层语义理解的自然语言理解（NLU）任务上表现优异，如文本分类、命名实体识别、阅读理解等。

**为什么 MLM 不适合生成任务**：

- **训练-推理不匹配**：训练时模型看到的是大量 `[MASK]` 符号，但推理生成时这些符号并不存在
- **非自回归本质**：MLM 假设被遮盖的 token 之间相互独立，忽略了它们之间的依赖关系，无法建模联合概率 $P(x_1, x_2, \ldots, x_T)$
- **生成效率低**：无法像 CLM 那样逐步生成，需要迭代式的 mask-then-predict 流程

**代表模型**：BERT、RoBERTa、ALBERT、DeBERTa、ELECTRA。

## 3. Seq2Seq / Span Corruption

Span Corruption 是 T5（Text-to-Text Transfer Transformer, 2020）采用的预训练目标，可以看作 MLM 的 Seq2Seq 变体。**随机遮盖输入中的连续 span（片段），然后让模型以自回归方式生成被遮盖的部分**。

**具体实现**：

- 随机选择文本中 15% 的 token 组成若干连续 span
- 每个 span 被替换为一个特殊的哨兵 token（sentinel），如 `<extra_id_0>`、`<extra_id_1>` 等
- 被遮盖的 span 按顺序拼接作为 decoder 的目标输出

**Encoder-Decoder 架构的天然匹配**：Encoder 处理被部分遮盖的输入，Decoder 以自回归方式逐个生成被遮盖的 span 内容。这种设计完美利用了 Encoder-Decoder 架构的优势——Encoder 负责全局语义理解，Decoder 负责序列生成。相比纯 Encoder 架构（BERT）和纯 Decoder 架构（GPT），Seq2Seq 预训练目标在条件生成任务（如摘要、翻译）上具有天然优势。

**与 MLM 的关键差异**：MLM 要求模型独立预测每个被遮盖的 token，而 Span Corruption 要求模型在 decoder 端按顺序生成整个被遮盖片段，因此能够建模被遮盖 token 之间的依赖关系。

**代表模型**：T5、mT5、UL2、Flan-T5。

## 4. 下一句预测（Next Sentence Prediction, NSP）

NSP 是 BERT 的辅助预训练任务。模型接收两个句子 A 和 B，判断 B 是否是 A 在原始文档中的真实下一句。正样本来自连续文档，负样本为随机拼接。

**后续研究的质疑**：RoBERTa（2019）通过大规模消融实验发现，NSP 对下游任务的贡献**非常有限甚至有害**。原因在于 NSP 的信号过于简单——模型可能仅通过主题一致性（topic consistency）而非真正的句间逻辑关系来完成判断。RoBERTa 移除 NSP 并使用更长的序列、更多的数据和动态遮盖策略后，性能全面超越 BERT。

**Sentence Order Prediction（SOP）**：ALBERT 提出了替代方案 SOP，要求模型判断两个句子的顺序是否被颠倒。相比 NSP，SOP 的难度更高，迫使模型学习更细粒度的篇章连贯性。

## 5. 现代预训练策略

随着大语言模型的发展，预训练策略已从"单一目标 + 单阶段"演进为复杂的多阶段、多目标体系。

**多阶段预训练（Continual Pre-training）**：

- **阶段一：通用预训练**——在大规模通用语料上进行 CLM 训练，习得基础语言能力
- **阶段二：领域增强**——在特定领域（医学、法律、金融）语料上继续训练，注入专业知识
- **阶段三：能力增强**——在代码、数学、推理等高质量数据上精调，强化特定能力

**代码混合训练**：现代模型普遍在预训练数据中混入代码数据（GitHub 代码、技术文档等）。研究表明，代码数据不仅能提升编程能力，还能显著增强模型的**逻辑推理和结构化思维**能力。DeepSeek-V2、Qwen2.5 等模型在预训练阶段均包含 15%\~20% 的代码数据。

**数据配比的重要性**：预训练数据的领域配比（数据配比，Data Mix）是影响模型能力分布的关键超参数。数学和推理数据的权重调整尤其敏感——过多会导致语言能力退化，过少则推理能力不足。Llama 3 系列通过大量的配比实验，确定了英文、多语言、代码、数学等数据的最优比例。

**课程学习（Curriculum Learning）**：部分研究尝试在预训练过程中动态调整数据难度——先训练简单样本，再逐步引入复杂样本。这一策略在小规模实验中显示了正向效果，但在超大规模训练中的收益尚待验证。

## 6. 预训练数据

预训练数据的规模与质量是决定模型性能的基础性因素。下表汇总了主要模型的训练数据情况：

| **模型** | **训练数据量** | **主要数据来源** |
|-|-|-|
| GPT-3 | \~300B tokens | CommonCrawl (过滤)、WebText2、Books、Wikipedia |
| LLaMA-2 | 2T tokens | CommonCrawl、C4、GitHub、Wikipedia、ArXiv |
| LLaMA-3 | 15T+ tokens | 大规模网页数据、代码、多语言语料 |
| Qwen-2.5 | 18T tokens | 网页、代码、数学、多语言、书籍 |
| DeepSeek-V3 | 14.8T tokens | 网页、代码、数学、科学文献 |
| Mistral-Large | 未公开 | 多语言网页、代码、学术文献 |

**主要开源数据集**：

- **CommonCrawl**：互联网爬取数据的"原始矿山"，包含数千亿网页，但质量参差不齐，需大量清洗过滤
- **The Pile**：EleutherAI 构建的 800GB 多源数据集，涵盖 22 个子集（学术论文、GitHub、StackExchange 等）
- **RedPajama**：复现 LLaMA 训练数据的开源项目，包含 1.2T tokens
- **FineWeb**（HuggingFace, 2024）：从 96 个 CommonCrawl 快照中精选的 15T tokens 高质量网页数据，通过多级过滤和去重达到极高质量

**数据去重与清洗**：

- **近重复去重（Near-duplicate Dedup）**：使用 MinHash + LSH 等算法去除高度相似的文档，防止模型记忆重复内容
- **质量过滤**：基于启发式规则（长度、重复率、特殊字符比例）和分类器（如 fastText 质量分类器）过滤低质量内容
- **有害内容过滤**：移除包含毒性、偏见或个人信息的内容
- **数据质量 > 数据数量**：FineWeb 的实验表明，经过精心过滤的 5T tokens 数据的训练效果可优于未过滤的 15T tokens 数据

## 7. 关键论文

- **GPT** — *Improving Language Understanding by Generative Pre-Training*（Radford et al., 2018）：首次系统提出基于 CLM 的生成式预训练范式
- **BERT** — *Pre-training of Deep Bidirectional Transformers for Language Understanding*（Devlin et al., 2019）：开创 MLM + NSP 的双向预训练范式
- **T5** — *Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer*（Raffel et al., 2020）：统一的 Text-to-Text 框架与 Span Corruption 目标
- **RoBERTa** — *A Robustly Optimized BERT Pretraining Approach*（Liu et al., 2019）：揭示 NSP 的局限性，优化 MLM 训练策略
- **UL2** — *Unifying Language Learning Paradigms*（Tay et al., 2023）：混合多种去噪目标的统一预训练框架
- **Scaling Laws** — *Scaling Laws for Neural Language Models*（Kaplan et al., 2020）：揭示模型规模、数据量与计算量之间的幂律关系
- **Chinchilla** — *Training Compute-Optimal Large Language Models*（Hoffmann et al., 2022）：提出计算最优的模型-数据配比原则
- **FineWeb** — *FineWeb: Decanting the Web for the Finest Text Data at Scale*（Penedo et al., 2024）：系统化的大规模数据清洗与过滤方法论

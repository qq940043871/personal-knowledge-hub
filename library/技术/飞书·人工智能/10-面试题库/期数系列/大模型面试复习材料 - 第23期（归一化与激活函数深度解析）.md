### 1.1 归一化技术全景——从 BatchNorm 到 RMSNorm

**四代演进路径**：

#### **第1代：BatchNorm（2015）**

- **核心思想**：对每个 Batch 的特征维度归一化
- **公式**：\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}
- **优点**：加速收敛、降低对初始化的依赖
- **致命缺陷**：**Batch 大小依赖**：小 Batch 时统计量不准确
- **训练/推理不一致**：推理用训练时移动的均值/方差
- **不适合 RNN**：序列长度不同导致统计量不稳定
- **跨卡同步开销**：分布式训练需要同步 Batch 统计量

#### **第2代：LayerNorm（2016）**

- **核心思想**：对特征维度归一化（跨样本、跨特征）
- **公式**：\hat{x} = \frac{x - \mu_{seq}}{\sqrt{\sigma_{seq}^2 + \epsilon}}
- **优点**：**无需 Batch 统计量**：适合小 Batch、在线学习
- **适合序列模型**：RNN、Transformer 都能用
- **训练/推理一致**：统计量基于当前输入计算
- **缺点**：计算量比 BatchNorm 大（需要计算均值和方差）

#### **第3代：RMSNorm（2019）**

- **核心思想**：只用均方根归一化，去掉均值中心化
- **公式**：\hat{x} = \frac{x}{\sqrt{\frac{1}{n}\sum_{i=1}^n x_i^2 + \epsilon}}
- **为什么比 LayerNorm 好**：**计算更快**：不需要计算均值（节省 ~10-15% 计算时间）
- **数值稳定性更好**：避免均值减法导致的精度损失
- **大模型标配**：LLaMA、GPT-3、PaLM 都用 RMSNorm
- **量化对比**：归一化方法计算时间 (ms)显存占用 (MB)训练稳定性BatchNorm12.345⭐⭐LayerNorm15.752⭐⭐⭐⭐RMSNorm13.548⭐⭐⭐⭐⭐

#### **第4代：AdaNorm（2023）**

- **核心思想**：自适应调整归一化的尺度参数
- **公式**：\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \cdot \alpha(x) + \beta(x)
- **创新点**：\alpha 和 \beta 是输入的函数（通过小型神经网络学习）
- **效果**：训练稳定性 +20%，收敛速度 +15%

### 1.2 激活函数演进——从 ReLU 到 SwiGLU

**五代演进路径**：

#### **第1代：ReLU（2012）**

- **公式**：f(x) = \max(0, x)
- **优点**：计算简单、缓解梯度消失
- **缺点**：**Dead ReLU 问题**：负值区域梯度为 0，神经元永久失活
- **非零中心**：输出均值 > 0，导致梯度更新方向偏斜

#### **第2代：GELU（2016）**

- **公式**：f(x) = x \cdot \Phi(x)（其中 \Phi 是标准正态 CDF）
- **近似实现**：0.5x \cdot (1 + \tanh[\sqrt{2/\pi}(x + 0.044715x^3)])
- **优点**：**平滑非线性**：比 ReLU 更平滑，梯度流更稳定
- **自适应 dropout**：根据输入大小动态调整激活概率
- **大模型标配**：GPT-2、GPT-3、BERT 都用 GELU
- **代码实现**：

```
<code>import torch<br/>import torch.nn as nn<br/><br/>class GELU_Approx(nn.Module):<br/>    def forward(self, x):<br/>        return 0.5 * x * (1.0 + torch.tanh(<br/>            math.sqrt(2.0 / math.pi) * (x + 0.044715 * torch.pow(x, 3))<br/>        ))<br/><br/># 官方实现（PyTorch 1.9+）<br/>gelu = nn.GELU()</code>
```

#### **第3代：Swish（2017）**

- **公式**：f(x) = x \cdot \sigma(\beta x)（其中 \beta 是可学习参数）
- **优点**：自门控机制、无限阶可导
- **缺点**：计算量比 GELU 大（需要计算 Sigmoid）

#### **第4代：GLU（Gated Linear Unit，2017）**

- **公式**：f(x) = (xW + b) \otimes \sigma(xV + c)
- **核心思想**：门控机制控制信息流
- **缺点**：参数量翻倍（需要两个线性变换）

#### **第5代：SwiGLU（2020）**

- **公式**：f(x) = (xW_1 + b_1) \otimes \text{Swish}(xW_2 + b_2)
- **为什么是大模型标配**：**门控 + 平滑非线性**：结合 GLU 的门控机制和 Swish 的平滑性
- **性能提升显著**：PaLM（540B）用 SwiGLU 比 GELU 高 2-3 个点到 MMLU
- **大模型标配**：LLaMA、PaLM、Chinchilla 都用 SwiGLU
- **量化对比**：激活函数MMLU 准确率 (%)训练时间 (hours)参数量 (B)ReLU68.512013GELU70.212513Swish70.513013GLU71.014015（+15%）SwiGLU72.814515（+15%）

**代码实现（SwiGLU）**：

```
<code>import torch<br/>import torch.nn as nn<br/>import math<br/><br/>class SwiGLU(nn.Module):<br/>    def __init__(self, d_model, d_ff):<br/>        super().__init__()<br/>        self.W1 = nn.Linear(d_model, d_ff, bias=False)<br/>        self.W2 = nn.Linear(d_model, d_ff, bias=False)<br/>        self.W3 = nn.Linear(d_ff, d_model, bias=False)<br/>        self.swish = nn.SiLU()  # Swish 的官方实现<br/><br/>    def forward(self, x):<br/>        # x: [batch_size, seq_len, d_model]<br/>        swish_out = self.swish(self.W1(x))  # [batch_size, seq_len, d_ff]<br/>        gate = self.W2(x)                    # [batch_size, seq_len, d_ff]<br/>        gated = swish_out * gate             # 逐元素乘法（门控）<br/>        return self.W3(gated)                # [batch_size, seq_len, d_model]<br/><br/># 使用示例<br/>swiglu = SwiGLU(d_model=768, d_ff=2048)<br/>x = torch.randn(2, 128, 768)<br/>output = swiglu(x)<br/>print(output.shape)  # torch.Size([2, 128, 768])</code>
```

### 1.3 Post-Norm vs Pre-Norm——残差连接的位置之争

**两种范式对比**：

#### **Post-Norm（原始 Transformer）**

- **公式**：x_{out} = \text{LayerNorm}(x + \text{SubLayer}(x))
- 即：先残差连接，再归一化
- **优点**：理论收敛性更好（残差连接直接作用于输出）
- **缺点**：**训练不稳定**：深层模型（>12 层）容易梯度爆炸/消失
- **需要 Warm-up**：学习率需要线性 Warm-up（前 4000 步）
- **LayerScale 必要**：需要给残差连接乘一个小的系数（如 0.1）

#### **Pre-Norm（改进版）**

- **公式**：x_{out} = x + \text{SubLayer}(\text{LayerNorm}(x))
- 即：先归一化，再残差连接
- **优点**：**训练更稳定**：深层模型（>100 层）也能稳定训练
- **无需 Warm-up**：学习率可以直接用 Cosine Decay
- **现代大模型标配**：LLaMA、GPT-3、PaLM 都用 Pre-Norm
- **缺点**：理论收敛性略差（但实践中影响很小）

### 2.1 RMSNorm 为什么比 LayerNorm 更快？——数学推导与代码级理解

**问题定义**：LayerNorm 需要计算均值和方差，RMSNorm 只计算均方根，为什么更快？

#### **第1层：数学公式对比**

**LayerNorm 公式**：  
\mu = \frac{1}{n}\sum_{i=1}^n x_i, \quad\sigma^2 = \frac{1}{n}\sum_{i=1}^n (x_i - \mu)^2  
\hat{x}_i = \frac{x_i - \mu}{\sqrt{\sigma^2 + \epsilon}}

**RMSNorm 公式**：  
\text{RMS}(x) = \sqrt{\frac{1}{n}\sum_{i=1}^n x_i^2}  
\hat{x}_i = \frac{x_i}{\text{RMS}(x) + \epsilon}

**结论**：RMSNorm 计算量比 LayerNorm 少 ~50%

#### **第3层：数值稳定性分析**

**LayerNorm 的数值问题**：

- 均值减法可能导致精度损失（尤其是 FP16/BF16 训练）
- 方差计算需要平方操作，可能溢出

**RMSNorm 的数值优势**：

- 无需均值减法，避免精度损失
- 均方根计算更稳定（只需要平方和）

#### **第4层：代码级对比**

**LayerNorm 实现（PyTorch）**：

```
<code>class LayerNorm(nn.Module):<br/>    def __init__(self, d_model, eps=1e-5):<br/>        super().__init__()<br/>        self.gamma = nn.Parameter(torch.ones(d_model))<br/>        self.beta = nn.Parameter(torch.zeros(d_model))<br/>        self.eps = eps<br/><br/>    def forward(self, x):<br/>        # x: [batch_size, seq_len, d_model]<br/>        mean = x.mean(dim=-1, keepdim=True)  # [batch_size, seq_len, 1]<br/>        var = x.var(dim=-1, keepdim=True, unbiased=False)  # [batch_size, seq_len, 1]<br/>        normalized = (x - mean) / torch.sqrt(var + self.eps)<br/>        return self.gamma * normalized + self.beta</code>
```

**RMSNorm 实现（PyTorch）**：

```

```

### 2.2 SwiGLU 的门控机制为什么有效？——信息论视角

**问题定义**：SwiGLU 用门控机制控制信息流，为什么比单纯的激活函数更有效？

#### **第1层：信息论视角**

**门控机制的信息论解释**：

- **信息瓶颈理论**：门控机制可以过滤掉不重要的信息，只保留关键特征
- **互信息最大化**：门控机制最大化输入和输出之间的互信息

**数学推导**：

- 设输入 x，门控信号 g = \sigma(xW_g)，输出 y = xW \otimes g
- 互信息：I(x; y) = H(y) - H(y|x)
- 门控机制通过 g 选择性地保留信息，最大化 I(x; y)

#### **第2层：梯度流分析**

**SwiGLU 的梯度流**：

- 门控信号 g 控制梯度流：如果 g \approx 0，梯度不会流过该神经元
- 这相当于**自适应 Dropout**：根据输入重要性动态调整神经元激活

**代码演示（梯度流）**：

```
<code>import torch<br/>import torch.nn as nn<br/><br/>class SwiGLU_Gradient(nn.Module):<br/>    def __init__(self, d_model, d_ff):<br/>        super().__init__()<br/>        self.W1 = nn.Linear(d_model, d_ff, bias=False)<br/>        self.W2 = nn.Linear(d_model, d_ff, bias=False)<br/>        self.W3 = nn.Linear(d_ff, d_model, bias=False)<br/>        self.swish = nn.SiLU()<br/><br/>    def forward(self, x):<br/>        swish_out = self.swish(self.W1(x))<br/>        gate = self.W2(x)<br/>        gated = swish_out * gate  # 门控：梯度流受 gate 控制<br/>        return self.W3(gated)<br/><br/># 梯度流演示<br/>x = torch.randn(2, 128, 768, requires_grad=True)<br/>swiglu = SwiGLU_Gradient(768, 2048)<br/>output = swiglu(x)<br/>loss = output.sum()<br/>loss.backward()<br/>print(f"x.grad shape: {x.grad.shape}")  # 梯度流回 x</code>
```

### 2.3 Pre-Norm 为什么训练更稳定？——反向传播视角

**问题定义**：Pre-Norm 比 Post-Norm 训练更稳定，为什么？

#### **第1层：反向传播公式对比**

**Post-Norm 反向传播**：

- 设 x_{out} = \text{LayerNorm}(x + \text{SubLayer}(x))
- 梯度：\frac{\partial L}{\partial x} = \frac{\partial L}{\partial x_{out}} \cdot \frac{\partial x_{out}}{\partial x}
- **问题**：\frac{\partial x_{out}}{\partial x} 包含 LayerNorm 的梯度，容易梯度爆炸/消失

**Pre-Norm 反向传播**：

- 设 x_{out} = x + \text{SubLayer}(\text{LayerNorm}(x))
- 梯度：\frac{\partial L}{\partial x} = \frac{\partial L}{\partial x_{out}} \cdot (1 + \frac{\partial \text{SubLayer}}{\partial x})
- **优势**：梯度直接从 x_{out} 流到 x（恒等映射），不会爆炸/消失

#### **第2层：极限情况分析**

**深层模型（>100 层）**：

- **Post-Norm**：梯度需要穿过 100 个 LayerNorm，容易消失
- **Pre-Norm**：梯度直接流过恒等映射，稳定

**代码演示（梯度范数）**：

```
<code>import torch<br/>import torch.nn as nn<br/><br/>def compute_gradient_norm(model, x):<br/>    output = model(x)<br/>    loss = output.sum()<br/>    loss.backward()<br/>    total_norm = 0<br/>    for p in model.parameters():<br/>        if p.grad is not None:<br/>            param_norm = p.grad.data.norm(2)<br/>            total_norm += param_norm.item() ** 2<br/>    return total_norm ** 0.5<br/><br/># 测试 100 层模型<br/>class DeepPostNorm(nn.Module):<br/>    def __init__(self, d_model, num_layers):<br/>        super().__init__()<br/>        self.layers = nn.ModuleList([<br/>            PostNormTransformerBlock(d_model) for _ in range(num_layers)<br/>        ])<br/><br/>    def forward(self, x):<br/>        for layer in self.layers:<br/>            x = layer(x)<br/>        return x<br/><br/>class DeepPreNorm(nn.Module):<br/>    def __init__(self, d_model, num_layers):<br/>        super().__init__()<br/>        self.layers = nn.ModuleList([<br/>            PreNormTransformerBlock(d_model) for _ in range(num_layers)<br/>        ])<br/><br/>    def forward(self, x):<br/>        for layer in self.layers:<br/>            x = layer(x)<br/>        return x<br/><br/># 梯度范数对比<br/>postnorm_model = DeepPostNorm(768, 100)<br/>prenorm_model = DeepPreNorm(768, 100)<br/>x = torch.randn(2, 128, 768)<br/><br/>postnorm_grad = compute_gradient_norm(postnorm_model, x)<br/>prenorm_grad = compute_gradient_norm(prenorm_model, x)<br/><br/>print(f"Post-Norm 梯度范数: {postnorm_grad:.4f}")  # 可能很小（梯度消失）<br/>print(f"Pre-Norm 梯度范数: {prenorm_grad:.4f}")    # 正常</code>
```

#### **第1层：归一化方法选型**

**选择：RMSNorm**

**理由**：

1. **计算效率**：比 LayerNorm 快 ~14%（130B 模型训练时间 -9%）
1. **数值稳定性**：无需均值减法，避免精度损失
1. **大模型标配**：LLaMA、GPT-3、PaLM 都用 RMSNorm

**代码实现**：

```
<code>class RMSNorm(nn.Module):<br/>    def __init__(self, d_model, eps=1e-5):<br/>        super().__init__()<br/>        self.gamma = nn.Parameter(torch.ones(d_model))<br/>        self.eps = eps<br/><br/>    def forward(self, x):<br/>        rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + self.eps)<br/>        return self.gamma * (x / rms)</code>
```

---

**选择：SwiGLU**

**理由**：

1. **性能提升显著**：PaLM（540B）用 SwiGLU 比 GELU 高 4.3 个点
1. **门控机制**：过滤掉不重要的信息，只保留关键特征
1. **大模型标配**：LLaMA、PaLM、Chinchilla 都用 SwiGLU

**代码实现**：

```
<code>class SwiGLU(nn.Module):<br/>    def __init__(self, d_model, d_ff):<br/>        super().__init__()<br/>        self.W1 = nn.Linear(d_model, d_ff, bias=False)<br/>        self.W2 = nn.Linear(d_model, d_ff, bias=False)<br/>        self.W3 = nn.Linear(d_ff, d_model, bias=False)<br/>        self.swish = nn.SiLU()<br/><br/>    def forward(self, x):<br/>        swish_out = self.swish(self.W1(x))<br/>        gate = self.W2(x)<br/>        gated = swish_out * gate<br/>        return self.W3(gated)</code>
```

---

**选择：Pre-Norm**

**理由**：

1. **训练稳定性**：支持 1000+ 层稳定训练（Post-Norm 只支持 12 层）
1. **无需 Warm-up**：学习率可以直接用 Cosine Decay
1. **大模型标配**：LLaMA、GPT-3、PaLM 都用 Pre-Norm

**代码实现**：

```
<code>class PreNormTransformerBlock(nn.Module):<br/>    def __init__(self, d_model):<br/>        super().__init__()<br/>        self.attn = MultiHeadAttention(d_model)<br/>        self.ffn = SwiGLU(d_model, d_ff=4*d_model)  # 用 SwiGLU<br/>        self.norm1 = RMSNorm(d_model)  # 用 RMSNorm<br/>        self.norm2 = RMSNorm(d_model)<br/><br/>    def forward(self, x):<br/>        x = x + self.attn(self.norm1(x))   # Pre-Norm + RMSNorm<br/>        x = x + self.ffn(self.norm2(x))    # Pre-Norm + SwiGLU<br/>        return x</code>
```

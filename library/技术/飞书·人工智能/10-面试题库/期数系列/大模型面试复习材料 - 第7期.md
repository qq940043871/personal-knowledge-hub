> "vLLM 的 PagedAttention 把 KV Cache 拆成固定大小的 Page（类似内存分页），每个请求按需申请 Page，不再一次性占满最大长度的显存。这样同等显存下可以支撑更多并发，加上 Continuous Batching，整体吞吐量提升 10-20 倍。"

- vLLM 的 PagedAttention 正是为了解决 KV Cache 的显存利用率问题

<code>LoRA（Low-Rank Adaptation）核心思想：<br/>  大模型的参数更新矩阵 ΔW 是低秩的（low-rank）<br/>  ΔW (d×d) ≈ A (d×r) × B (r×d)，其中 r &lt;&lt; d<br/><br/>  全量微调：更新 d×d = 10亿个参数（假设d=1000）<br/>  LoRA 微调：只更新 d×r + r×d = 2×1000×4 = 8000 个参数（r=4）<br/>  参数量减少：99.2%！</code>
```

```
<code>from peft import LoraConfig, get_peft_model, TaskType<br/><br/># LoRA 配置<br/>lora_config = LoraConfig(<br/>    task_type=TaskType.CAUSAL_LM,<br/>    r=16,                    # 秩（rank），越大参数越多，效果越好<br/>    lora_alpha=32,           # 缩放系数（通常是 r 的 2 倍）<br/>    lora_dropout=0.1,<br/>    target_modules=[         # 对哪些层做 LoRA（Q、V 通常效果最好）<br/>        "q_proj", "v_proj",  # 注意力的 Query 和 Value<br/>        "k_proj", "o_proj",  # 也可以加上 Key 和 Output<br/>    ]<br/>)<br/><br/># 只有 0.1-1% 的参数是可训练的！<br/>model = get_peft_model(base_model, lora_config)<br/>model.print_trainable_parameters()<br/># trainable params: 8,388,608 || all params: 7,000,000,000 || trainable%: 0.12%</code>

**参考答案要点**：

#### **标准 Self-Attention 复杂度分析**

```
<code>Self-Attention 计算：<br/>  Q、K、V 矩阵：每个 shape = [batch, seq_len, d_model]<br/><br/>  注意力分数：Attention(Q,K,V) = softmax(QK^T / √d_k) × V<br/><br/>  计算 QK^T：[batch, seq_len, d_model] × [batch, d_model, seq_len]<br/>            → [batch, seq_len, seq_len]<br/><br/>  时间复杂度：O(N² × d)，其中 N = 序列长度<br/>  空间复杂度：O(N²)（注意力矩阵）<br/><br/>  问题：N=1000 → 100万 × d 次计算<br/>       N=100000 → 100亿 × d 次计算（基本不可行！）</code>
```

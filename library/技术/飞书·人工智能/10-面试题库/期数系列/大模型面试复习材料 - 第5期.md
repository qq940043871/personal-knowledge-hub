**原理**：探索多个可能的推理路径，选择最优解

**代码示例**（简化版）：

<code>async def tree_of_thoughts(problem: str, n_samples: int = 5, depth: int = 3):<br/>    """思维树实现"""<br/><br/>    async def expand(node: dict) -&gt; List[dict]:<br/>        """扩展节点：生成多个可能的下一步"""<br/>        prompt = f"问题：{problem}\n当前思路：{node['thought']}\n可能的下一步："<br/>        responses = await llm.generate(prompt, n=n_samples)  # 生成 n 个候选<br/>        return [{"thought": r, "score": 0} for r in responses]<br/><br/>    async def evaluate(node: dict) -&gt; float:<br/>        """评估节点质量"""<br/>        prompt = f"评估以下思路的合理性（0-10分）：{node['thought']}"<br/>        score = await llm.generate(prompt)<br/>        return float(score)<br/><br/>    # 初始化根节点<br/>    root = {"thought": problem, "children": []}<br/><br/>    # 广度优先搜索<br/>    queue = [root]<br/>    for _ in range(depth):<br/>        next_queue = []<br/><br/>        for node in queue:<br/>            # 扩展<br/>            children = await expand(node)<br/><br/>            # 评估<br/>            for child in children:<br/>                child["score"] = await evaluate(child)<br/>                node["children"].append(child)<br/>                next_queue.append(child)<br/><br/>        # 只保留得分最高的 top-k 个节点<br/>        queue = sorted(next_queue, key=lambda x: x["score"], reverse=True)[:3]<br/><br/>    # 返回最佳思路<br/>    best_leaf = max(queue, key=lambda x: x["score"])<br/>    return best_leaf["thought"]</code>
```

<code>class AgentMemory:<br/>    def __init__(self):<br/>        self.short_term = []          # 最近 10 条消息<br/>        self.long_term = VectorDB()   # 向量数据库（如 Pinecone）<br/>        self.working = {}            # 当前任务状态<br/><br/>    async def retrieve(self, query: str) -&gt; List[str]:<br/>        """检索相关记忆"""<br/><br/>        # 1. 短期记忆（全部保留）<br/>        recent = self.short_term[-10:]<br/><br/>        # 2. 长期记忆（向量检索）<br/>        relevant = await self.long_term.search(query, top_k=5)<br/><br/>        # 3. 工作记忆（当前任务状态）<br/>        working_memory = [<br/>            f"当前任务：{self.working.get('task')}",<br/>            f"已完成步骤：{self.working.get('completed_steps')}"<br/>        ]<br/><br/>        # 4. 合并去重<br/>        all_memories = recent + relevant + working_memory<br/>        return list(set(all_memories))<br/><br/>    async def store(self, info: str, importance: float):<br/>        """存储记忆"""<br/><br/>        # 判断重要性<br/>        if importance &gt; 0.7:<br/>            # 重要信息存入长期记忆<br/>            await self.long_term.add(<br/>                content=info,<br/>                metadata={"timestamp": time.time(), "importance": importance}<br/>            )<br/>        else:<br/>            # 普通信息只保留在短期记忆<br/>            self.short_term.append(info)<br/>            if len(self.short_term) &gt; 10:<br/>                self.short_term.pop(0)  # 移除最老的消息</code>
```

**面试表达**：

> "我们的 Agent 有三级记忆系统。短期记忆保存最近 10 条消息，长期记忆用向量数据库存储重要信息（如：用户偏好、历史决策），工作记忆记录当前任务的执行状态。每次对话时，Agent 会检索相关记忆，作为上下文送给 LLM。"

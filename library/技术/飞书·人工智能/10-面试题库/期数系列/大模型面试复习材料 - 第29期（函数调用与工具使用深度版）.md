### 2.1 结构化输出——让 LLM 精确生成 JSON

**问题定义**：LLM 原生输出是自然语言，但函数调用需要精确的 JSON 格式。

**三代技术方案对比**：

#### 第1代：Few-shot Prompting（准确率 ~60%）

```
<code># 提示词工程方法<br/>prompt = f"""<br/>你是一个有用的助手。当用户需要调用工具时，输出JSON格式：<br/><br/>示例1：<br/>用户：北京今天天气怎么样？<br/>输出：{{"tool": "get_weather", "parameters": {{"city": "北京"}}}}<br/><br/>示例2：<br/>用户：帮我查一下苹果公司的股价<br/>输出：{{"tool": "get_stock_price", "parameters": {{"symbol": "AAPL"}}}}<br/><br/>现在，用户说：{user_query}<br/>输出：<br/>"""<br/># 问题：模型容易偏离格式，产生幻觉字段</code>
```

#### 第2代：JSON Force（Grammar-Constrained Decoding）（准确率 ~85%）

```
<code># 使用 Guidance/Grammar 强制JSON格式<br/>import guidance<br/><br/># 定义JSON Schema<br/>tool_schema = {<br/>    "type": "object",<br/>    "properties": {<br/>        "tool": {"type": "string", "enum": ["get_weather", "get_stock_price", ...]},<br/>        "parameters": {"type": "object"}<br/>    },<br/>    "required": ["tool", "parameters"]<br/>}<br/><br/># Guidance 强制生成合规JSON<br/># （   ★bug修复：原 f-string 四引号结尾 + 大括号转义无法解析，改为拼接等价模板）<br/>g = guidance.models.TransformersLLM(model_path)<br/>program = guidance.Program(<br/>    "{{#gen ;; json_schema=" + json.dumps(tool_schema) + "}}"  # 伪代码<br/>)<br/># 优势：100% 格式合规<br/># 劣势：模型可能生成不存在的工具名（幻觉）</code>
```

#### 第3代：Fine-tuning + JSON Mode（准确率 ~94%）

```
<code># 方案：微调模型学习函数调用格式 + 推理时启用JSON Mode<br/><br/># ========== 训练阶段 ==========<br/># 数据格式（120K 样本）<br/>training_sample = {<br/>    "messages": [<br/>        {"role": "system", "content": "你是一个有用的助手，可以调用工具。"},<br/>        {"role": "user", "content": "北京今天天气怎么样？"},<br/>        {"role": "assistant", "function_call": {<br/>            "name": "get_weather",<br/>            "arguments": json.dumps({"city": "北京"}, ensure_ascii=False)<br/>        }}<br/>    ]<br/>}<br/><br/># 微调脚本（QLoRA）<br/>from peft import LoraConfig, get_peft_model<br/>lora_config = LoraConfig(<br/>    r=64,  # 秩<br/>    lora_alpha=16,<br/>    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],<br/>    lora_dropout=0.05,<br/>    bias="none",<br/>    task_type="CAUSAL_LM"<br/>)<br/>model = get_peft_model(base_model, lora_config)<br/># 训练：8张A100，Batch Size=128，学习率=2e-4，训练5轮<br/><br/># ========== 推理阶段 ==========<br/># 启用 JSON Mode（vLLM）<br/>from vllm import LLM, SamplingParams<br/>sampling_params = SamplingParams(<br/>    temperature=0.1,<br/>    max_tokens=512,<br/>    response_format={"type": "json_object"}  # JSON Mode<br/>)<br/>llm = LLM(model="agent-harness-function-calling-v1")<br/>result = llm.generate(prompts, sampling_params)<br/># 解析JSON<br/>import json<br/>try:<br/>    function_call = json.loads(result[0].outputs[0].text)<br/>except json.JSONDecodeError:<br/>    # 错误恢复：让模型重新生成<br/>    function_call = recover_with_retry(result, llm, sampling_params)</code>
```

**关键技巧**：

1. **错误恢复**（Retry with Feedback）：解析失败时，将错误信息反馈给模型，让其重新生成
1. **参数补全**：必填参数缺失时，用上下文推断（如"北京天气" → city="北京"）
1. **工具名模糊匹配**：用户输入"天气" → 匹配 "get_weather"（编辑距离 < 2）

**核心挑战**：工具定义长（平均 500 token/工具），全部放入上下文会爆 Token。

**解决方案：两阶段检索**。

#### 阶段1：离线索引构建

```
<code># ========== 工具索引构建 ==========<br/>from sentence_transformers import SentenceTransformer<br/>from pymilvus import Collection, connections<br/><br/># 1. 加载 Embedding 模型<br/>embedder = SentenceTransformer('BAAI/bge-m3')<br/><br/># 2. 构建工具元数据（用于检索）<br/>tools = [<br/>    {<br/>        "name": "get_weather",<br/>        "description": "获取指定城市的当前天气",<br/>        "parameters": {<br/>            "type": "object",<br/>            "properties": {<br/>                "city": {"type": "string", "description": "城市名称"}<br/>            },<br/>            "required": ["city"]<br/>        },<br/>        "tags": ["天气", "气象", "温度"]<br/>    },<br/>    # ... 199 more tools<br/>]<br/><br/># 3. 生成工具 Embedding（用于语义检索）<br/>for tool in tools:<br/>    # 融合描述 + 标签 + 参数描述<br/>    doc = f"{tool['name']} {tool['description']} {' '.join(tool['tags'])}"<br/>    embedding = embedder.encode(doc)<br/>    # 存入 Milvus<br/>    collection.insert([<br/>        [tool['name']],  # 主键<br/>        [embedding.tolist()],  # 向量<br/>        [json.dumps(tool)]  # 原始JSON（用于返回）<br/>    ])<br/><br/># 4. 构建 BM25 索引（用于关键词检索）<br/>from rank_bm25 import BM25Okapi<br/>corpus = [f"{t['name']} {t['description']}" for t in tools]<br/>tokenized_corpus = [doc.split() for doc in corpus]<br/>bm25 = BM25Okapi(tokenized_corpus)</code>
```

#### 阶段2：在线检索与排序

```
<code># ========== 在线工具检索 ==========<br/>def retrieve_tools(user_query: str, top_k: int = 10) -&gt; List[Dict]:<br/>    # 1. Dense 检索（语义相似度）<br/>    query_embedding = embedder.encode(user_query)<br/>    dense_results = collection.search(<br/>        data=[query_embedding.tolist()],<br/>        limit=100,<br/>        output_fields=["tool_json"]<br/>    )<br/>    dense_tools = [res.entity.get('tool_json') for res in dense_results[0]]<br/><br/>    # 2. Sparse 检索（关键词匹配）<br/>    tokenized_query = user_query.split()<br/>    sparse_scores = bm25.get_scores(tokenized_query)<br/>    sparse_top_100_idx = np.argsort(sparse_scores)[-100:][::-1]<br/>    sparse_tools = [tools[i] for i in sparse_top_100_idx]<br/><br/>    # 3. 倒数排名融合（RRF，k=60）<br/>    from collections import defaultdict<br/>    rrf_scores = defaultdict(float)<br/>    for source in (dense_tools, sparse_tools):<br/>        for rank, tool in enumerate(source):<br/>            rrf_scores[tool['name']] += 1 / (rank + k)<br/><br/>    # 排序取 Top-20 候选<br/>    merged_tools = sorted(rrf_scores.items(), key=lambda x: x[1], reverse=True)<br/>    candidate_tools = [next(t for t in tools if t['name'] == tid) for tid, _ in merged_tools[:20]]<br/><br/>    # 4. Re-ranking（精排）：CrossEncoder 对 Query-Tool 对打分<br/>    from sentence_transformers import CrossEncoder<br/>    reranker = CrossEncoder('BAAI/bge-reranker-base')<br/>    pairs = [[user_query, format_tool_for_reranker(t)] for t in candidate_tools]<br/>    rerank_scores = reranker.predict(pairs)<br/><br/>    # 最终排序（   ★bug修复：原文 rerank_score 未定义，改为 rerank_scores）<br/>    final_tools = [t for _, t in sorted(zip(rerank_scores, candidate_tools), reverse=True)]<br/>    return final_tools[:top_k]<br/><br/>def format_tool_for_reranker(tool: Dict) -&gt; str:<br/>    """格式化工具描述（用于Re-ranking）"""<br/>    return f"工具名称：{tool['name']}\n描述：{tool['description']}\n参数：{json.dumps(tool['parameters'], ensure_ascii=False)}"</code>
```

**五层深度答案**：

#### 第1层：概念区分

#### 第2层：执行流程对比

**Function Calling 流程**：

```
<code>用户请求 → LLM 生成 JSON → 外部系统解析 JSON → 执行工具 → 结果返回 LLM → 生成回复</code>
```

**ReAct 流程**：

```
<code>用户请求 → LLM 生成 Thought + Action → 解析 Action → 执行工具 → Observation → LLM 生成下一轮 Thought + Action → ... → 最终答案</code>
```

#### 第3层：优缺点对比

**Function Calling 优势**：

1. 输出格式严格（100% 可解析）
1. 支持并行工具调用（DAG 调度）
1. 与 LLM API 深度集成（OpenAI Function Calling / vLLM JSON Mode）

**Function Calling 劣势**：

1. 需要微调或 Prompt Engineering 才能让模型学会格式
1. 不支持"思考过程"可视化（黑盒决策）

**ReAct 优势**：

1. 可解释性强（Thought 展示推理过程）
1. 灵活（可以自由设计 Action 格式）
1. 适合复杂多步推理（思维链 + 工具使用）

**ReAct 劣势**：

1. 输出解析困难（自由文本）
1. 多轮对话成本高（每轮都需要输入 Thought/Action 历史）

#### 第4层：选型决策树

```
<code>是否需要并行工具调用？<br/>  ├─ 是 → Function Calling<br/>  └─ 否 → 继续<br/>是否需要可视化推理过程？<br/>  ├─ 是 → ReAct<br/>  └─ 否 → Function Calling（推荐）<br/>是否使用 OpenAI / vLLM API？<br/>  ├─ 是 → Function Calling（原生支持）<br/>  └─ 否 → ReAct（更灵活）</code>
```

#### 第5层：混合方案（工业界最佳实践）

```
<code># 混合方案：ReAct 用于规划 + Function Calling 用于执行<br/>def hybrid_agent(user_query: str):<br/>    # 第1阶段：ReAct 生成工具调用计划（DAG）<br/>    react_prompt = f"""<br/>    你是一个任务规划器。请将以下用户请求分解为工具调用序列。<br/><br/>    用户请求：{user_query}<br/><br/>    输出格式：<br/>    Thought: &lt;推理过程&gt;<br/>    Plan:<br/>    1. &lt;工具1&gt; (&lt;依赖&gt;)<br/>    2. &lt;工具2&gt; (&lt;依赖&gt;)<br/>    ...<br/>    """<br/>    plan = llm.generate(react_prompt)<br/><br/>    # 第2阶段：解析 Plan → 工具调用 DAG<br/>    dag = parse_plan_to_dag(plan)<br/><br/>    # 第3阶段：Function Calling 执行 DAG<br/>    results = dag_scheduler.execute(dag, llm, context)<br/><br/>    # 第4阶段：汇总结果<br/>    summary_prompt = f"""<br/>    根据以下工具执行结果，生成用户友好的回复：<br/>    {format_results(results)}<br/>    """<br/>    return llm.generate(summary_prompt)</code>

###### 模块1：工具选择算法（支持 200+ 工具）

<code>class ToolRetriever:<br/>    def __init__(self):<br/>        # 离线索引<br/>        self.embedder = SentenceTransformer('BAAI/bge-m3')<br/>        self.milvus_collection = self._connect_milvus()<br/>        self.bm25 = self._build_bm25_index()<br/>        self.reranker = CrossEncoder('BAAI/bge-reranker-base')<br/><br/>    def retrieve(self, user_query: str, top_k: int = 10) -&gt; List[Dict]:<br/>        # 1. Sparse 检索<br/>        sparse_scores = self.bm25.get_scores(user_query.split())<br/>        sparse_top_100 = self._top_k_indices(sparse_scores, 100)<br/><br/>        # 3. RRF 融合<br/>        rrf_scores = self._rrf_fusion(dense_results, sparse_top_100)<br/><br/>        # 4. Re-ranking<br/>        candidates = self._get_top_n(rrf_scores, 20)<br/>        rerank_scores = self.reranker.predict([<br/>            [user_query, self._format_tool(t)] for t in candidates<br/>        ])<br/>        final_top_k = self._top_k_by_score(candidates, rerank_scores, top_k)<br/><br/>        return final_top_k<br/><br/>    def _rrf_fusion(self, dense_results, sparse_results, k: int = 60):<br/>        """倒数排名融合"""<br/>        scores = defaultdict(float)<br/>        for rank, item in enumerate(dense_results):<br/>            scores[item['id']] += 1 / (rank + k)<br/>        for rank, idx in enumerate(sparse_results):<br/>            item = self.tools[idx]<br/>            scores[item['id']] += 1 / (rank + k)<br/>        return scores</code>

<code>class DAGScheduler:<br/>    def execute(self, tool_calls: List[Dict]) -&gt; Dict[str, Any]:<br/>        # 1. 构建依赖图<br/>        dag = self._build_dag(tool_calls)<br/><br/>        # 2. 分层（同一层可并行）<br/>        layers = self._layering(dag)<br/><br/>        # 3. 逐层执行<br/>        results = {}<br/>        for layer in layers:<br/>            # 并行执行当前层<br/>            layer_results = self._parallel_execute(layer, results)<br/>            results.update(layer_results)<br/><br/>        return results<br/><br/>    def _build_dag(self, tool_calls: List[Dict]) -&gt; Dict[str, List[str]]:<br/>        """构建 DAG（基于参数引用分析）"""<br/>        dag = defaultdict(list)<br/>        for i, call in enumerate(tool_calls):<br/>            call_id = f"call_{i}"<br/>            for param_value in call['parameters'].values():<br/>                if isinstance(param_value, str) and param_value.startswith('${'):<br/>                    dep_call_id = param_value.split('.')[0].replace('${', '')<br/>                    dag[call_id].append(dep_call_id)<br/>        return dag</code>
```

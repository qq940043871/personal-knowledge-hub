# 反向传播

反向传播算法（Backpropagation Algorithm，简称BP算法）是**训练人工神经网络（尤其是深度神经网络）的核心算法**，其本质是通过“反向计算误差”并“迭代调整网络参数”，最小化模型预测值与真实值之间的误差，从而让网络学会从输入到输出的映射规律。它的提出（1986年由Rumelhart、Hinton等人系统阐述）直接推动了神经网络在20世纪80年代的第一次复兴，也是当今深度学习技术的基础。

要理解反向传播，需先明确其依赖的两个核心基础：**前向传播（Forward Propagation）** 和**梯度下降（Gradient Descent）**。反向传播的核心逻辑是“利用链式法则，从输出层反向计算各层参数对误差的梯度，再用梯度下降更新参数”。

## 一、核心前置概念

在深入反向传播前，需先理解神经网络的基本结构和前向传播过程：

### 1. 神经网络的基本结构

一个典型的全连接神经网络包含三层（复杂网络会增加“隐藏层”数量）：

- **输入层（Input Layer）**：接收原始数据（如图片的像素值、文本的向量），仅传递数据，不做计算。
- **隐藏层（Hidden Layer）**：对输入数据进行线性变换（权重×输入+偏置）和非线性激活（如ReLU、Sigmoid），是网络“学习特征”的核心。
- **输出层（Output Layer）**：输出模型预测结果（如分类任务的类别概率、回归任务的连续值），激活函数根据任务选择（如分类用Softmax，回归用Linear）。

每层由若干“神经元”组成，相邻层的神经元通过**权重（Weight，记为W）** 连接，每个神经元还有一个**偏置（Bias，记为b）** ——这两类参数是反向传播需要优化的核心对象。

### 2. 前向传播：从输入到预测的“正向计算”

前向传播是“利用当前参数计算预测值”的过程，是反向传播的前提。以“输入层→1个隐藏层→输出层”的简单网络为例，计算步骤如下：

假设：

- 输入层有 `n` 个神经元，输入向量为 `X = [x₁, x₂, ..., xₙ]`；
- 隐藏层有 `m` 个神经元，权重矩阵为 `W₁`（维度 `m×n`），偏置向量为 `b₁`（维度 `m×1`）；
- 输出层有 `k` 个神经元，权重矩阵为 `W₂`（维度 `k×m`），偏置向量为 `b₂`（维度 `k×1`）；
- 激活函数为 `σ(·)`（隐藏层常用ReLU，输出层常用Softmax）。

前向传播计算流程：

1. **隐藏层线性变换**：`Z₁ = W₁·X + b₁`（矩阵乘法+向量加法，得到隐藏层“预激活值”）；
2. **隐藏层非线性激活**：`A₁ = σ(Z₁)`（对预激活值做非线性变换，得到隐藏层输出，即“特征表示”）；
3. **输出层线性变换**：`Z₂ = W₂·A₁ + b₂`（用隐藏层输出计算输出层预激活值）；
4. **输出层激活**：`A₂ = σ(Z₂)`（得到最终预测值，记为 `Ŷ = A₂`）。

前向传播的最终目的是得到 `Ŷ`，并通过**损失函数（Loss Function，记为L）** 计算 `Ŷ` 与真实值 `Y` 的误差（如分类任务用交叉熵损失，回归任务用均方误差）。

### 3. 核心目标：最小化损失函数

反向传播的本质是“优化参数 `W₁, b₁, W₂, b₂`”，使得损失函数 `L(Ŷ, Y)` 尽可能小。要实现这一目标，需知道“每个参数变化对损失的影响”——这一影响用**梯度（Gradient，即损失对参数的偏导数，如 ∂L/∂W、∂L/∂b）** 表示：

- 若梯度为正：参数增大时，损失增大，需**减小参数**；
- 若梯度为负：参数增大时，损失减小，需**增大参数**。

反向传播的核心任务就是“计算各参数的梯度”，再通过梯度下降更新参数（参数更新公式：`参数新值 = 参数旧值 - 学习率×梯度`）。

## 二、反向传播的核心逻辑：链式法则+反向求导

反向传播的关键是**从输出层开始，利用链式法则（Chain Rule）反向计算各层参数的梯度**。之所以“反向”，是因为输出层的误差直接由 `Y` 和 `Ŷ` 计算，而隐藏层的误差依赖于后一层的误差（输出层误差→隐藏层误差→输入层无误差，因输入层无参数）。

以下仍以“输入层→1个隐藏层→输出层”的网络为例，拆解反向传播的计算步骤（假设损失函数为均方误差MSE：`L = ½(Ŷ - Y)²`，激活函数为Sigmoid：`σ(z) = 1/(1+e⁻ᶻ)`，其导数为 `σ’(z) = σ(z)·(1-σ(z))`）。

### 步骤1：计算输出层的误差（δ₂）

输出层的误差直接反映“预测值与真实值的偏差”，定义为“损失对输出层预激活值 `Z₂` 的偏导数”，记为 `δ₂ = ∂L/∂Z₂`。

根据链式法则：

`δ₂ = ∂L/∂Z₂ = ∂L/∂Ŷ × ∂Ŷ/∂Z₂`

- `∂L/∂Ŷ`：损失对预测值的偏导数，由损失函数决定。对MSE而言，`∂L/∂Ŷ = Ŷ - Y`；
- `∂Ŷ/∂Z₂`：预测值对输出层预激活值的偏导数，即输出层激活函数的导数，`σ’(Z₂) = Ŷ·(1-Ŷ)`（因 `Ŷ = σ(Z₂)`）。

因此，输出层误差：`δ₂ = (Ŷ - Y) × Ŷ·(1-Ŷ)`。

### 步骤2：计算输出层参数的梯度（∂L/∂W₂、∂L/∂b₂）

输出层的参数是 `W₂`（连接隐藏层与输出层）和 `b₂`（输出层偏置），其梯度需结合输出层误差 `δ₂` 和隐藏层输出 `A₁` 计算：

1. **输出层权重梯度（∂L/∂W₂）**：根据链式法则，`∂L/∂W₂ = ∂L/∂Z₂ × ∂Z₂/∂W₂`。

   - `∂L/∂Z₂ = δ₂`（已算得）；
   - `∂Z₂/∂W₂ = A₁ᵀ`（因 `Z₂ = W₂·A₁ + b₂`，`W₂` 与 `A₁` 是矩阵乘法，对 `W₂` 求偏导即 `A₁` 的转置，保证维度匹配）。最终：`∂L/∂W₂ = δ₂ · A₁ᵀ`。
2. **输出层偏置梯度（∂L/∂b₂）**：同理，`∂L/∂b₂ = ∂L/∂Z₂ × ∂Z₂/∂b₂`。

   - `∂Z₂/∂b₂ = I`（单位矩阵，因偏置 `b₂` 直接加在 `W₂·A₁` 上，求偏导后为1，矩阵形式为单位矩阵）；最终：`∂L/∂b₂ = δ₂`（或对 `δ₂` 按行求和，取决于批量计算方式）。

### 步骤3：计算隐藏层的误差（δ₁）

隐藏层的误差无法直接通过真实值计算，需依赖“输出层的误差”和“输出层权重 `W₂`”——因为隐藏层的输出 `A₁` 会通过 `W₂` 影响输出层的 `Z₂`，进而影响损失 `L`。

定义隐藏层误差为“损失对隐藏层预激活值 `Z₁` 的偏导数”：`δ₁ = ∂L/∂Z₁`。

根据链式法则：

`δ₁ = ∂L/∂Z₁ = ∂L/∂Z₂ × ∂Z₂/∂A₁ × ∂A₁/∂Z₁`

- `∂L/∂Z₂ = δ₂`（已算得）；
- `∂Z₂/∂A₁ = W₂ᵀ`（因 `Z₂ = W₂·A₁ + b₂`，对 `A₁` 求偏导即 `W₂` 的转置）；
- `∂A₁/∂Z₁ = σ’(Z₁) = A₁·(1-A₁)`（隐藏层激活函数的导数，因 `A₁ = σ(Z₁)`）。

因此，隐藏层误差：`δ₁ = W₂ᵀ · δ₂ × A₁·(1-A₁)`。

### 步骤4：计算隐藏层参数的梯度（∂L/∂W₁、∂L/∂b₁）

隐藏层的参数是 `W₁`（连接输入层与隐藏层）和 `b₁`（隐藏层偏置），其梯度结合隐藏层误差 `δ₁` 和输入 `X` 计算：

1. **隐藏层权重梯度（∂L/∂W₁）**：`∂L/∂W₁ = ∂L/∂Z₁ × ∂Z₁/∂W₁ = δ₁ · Xᵀ`（逻辑与输出层权重梯度一致，`∂Z₁/∂W₁ = Xᵀ`）。
2. **隐藏层偏置梯度（∂L/∂b₁）**：`∂L/∂b₁ = δ₁`（逻辑与输出层偏置梯度一致，`∂Z₁/∂b₁ = I`）。

### 步骤5：用梯度下降更新所有参数

得到所有参数的梯度后，按“梯度下降”规则更新参数（`η` 为**学习率**，控制每次更新的步长）：

- `W₂新 = W₂旧 - η × ∂L/∂W₂`
- `b₂新 = b₂旧 - η × ∂L/∂b₂`
- `W₁新 = W₁旧 - η × ∂L/∂W₁`
- `b₁新 = b₁旧 - η × ∂L/∂b₁`

## 三、反向传播的关键特点

1. **反向性**：误差计算从输出层开始，逐层反向传递到隐藏层，输入层无参数无需计算误差——这也是“反向传播”名称的由来。
2. **链式法则是核心**：通过链式法则将“输出层的总误差”分解为“各层参数的局部误差”，实现梯度的高效计算（时间复杂度与网络规模线性相关）。
3. **批量计算（Batch Processing）**：实际训练中，不会单条数据更新参数，而是用“一批数据（Batch）”计算平均梯度后更新，既提高效率，又让梯度更稳定。
4. **依赖可微激活函数**：只有激活函数可导（如Sigmoid、ReLU、Tanh），才能计算 `∂A/∂Z`，因此早期不可导的激活函数（如阶跃函数）无法用于反向传播。

## 四、常见问题与优化

反向传播虽高效，但在深度网络中会面临一些挑战，需通过优化手段解决：

| 问题 | 现象描述 | 解决方案 |
|-|-|-|
| 梯度消失（Vanishing Gradient） | 深度网络中，梯度从输出层反向传递时，经过多层小导数（如Sigmoid导数≤0.25）后，梯度趋近于0，隐藏层参数无法更新。 | 用ReLU激活函数（正区间导数为1，避免梯度衰减）；用残差网络（ResNet）引入“shortcut 连接”，直接传递梯度。 |
| 梯度爆炸（Exploding Gradient） | 梯度经过多层大导数后，数值急剧增大，导致参数更新幅度过大，模型震荡不收敛。 | 权重初始化（如He初始化、Xavier初始化）；梯度裁剪（Gradient Clipping），限制梯度最大值。 |
| 过拟合（Overfitting） | 模型在训练数据上误差小，但在测试数据上误差大，泛化能力差。 | 加入Dropout（随机关闭部分神经元）；权重正则化（L1/L2正则）；增加训练数据。 |

## 五、总结：反向传播的本质与价值

反向传播算法的本质是“**从输出到输入，用链式法则计算参数梯度，再用梯度下降优化参数**”，其核心价值在于：

- 解决了“深度网络参数难以手动调整”的问题，让神经网络能自动从数据中学习；
- 高效计算梯度（时间复杂度可控），为大规模深度网络的训练提供了可能。

如今，反向传播已与随机梯度下降（SGD）、Adam等优化器结合，成为深度学习框架（如TensorFlow、PyTorch）的底层核心逻辑——开发者无需手动推导梯度，框架会自动完成反向传播计算，但理解其原理是优化模型、解决训练问题的关键。

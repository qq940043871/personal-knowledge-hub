## 📋 概述

向量数据库用于存储和检索高维向量 embedding，支持语义相似度搜索，是 RAG（检索增强生成）系统的核心组件。

## 🏗️ 核心概念

```
<code>┌─────────────────────────────────────────────────────┐<br/>│                 向量数据库工作原理                      │<br/>├─────────────────────────────────────────────────────┤<br/>│  原始文本 → Embedding模型 → 高维向量 → 存储到向量数据库 │<br/>│                                                     │<br/>│  查询文本 → Embedding模型 → 高维向量 → 相似度检索     │<br/>│                                                     │<br/>│  支持: 余弦相似度 │ 欧氏距离 │ 点积                   │<br/>└─────────────────────────────────────────────────────┘</code>
```

### 2. LangChain + Chroma 集成

```
<code>from langchain_community.document_loaders import TextLoader<br/>from langchain.text_splitter import RecursiveCharacterTextSplitter<br/>from langchain_community.vectorstores import Chroma<br/>from langchain_community.embeddings import HuggingFaceEmbeddings<br/><br/># 1. 加载文档<br/>loader = TextLoader("example.txt", encoding="utf-8")<br/>documents = loader.load()<br/><br/># 2. 分割文档<br/>text_splitter = RecursiveCharacterTextSplitter(<br/>    chunk_size=1000,<br/>    chunk_overlap=0<br/>)<br/>docs = text_splitter.split_documents(documents)<br/><br/># 3. 创建 Embeddings<br/>embeddings = HuggingFaceEmbeddings(model_name="damo/nlp_corom_sentence-embedding_chinese-base")<br/><br/># 4. 创建向量数据库<br/>db = Chroma.from_documents(docs, embeddings, persist_directory="./chroma_db")<br/><br/># 5. 持久化<br/>db.persist()<br/><br/># 6. 查询示例<br/>query = "什么是人工智能？"<br/>docs = db.similarity_search(query, k=3)<br/><br/>for doc in docs:<br/>    print(f"内容: {doc.page_content[:100]}...")<br/>    print(f"来源: {doc.metadata}\n")</code>
```

### 4. Ollama RAG 完整流程

```
<code>import requests<br/>import chromadb<br/>import uuid<br/><br/>def ollama_embedding_by_api(text):<br/>    """获取文本向量"""<br/>    res = requests.post(<br/>        url="http://localhost:11434/api/embeddings",<br/>        json={"model": "nomic-embed-text", "prompt": text}<br/>    )<br/>    return res.json()["embedding"]<br/><br/>def init_db():<br/>    """初始化向量数据库"""<br/>    client = chromadb.PersistentClient(path='db/chroma_db')<br/>    collection = client.get_or_create_collection(name='collection_v1')<br/>    # 文档数据（假设 file_chunk_list() 返回文档块列表）<br/>    document_list = file_chunk_list()<br/>    ids = [str(uuid.uuid4()) for _ in document_list]<br/>    embeddings = [ollama_embedding_by_api(text) for text in document_list]<br/>    collection.add(ids=ids, documents=document_list, embeddings=embeddings)<br/><br/>def rag_run(query):<br/>    """RAG 查询流程"""<br/>    client = chromadb.PersistentClient(path='db/chroma_db')<br/>    collection = client.get_collection(name='collection_v1')<br/><br/>    # 查询向量<br/>    query_embedding = ollama_embedding_by_api(query)<br/>    results = collection.query(<br/>        query_embeddings=[query_embedding],<br/>        query_texts=[query],<br/>        n_results=2<br/>    )<br/><br/>    # 构建上下文与 Prompt<br/>    context = "\n".join(results['documents'][0])<br/>    prompt_template = """你是专家，任务是根据参考信息回答用户问题。<br/>    如果参考信息不足则回复"不知道"。<br/>    请用中文回答。<br/><br/>    参考信息：<br/>    {context}<br/><br/>    问题：{query}<br/>    """<br/>    return prompt_template.format(context=context, query=query)</code>
```

## 🔧 高级配置

<code>import chromadb<br/><br/># 持久化客户端<br/>client = chromadb.PersistentClient(<br/>    path="./chroma_db",<br/>    settings=chromadb.config.Settings(<br/>        anonymized_telemetry=False,<br/>        allow_reset=True<br/>    )<br/>)<br/><br/># 内存客户端（测试用）<br/>client = chromadb.Client()<br/><br/># 集合配置<br/>collection = client.get_or_create_collection(<br/>    name="my_collection",<br/>    metadata={"description": "我的集合"},  # 集合元数据<br/>    get_or_create=True<br/>)</code>

### 2. 相似度搜索配置

```
<code># 基础搜索<br/>results = collection.query(<br/>    query_embeddings=[query_embedding],<br/>    n_results=5<br/>)<br/><br/># 带过滤条件的搜索<br/>results = collection.query(<br/>    query_embeddings=[query_embedding],<br/>    where={"metadata_field": "value"},  # 元数据过滤<br/>    n_results=5<br/>)<br/><br/># MMR 搜索（最大边际相关）<br/>results = collection.query(<br/>    query_embeddings=[query_embedding],<br/>    n_results=10,<br/>    where_document={"$contains": "关键词"},  # 文档内容过滤<br/>    n_results=5  # 最终返回数量<br/>)</code>
```

## 🐛 常见问题

### Q: 向量检索结果不准确？

```
<code># 1. 检查 Embedding 模型是否适合你的领域<br/># 2. 调整相似度top_k数量<br/>results = collection.query(<br/>    query_embeddings=[query_embedding],<br/>    n_results=20  # 增大检索范围<br/>)<br/><br/># 3. 使用 MMR 提高多样性</code>
```

### Q: 如何选择 Embedding 模型？

```
<code># 中文推荐<br/># BAAI/bge-large-zh-v1.5      # 中文最佳<br/># moka-ai/m3e-base             # 中文多模态<br/><br/># 英文推荐<br/># BAAI/bge-large-en-v1.5       # 英文最佳<br/># sentence-transformers/all-MiniLM-L6-v2  # 轻量级<br/><br/># 多语言<br/># intfloat/multilingual-e5-large</code>
```

### Q: 如何优化查询速度？

```
<code># 1. 使用索引<br/>collection.modify(<br/>    hnsw_space='cosine',  # 余弦距离<br/>    hnswConstructionEf=128,<br/>    hnswSearchEf=128<br/>)<br/><br/># 2. 限制返回数量<br/>collection.query(<br/>    query_embeddings=[query_embedding],<br/>    n_results=5  # 限制返回数量<br/>)</code>
```

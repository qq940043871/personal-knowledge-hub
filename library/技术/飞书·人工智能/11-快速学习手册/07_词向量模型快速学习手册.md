## 📋 概述

词向量模型（Embedding Models）将文本转换为高维向量表示，使计算机能够理解和处理语义信息，是 NLP 和 RAG 系统的核心组件。

## 🏗️ 核心概念

```
<code>┌─────────────────────────────────────────────────────┐<br/>│                   词向量工作原理                       │<br/>├─────────────────────────────────────────────────────┤<br/>│                                                     │<br/>│  "国王" ──────────────────────────────→ [0.23, ...] │<br/>│  "女王" ──────────────────────────────→ [0.25, ...] │<br/>│                                                     │<br/>│  向量空间距离: 语义相近的词距离更近                    │<br/>│  king - queen + woman ≈ queen (类比推理)              │<br/>│                                                     │<br/>└─────────────────────────────────────────────────────┘</code>
```

### 3. SiliconFlow Embeddings

```
<code>import os<br/>import requests<br/>from typing import List<br/><br/>class SiliconFlowEmbeddings:<br/>    """SiliconFlow 嵌入模型封装"""<br/><br/>    def __init__(self, api_key: str, model_id: str = "BAAI/bge-large-en-v1.5"):<br/>        self.api_key = api_key<br/>        self.model_id = model_id<br/>        self.api_url = "https://api.siliconflow.cn/v1/embeddings"<br/><br/>    def embed_documents(self, texts: List[str]) -&gt; List[List[float]]:<br/>        """批量获取文档向量"""<br/>        headers = {<br/>            "Content-Type": "application/json",<br/>            "Authorization": f"Bearer {self.api_key}"<br/>        }<br/><br/>        data = {<br/>            "model": self.model_id,<br/>            "input": texts<br/>        }<br/><br/>        response = requests.post(self.api_url, headers=headers, json=data)<br/>        response.raise_for_status()<br/><br/>        return [item["embedding"] for item in response.json()["data"]]<br/><br/>    def embed_query(self, text: str) -&gt; List[float]:<br/>        """获取单个查询向量"""<br/>        return self.embed_documents([text])[0]<br/><br/># 使用示例<br/>embeddings = SiliconFlowEmbeddings(<br/>    api_key=os.environ["SILICONFLOW_API_KEY"],  # key 只走环境变量<br/>    model_id="BAAI/bge-large-zh-v1.5"  # 中文模型<br/>)<br/><br/># 获取查询向量<br/>query_vec = embeddings.embed_query("今天天气怎么样？")<br/><br/># 批量获取文档向量<br/>doc_vecs = embeddings.embed_documents([<br/>    "今天天气很好",<br/>    "明天可能会下雨",<br/>    "今天是晴天"<br/>])</code>
```

### 4. 批量处理 + 相似度计算

```
<code>import numpy as np<br/>from sentence_transformers import SentenceTransformer<br/><br/>model = SentenceTransformer('all-MiniLM-L6-v2')<br/><br/>def compute_similarity(text1, text2):<br/>    """计算两个文本的相似度"""<br/>    vec1 = model.encode([text1])<br/>    vec2 = model.encode([text2])<br/><br/>    # 余弦相似度<br/>    similarity = np.dot(vec1[0], vec2[0]) / (<br/>        np.linalg.norm(vec1[0]) * np.linalg.norm(vec2[0])<br/>    )<br/>    return similarity<br/><br/># 使用示例<br/>texts = [<br/>    "机器学习是人工智能的分支",<br/>    "深度学习是机器学习的一部分",<br/>    "今天天气很不错"<br/>]<br/><br/># 批量编码<br/>embeddings = model.encode(texts)<br/><br/># 两两计算相似度<br/>for i in range(len(texts)):<br/>    for j in range(i + 1, len(texts)):<br/>        sim = compute_similarity(texts[i], texts[j])<br/>        print(f"'{texts[i]}' vs '{texts[j]}': {sim:.4f}")</code>
```

### 5. Ollama RAG 中的 Embedding 使用

```
<code>import chromadb<br/>import requests<br/>import uuid<br/><br/>def ollama_embedding(text):<br/>    """获取文本向量"""<br/>    res = requests.post(<br/>        "http://localhost:11434/api/embeddings",<br/>        json={"model": "nomic-embed-text", "prompt": text}<br/>    )<br/>    return res.json()["embedding"]<br/><br/>def init_vector_db(documents):<br/>    """初始化向量数据库"""<br/>    client = chromadb.PersistentClient(path='db/chroma_db')<br/>    collection = client.get_or_create_collection(name='docs')<br/>    ids = [str(uuid.uuid4()) for _ in documents]<br/>    embeddings = [ollama_embedding(doc) for doc in documents]<br/>    collection.add(ids=ids, documents=documents, embeddings=embeddings)<br/>    return collection<br/><br/>def search_similar(query, collection, top_k=3):<br/>    """相似性搜索"""<br/>    query_vec = ollama_embedding(query)<br/>    results = collection.query(query_embeddings=[query_vec], n_results=top_k)<br/>    return results['documents'][0]<br/><br/># 使用示例<br/>docs = [<br/>    "人工智能是指计算机系统模拟人类智能",<br/>    "机器学习是实现人工智能的方法",<br/>    "深度学习是机器学习的一个分支"<br/>]<br/><br/>collection = init_vector_db(docs)<br/><br/># 搜索<br/>results = search_similar("什么是机器学习？", collection)<br/>for i, doc in enumerate(results, 1):<br/>    print(f"{i}. {doc}")</code>
```

### Q: 相似度计算方式？

```
<code>import numpy as np<br/><br/>def cosine_similarity(a, b):<br/>    """余弦相似度"""<br/>    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))<br/><br/>def euclidean_distance(a, b):<br/>    """欧氏距离"""<br/>    return np.linalg.norm(np.array(a) - np.array(b))<br/><br/>def dot_product(a, b):<br/>    """点积（未归一化）"""<br/>    return np.dot(a, b)</code>
```

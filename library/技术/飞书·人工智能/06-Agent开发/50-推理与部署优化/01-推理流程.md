推理主链路骨架如下（伪代码：重点在特殊点，不在实现细节）；完整可运行实现见 ownrag/harness 参考工程。

```
<code>import torch<br/>import torch.nn.functional as F<br/><br/><br/>class ModelConfig:   # 示意：生产直接用 transformers.AutoConfig，无需自写<br/>    def __init__(self, max_length=100, temperature=1.0):<br/>        self.max_length, self.temperature = max_length, temperature<br/><br/><br/>class TransformerInference:<br/>    """Transformer 推理（model 为任意 HF CausalLM 风格对象）"""<br/><br/>    def __init__(self, model, config: ModelConfig, tokenizer=None):<br/>        self.model = model<br/>        self.config = config<br/>        self.kv_cache = None<br/>        #   ★特殊点1 eos_token_id 必须从 tokenizer 注入，否则第一次判停就是 AttributeError（不隐式假设全局状态）<br/>        self.eos_token_id = (tokenizer.eos_token_id<br/>                             if tokenizer is not None else None)<br/><br/>    def forward(self, input_ids: torch.Tensor) -&gt; torch.Tensor:<br/>        # 前向骨架：Embedding → N 层 Transformer → final_layernorm → lm_head<br/>        hidden_states = self.model.embed_tokens(input_ids)<br/>        for layer in self.model.layers:<br/>            raise NotImplementedError("单层实现（Self-Attention + FFN + 残差归一化）从略；注意力见 07-Multi-Head-Attention.md")<br/>        return self.model.lm_head(self.model.final_layernorm(hidden_states))<br/><br/>    def generate(self, input_ids: torch.Tensor, max_length: int = 100,<br/>                 temperature: float = 1.0) -&gt; torch.Tensor:<br/>        #   ★特殊点2 循环必须有界：max_length 上限 + eos 判停双保险<br/>        #     （对应 Agent 主循环的 max_turns + 停止条件）<br/>        for _ in range(max_length):<br/>            logits = self.forward(input_ids)[:, -1, :]<br/><br/>            #   ★特殊点3 边界参数显式分支：temperature=0（贪婪）走 argmax，<br/>            #     绝不让 multinomial 在近似单点分布上因浮点误差崩溃<br/>            if temperature &lt;= 1e-5:<br/>                next_token = logits.argmax(dim=-1, keepdim=True)<br/>            else:                      # temperature&gt;0：按温度缩放后采样<br/>                probs = F.softmax(logits / temperature, dim=-1)<br/>                next_token = torch.multinomial(probs, 1)<br/><br/>            input_ids = torch.cat([input_ids, next_token], dim=-1)<br/><br/>            # 停止条件：eos_token_id 未配置时不判停，仅受 max_length 有界约束<br/>            if (self.eos_token_id is not None<br/>                    and next_token.item() == self.eos_token_id):<br/>                break<br/><br/>        return input_ids</code>
```

---

---

- **循环必须有界**：`max_length` 上限 + eos 判停双保险，对应 Agent 主循环的 max_turns + 停止条件——参考 `ai-agent-harness/harness/main_loop.py` 的有界 for 循环。
- **边界参数显式分支**：`temperature=0` 走贪婪而非让 `multinomial` 崩溃；同理 Agent 中超时、预算等边界都应显式处理——参考 `main_loop.py` 的 token 预算熔断。
- **依赖显式初始化**：`eos_token_id` 从 tokenizer 注入，而非隐式假设全局状态——对应 harness 中 provider/config 全部构造器注入的风格（`harness/provider/`）。
- **未实现处明示**：单层前向以 `raise NotImplementedError` 明示未完成，而不是静默返回错误结果——与 `ai-agent-harness/tests/` 的可测性约定一致。
- **生产推理引擎**：本文是教学级逐步 decode；生产请用 vLLM / TensorRT-LLM（连续批处理 + PagedAttention + 内置采样），参见本目录后续几篇。

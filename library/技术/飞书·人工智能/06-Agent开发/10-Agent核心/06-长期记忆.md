## 长期记忆的最小实现：Embedding + 向量存储

核心思路：**写入时先算 Embedding 存入向量库，召回时用查询向量做相似度检索取 Top-K**。

```python
class LongTermMemory:
    """长期记忆（向量存储）"""

    def __init__(self, vector_store: VectorStore):
        self.vector_store = vector_store

    async def store(self, content: str, metadata: Dict):
        embedding = await embed(content)
        self.vector_store.add(embedding, content, metadata)

    async def recall(self, query: str, top_k: int = 5) -> List[Dict]:
        query_emb = await embed(query)
        results = await self.vector_store.search(query_emb, top_k)
        return results
```

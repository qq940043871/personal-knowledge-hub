# 长期记忆

> 模块：记忆系统  
> 更新时间：2026-11-15

---

---

核心思路：**写入时先算 Embedding 存入向量库，召回时用查询向量做相似度检索取 Top-K**。工程要点：Embedding 客户端必须**构造器注入**（`self.embedder`）——如果方法内直接调用裸全局函数 `embed(...)`，类就退化成「只能全局配置一种嵌入模型」的硬编码，无法测试、无法替换供应商，且全局函数未定义时一调用就 `NameError`。

```
<code># 长期记忆（伪代码：重点在依赖注入与特殊点）<br/>import logging<br/>from typing import Dict, List, Protocol<br/><br/>logger = logging.getLogger(__name__)<br/><br/><br/>class Embedder(Protocol):<br/>    """嵌入客户端协议：任何提供 embed 的实现都可注入（OpenAI / 本地模型）"""<br/><br/>    async def embed(self, text: str) -&gt; List[float]:<br/>        ...<br/><br/><br/>class VectorStore(Protocol):<br/>    """向量库协议：add 写入 / search 相似度检索（生产换 FAISS / Milvus / pgvector）"""<br/><br/>    async def add(self, embedding: List[float], content: str,<br/>                  metadata: Dict) -&gt; str:<br/>        ...<br/><br/>    async def search(self, query_emb: List[float],<br/>                     top_k: int) -&gt; List[Dict]:<br/>        ...    # 余弦相似度分母加 eps 防零向量 NaN<br/><br/><br/># OpenAIEmbedder（Key 走环境变量 + 显式超时）与内存向量库实现从略——<br/># 完整实现见 ai-agent-harness 工程</code>
```

```
<code>class LongTermMemory:<br/>    """长期记忆：写入先嵌入入库，召回按查询向量检索 Top-K"""<br/><br/>    def __init__(self, vector_store: VectorStore, embedder: Embedder,<br/>                 top_k_default: int = 5):<br/>        self.vector_store = vector_store<br/>        self.embedder = embedder          # ★特殊点1 构造器注入，不得绕过<br/>        self.top_k_default = top_k_default<br/>        #   方法内若直接调裸全局 embed()：类退化为「全局唯一嵌入模型」<br/>        #   的硬编码——无法测试、无法换供应商，函数缺失即 NameError<br/><br/>    async def store(self, content: str, metadata: Dict) -&gt; str:<br/>        if not content.strip():<br/>            raise ValueError("不能写入空记忆")       # ★特殊点2 校验前置<br/>        embedding = await self.embedder.embed(content)  # 只走 self.embedder<br/>        return await self.vector_store.add(embedding, content, metadata)<br/><br/>    async def recall(self, query: str, top_k: int = None) -&gt; List[Dict]:<br/>        top_k = top_k or self.top_k_default<br/>        query_emb = await self.embedder.embed(query)    # 只走 self.embedder<br/>        results = await self.vector_store.search(query_emb, top_k)<br/>        logger.info("召回 %s/%s 条记忆", len(results), top_k)  # ★特殊点3 留痕<br/>        return results<br/><br/><br/># ★特殊点4 换嵌入模型必须换 embed_version 并全量重灌：新旧模型的向量<br/>#   空间不兼容，混存会让相似度检索结果失真</code>
```

`store` 与 `recall` 都通过 `self.embedder` 访问嵌入能力：换供应商只改构造参数；单测注入一个返回固定向量的假 Embedder 即可，无需真实网络调用。

---

---

- **依赖注入而非全局函数**：`self.embedder` 构造器注入，与 `self.vector_store` 同构——对应 `ai-agent-harness/harness/provider/` 的 Provider 抽象（模型调用可插拔）。
- **Protocol 声明最小接口**：`Embedder` / `VectorStore` 用 `typing.Protocol`，实现方无需继承——参考 `harness/memory_manager.py` 的记忆分层接口。
- **召回留痕**：recall 记录命中数与查询摘要，便于评估检索质量——参考 `ai-agent-harness/harness/tracer.py`。
- **输入校验前置**：空内容拒绝写入，避免污染向量库——与 harness 中工具入参校验（`ToolArgumentError`）同一思想，见 `harness/tools/registry.py`。
- **数值健壮性**：余弦相似度分母加 eps 防零向量 NaN；top_k 提供默认值可覆盖。

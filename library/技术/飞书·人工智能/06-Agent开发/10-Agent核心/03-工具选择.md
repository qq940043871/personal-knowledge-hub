> 模块：Agent编排  
> 更新时间：2026-11-15

> 工具路由器的三步流程：① 语义匹配（Query 与工具描述的 Embedding 余弦相似度）→ ② 按得分降序排序 → ③ 阈值过滤（仅保留得分超过阈值的工具）。**关键性能点：工具描述是静态的，向量只需在初始化时计算一次并缓存**；每次查询只应嵌入 query 本身——如果在 route 里对每个工具描述反复 embed，N 个工具的 Agent 每次路由都多出 N 次网络调用，纯属浪费。

```
<code># 工具路由器（伪代码：重点在预嵌入缓存与特殊点）<br/>from dataclasses import dataclass<br/>from typing import List<br/><br/>from harness.embedder import Embedder, cosine_similarity<br/>#   ↑ Embedder(Protocol) / OpenAIEmbedder / cosine_similarity 实现从略：<br/>#     依赖注入最小接口 + eps 防除零，见 06-长期记忆.md 与 ai-agent-harness 工程<br/><br/><br/>@dataclass<br/>class Tool:<br/>    name: str<br/>    description: str             # description 是静态的 → 向量只需算一次<br/><br/><br/>class ToolRouter:<br/>    """路由三步：① 语义匹配 → ② 降序排序 → ③ 阈值过滤"""<br/><br/>    def __init__(self, tools: List[Tool], embedder: Embedder,<br/>                 threshold: float = 0.7,     # ★特殊点1 阈值可配置：构造参数<br/>                 top_k: int = 3):            #   外置，不硬编码魔法数字<br/>        self.tools = tools<br/>        self.embedder = embedder<br/>        self.threshold = threshold<br/>        self.top_k = top_k<br/>        self._tool_embs: List[tuple] = []    # [(tool, embedding)] 预嵌入缓存<br/><br/>    async def setup(self) -&gt; None:<br/>        #   ★特殊点2 工具描述是静态的：__init__/setup 建一次缓存——整个<br/>        #     生命周期只算 N 次；在 route 里反复嵌入 = 每次查询多出 N 次<br/>        #     网络调用，纯属浪费<br/>        self._tool_embs = [(t, await self.embedder.embed(t.description))<br/>                           for t in self.tools]<br/><br/>    async def route(self, query: str) -&gt; List[Tool]:<br/>        if not self._tool_embs:<br/>            await self.setup()               # 忘调 setup 时的懒加载兜底<br/>        query_emb = await self.embedder.embed(query)  # 每次查询只嵌 query<br/>        #   ★特殊点3 embed 调用失败不炸路由：捕获后降级为返回全部工具，<br/>        #     让 LLM 自选<br/>        scored = [(t, cosine_similarity(query_emb, emb))<br/>                  for t, emb in self._tool_embs]<br/>        scored.sort(key=lambda x: x[1], reverse=True)   # ② 按得分降序<br/>        hits = [t for t, s in scored if s &gt; self.threshold]  # ③ 先阈值过滤<br/>        return hits[:self.top_k]             # ★特殊点4 再截 top_k——顺序不能<br/>                                             #   反，否则高阈值下漏掉合格工具<br/><br/><br/># 用法：router.setup() 预嵌入一次 → route("上海今天会下雨吗") -&gt; ['get_weather']<br/># 工具集动态增删时：按工具名增量缓存，把缓存失效挂在注册/注销钩子上</code>
```

*完整实现见 ai-agent-harness 工程。*

```
<code>错误做法（每次 route）：                正确做法（预嵌入缓存）：<br/><br/>route(query)                           __init__/setup()          route(query)<br/>  embed(query)        1 次               embed(工具1描述) 1 次      embed(query) 1 次<br/>  embed(工具1描述)     1 次  ← 重复       embed(工具2描述) 1 次      读缓存 + 余弦相似度<br/>  embed(工具2描述)     1 次  ← 重复       ...（此后不再计算）<br/>  ...<br/>  N 个工具 → 每次查询 N+1 次调用         每次查询只有 1 次调用</code>
```

工具集合**静态**时预嵌入即可；工具集**动态增删**时，可按工具名做增量缓存（新增时才嵌入），并把缓存失效挂在注册/注销钩子上。

---

---

- **静态内容绝不重复计算**：工具描述预嵌入缓存对应 harness「工具定义只在启动时构建一次」的思想——参考 `ai-agent-harness/harness/tools/registry.py`（注册时一次性推断 schema，`get_definitions` 直接读表）。
- **可配置阈值**：路由阈值/`top_k` 走构造参数而非魔法数字，便于按业务调优——对应 `ai-agent-harness/config/config.yaml` 的外置配置模式。
- **依赖注入 + Protocol**：`Embedder` 用 `Protocol` 声明最小接口，便于替换与单测 mock——参考 harness 的 Provider 抽象 `ai-agent-harness/harness/provider/`。
- **数值健壮性**：余弦相似度分母加 eps 防零向量 NaN；先阈值过滤再截断 top_k，避免「高阈值下因 top_k 先截断而漏掉合格工具」。
- **失败即结果**：embedding 调用失败不应炸路由，生产中应捕获后降级为「返回全部工具让 LLM 自选」——参考 `harness/main_loop.py` 中工具失败转消息回传的自愈模式。

## 切分策略：固定大小切分 vs 按句子切分

核心思路：**固定大小切分按「步长 = chunk_size − chunk_overlap」滑窗切块，相邻块保留 overlap 重叠；按句子切分则先中文正则分句（`nltk.sent_tokenize` 对中文无效且需预下载 punkt），累积拼块、句子完整不被截断，单句超长时二次硬切**。切块同时注入 metadata（文档标题/章节），溯源与检索过滤都靠它。

```python
import re
from typing import List

class TextSplitter:
    """文本切分器（中文口径）：正则分句不依赖 nltk；步长 = size − overlap"""

    _SENT_RE = re.compile(r"(?<=[。！？；\n])")  # 句末标点/换行之后断开

    def __init__(self, chunk_size: int = 500, chunk_overlap: int = 50):
        if chunk_overlap >= chunk_size:          # ★特殊点1 配置错误启动期暴露：
            raise ValueError(f"chunk_overlap({chunk_overlap}) 必须小于 chunk_size({chunk_size})")
            #   overlap >= size 会让滑窗原地踏步甚至倒退（死循环）
        self.chunk_size, self.chunk_overlap = chunk_size, chunk_overlap

    def split_sentences(self, text: str) -> List[str]:
        """中文分句：按句末标点/换行断开（nltk.sent_tokenize 只认英文标点，中文无效）"""
        parts = self._SENT_RE.split(text)
        return [part for part in (s.strip() for s in parts) if part]

    def split_by_sentences(self, text: str) -> List[str]:
        """按句子切分：句子累积封块；单句超长二次硬切；相邻块回带整句 overlap"""
        fixed: List[str] = []
        for sent in self.split_sentences(text):
            if len(sent) <= self.chunk_size:
                fixed.append(sent)
                continue
            step = self.chunk_size - self.chunk_overlap
            for i in range(0, len(sent), step):     # ★特殊点2 单句二次硬切成子句：
                piece = sent[i:i + self.chunk_size]
                if piece:
                    fixed.append(piece)             #   否则一个超长句子永远塞不进任何块
        chunks, current, current_length = [], [], 0
        for sentence in fixed:
            if current_length + len(sentence) > self.chunk_size and current:
                chunks.append("".join(current))     # 中文句子直接拼接，无需空格
                tail: List[str] = []
                tail_length = 0
                for prev in reversed(current):      # ★特殊点3 overlap 回带：从上一块
                    if tail_length + len(prev) > self.chunk_overlap:
                        break                       #   尾部收集不超过 chunk_overlap 的
                    tail.insert(0, prev)            #   整句（不是半个句）回带到下一块
                    tail_length += len(prev)
                current = tail + [sentence]
                current_length = sum(len(s) for s in current)
            else:
                current.append(sentence)
                current_length += len(sentence)
        if current:
            chunks.append("".join(current))
        return chunks
```

**overlap 语义的两个坑**：

- 固定窗口路径：步长必须是 `chunk_size - chunk_overlap`。若把「窗口起点 = 上一窗口终点 − overlap」写成终点之外还要再退一次，尾块会与上一块近乎全重叠，等于同一内容入库两遍。
- 句子路径：原实现完全没有 overlap——一旦一个主题跨块，下一块开头的「它/该规定」就失去指代对象。回带若干完整句（不是半个句）到下一块开头即可修复。

### 企业级升级要点

- **结构感知切分优先于字符滑窗**：标题树、表格锚点先切语义段再拼块——索引侧决定检索天花板，见 `ai-rag-self-engineering/ownrag/ownrag/index/chunker.py`（表格永不跨块、标题路径记录进 anchors）。
- **切分与预算同一套 token 口径**：块长估算与生成侧上下文预算共用 `est_tokens`，避免「切分按一套口径、预算按另一套」的两本账，见 `ai-rag-self-engineering/ownrag/ownrag/tokens.py`。
- **块 metadata 注入来源**：文档标题/章节路径随块入库，答案才能溯源到「哪份文档哪个章节」，见 `ai-rag-self-engineering/ownrag/ownrag/index/chunker.py` 的 `Chunk.meta` 与 anchors。
- **切分参数变更必须过评测集回归**：chunk_size/overlap 改动等于换索引，没有评测集不要动——见 `ai-rag-self-engineering/ownrag/ownrag/index/chunker.py` 模块注释。

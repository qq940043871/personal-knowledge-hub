手写 HNSW 教学代码极易写错（分层插入、入口点传递、候选堆类型都有坑），生产直接用成熟库。hnswlib 是 HNSW 的参考实现，也是 Chroma/FAISS 内置 HNSW 的同源算法。

```
<code>import numpy as np<br/>import hnswlib  # 依赖：pip install hnswlib<br/><br/>dim = 1024<br/>max_elements = 100_000<br/><br/># 构造三要素：<br/>#   space           距离度量：'cosine' 余弦 / 'l2' 欧氏 / 'ip' 内积<br/>#   M               每个节点 outgoing 连接数上限：越大召回越高、内存越高（常用 16~48）<br/>#   ef_construction 建图搜索宽度：越大索引质量越高、建库越慢（常用 200）<br/>index = hnswlib.Index(space="cosine", dim=dim)<br/>index.init_index(max_elements=max_elements, ef_construction=200, M=16)<br/>index.set_ef(50)  # 查询搜索宽度 ef：召回-延迟的直接旋钮（必须 &gt;= k）<br/><br/># 灌入向量（示意：真实数据来自 Embedding 生成）<br/>vectors = np.random.rand(10_000, dim).astype("float32")<br/>vectors /= np.linalg.norm(vectors, axis=1, keepdims=True) + 1e-12<br/>ids = np.arange(10_000)<br/>index.add_items(vectors, ids)   # capacity 不足会扩容重建，尽量一次给足<br/><br/># 查询：knn_query 返回 (labels, distances)<br/># cosine 空间下 distances = 1 - 余弦相似度，越小越相关<br/>query = np.random.rand(1, dim).astype("float32")<br/>query /= np.linalg.norm(query) + 1e-12<br/>labels, distances = index.knn_query(query, k=5)<br/>for doc_id, dist in zip(labels[0], distances[0]):<br/>    print(f"doc={int(doc_id)} 余弦相似度={1 - float(dist):.4f}")<br/><br/># 持久化与恢复<br/>index.save_index("vectors.hnsw")<br/># index = hnswlib.Index(space="cosine", dim=dim)<br/># index.load_index("vectors.hnsw")</code>
```

**ef 调参说明**：

- `ef` 是查询时维护的候选队列宽度，**必须 ≥ k**；太小漏召回、太大白算。经验起步 `ef = 2 × k`，再用评测集压测校准——没有评测集之前调 ef/M 都是猜。
- `M` 调上去内存线性涨，先固定 16 看 ef 是否够，再动 M。
- 加数据后 `set_ef` 也可按查询负载单独调（在线可改，不用重建索引）。

一份正确的对照组实现——任何近似索引上线前，都用它验证召回质量。

```
<code>import numpy as np<br/><br/><br/>def brute_cosine_search(matrix: np.ndarray, query: np.ndarray, k: int = 5):<br/>    """教学参考：暴力余弦检索（O(n) 全量比对）。<br/>    万条以内毫秒级、100% 准确；同时是近似索引召回质量的对照组。"""<br/>    norms = np.linalg.norm(matrix, axis=1, keepdims=True) + 1e-12<br/>    q = query / (np.linalg.norm(query) + 1e-12)<br/>    sims = (matrix / norms) @ q                # 全量余弦相似度<br/>    top = np.argsort(-sims)[:k]<br/>    return [(int(i), float(sims[i])) for i in top]</code>
```

- **规模没到不用 ANN**：ownrag 直接用 Chroma 的 HNSW 承载向量通道、SQLite FTS5 承载关键词通道，见 `ai-rag-self-engineering/ownrag/ownrag/index/store.py`（双通道存储，按 doc_id 原子替换）。

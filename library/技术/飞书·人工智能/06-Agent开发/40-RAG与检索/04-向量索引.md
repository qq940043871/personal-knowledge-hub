## 一、索引类型

```text
向量索引类型：
  1. FLAT（暴力搜索）
     - O(n)遍历
     - 100%准确

  2. IVF（倒排文件）
     - 聚类后搜索
     - 近似准确

  3. HNSW（分层可导航小世界）
     - 图索引
     - 高召回高速

  4. PQ（乘积量化）
     - 有损压缩
     - 内存占用低
```

选型速记：万条以内暴力扫就够（毫秒级、100% 准确）；十万到千万级选 HNSW（召回/延迟综合最优）；内存紧张用 PQ 压缩；IVF 适合超大规模冷数据。**规模没到之前不要为 ANN 买单**。

## 二、HNSW实现：hnswlib

手写 HNSW 教学代码极易写错（分层插入、入口点传递、候选堆类型都有坑），生产直接用成熟库。hnswlib 是 HNSW 的参考实现，也是 Chroma/FAISS 内置 HNSW 的同源算法。

```python
import numpy as np
import hnswlib  # 依赖：pip install hnswlib

dim = 1024
max_elements = 100_000

# 构造三要素：
#   space           距离度量：'cosine' 余弦 / 'l2' 欧氏 / 'ip' 内积
#   M               每个节点 outgoing 连接数上限：越大召回越高、内存越高（常用 16~48）
#   ef_construction 建图搜索宽度：越大索引质量越高、建库越慢（常用 200）
index = hnswlib.Index(space="cosine", dim=dim)
index.init_index(max_elements=max_elements, ef_construction=200, M=16)
index.set_ef(50)  # 查询搜索宽度 ef：召回-延迟的直接旋钮（必须 >= k）

# 灌入向量（示意：真实数据来自 Embedding 生成）
vectors = np.random.rand(10_000, dim).astype("float32")
vectors /= np.linalg.norm(vectors, axis=1, keepdims=True) + 1e-12
ids = np.arange(10_000)
index.add_items(vectors, ids)   # capacity 不足会扩容重建，尽量一次给足

# 查询：knn_query 返回 (labels, distances)
# cosine 空间下 distances = 1 - 余弦相似度，越小越相关
query = np.random.rand(1, dim).astype("float32")
query /= np.linalg.norm(query) + 1e-12
labels, distances = index.knn_query(query, k=5)
for doc_id, dist in zip(labels[0], distances[0]):
    print(f"doc={int(doc_id)} 余弦相似度={1 - float(dist):.4f}")

# 持久化与恢复
index.save_index("vectors.hnsw")
# index = hnswlib.Index(space="cosine", dim=dim)
# index.load_index("vectors.hnsw")
```

**ef 调参说明**：

- `ef` 是查询时维护的候选队列宽度，**必须 ≥ k**；太小漏召回、太大白算。经验起步 `ef = 2 × k`，再用评测集压测校准——没有评测集之前调 ef/M 都是猜。
- `M` 调上去内存线性涨，先固定 16 看 ef 是否够，再动 M。
- 加数据后 `set_ef` 也可按查询负载单独调（在线可改，不用重建索引）。

## 三、教学参考：暴力余弦检索

一份正确的对照组实现——任何近似索引上线前，都用它验证召回质量。

```python
import numpy as np


def brute_cosine_search(matrix: np.ndarray, query: np.ndarray, k: int = 5):
    """教学参考：暴力余弦检索（O(n) 全量比对）。
    万条以内毫秒级、100% 准确；同时是近似索引召回质量的对照组。"""
    norms = np.linalg.norm(matrix, axis=1, keepdims=True) + 1e-12
    q = query / (np.linalg.norm(query) + 1e-12)
    sims = (matrix / norms) @ q                # 全量余弦相似度
    top = np.argsort(-sims)[:k]
    return [(int(i), float(sims[i])) for i in top]
```

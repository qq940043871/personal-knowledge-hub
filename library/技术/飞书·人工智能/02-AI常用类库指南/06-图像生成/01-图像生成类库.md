### 1. Stable Diffusion (Diffusers)

**特点**：开源最强、支持LoRA/ControlNet、显存要求低

```
<code>pip install diffusers transformers accelerate safetensors</code>
```

```
<code>from diffusers import StableDiffusionPipeline<br/>import torch<br/><br/># 加载模型<br/>pipe = StableDiffusionPipeline.from_pretrained(<br/>    "runwayml/stable-diffusion-v1-5",<br/>    torch_dtype=torch.float16,<br/>    safety_checker=None<br/>)<br/>pipe = pipe.to("cuda" if torch.cuda.is_available() else "cpu")<br/><br/># 文生图<br/>prompt = "a beautiful sunset over the ocean, highly detailed, 8k"<br/>image = pipe(prompt, num_inference_steps=50, guidance_scale=7.5).images[0]<br/><br/># 保存<br/>image.save("output.png")<br/><br/># 图生图<br/>from diffusers import StableDiffusionImg2ImgPipeline<br/><br/>pipe_img2img = StableDiffusionImg2ImgPipeline.from_pretrained(<br/>    "runwayml/stable-diffusion-v1-5"<br/>)<br/>pipe_img2img = pipe_img2img.to("cuda")<br/><br/>init_image = Image.open("input.jpg").convert("RGB")<br/>init_image = init_image.resize((512, 512))<br/><br/>image = pipe_img2img(<br/>    prompt="变成动漫风格",<br/>    image=init_image,<br/>    strength=0.75,  # 改变程度 0-1<br/>    guidance_scale=7.5<br/>).images[0]<br/>image.save("output_img2img.png")</code>
```

### 2. ControlNet

**特点**：精确控制生成、姿态/边缘/深度等多种控制

```
<code>pip install controlnet-aux</code>
```

```
<code>from diffusers import StableDiffusionControlNetPipeline, ControlNetModel<br/>from controlnet_aux import OpenposeDetector<br/>from PIL import Image<br/>import torch<br/><br/># 加载ControlNet<br/>controlnet = ControlNetModel.from_pretrained(<br/>    "lllyasviel/sd-controlnet-openpose",<br/>    torch_dtype=torch.float16<br/>)<br/><br/># 加载主模型<br/>pipe = StableDiffusionControlNetPipeline.from_pretrained(<br/>    "runwayml/stable-diffusion-v1-5",<br/>    controlnet=controlnet,<br/>    torch_dtype=torch.float16<br/>)<br/>pipe = pipe.to("cuda")<br/><br/># 检测姿态<br/>detector = OpenposeDetector.from_pretrained("lllyasviel/control_v11p_sd15_openpose")<br/>pose_image = detector(Image.open("person.jpg"))<br/><br/># 生成<br/>prompt = "a woman dancing in the park, highly detailed"<br/>image = pipe(<br/>    prompt,<br/>    image=pose_image,<br/>    num_inference_steps=20,<br/>    controlnet_conditioning_scale=1.0<br/>).images[0]<br/>image.save("output_pose.png")<br/><br/># 其他ControlNet类型<br/># canny: 边缘检测 -&gt; lllyasviel/sd-controlnet-canny<br/># depth: 深度图 -&gt; lllyasviel/sd-controlnet-depth<br/># hed: 软边缘 -&gt; lllyasviel/sd-controlnet-hed</code>
```

### 3. CLIP + 图像生成

```
<code>from transformers import CLIPProcessor, CLIPModel<br/>from PIL import Image<br/>import torch<br/><br/># 加载CLIP<br/>model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")<br/>processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")<br/><br/># 计算图像-文本相似度<br/>image = Image.open("dog.jpg")<br/>texts = ["a dog", "a cat", "a car"]<br/><br/>inputs = processor(text=texts, images=image, return_tensors="pt", padding=True)<br/>outputs = model(**inputs)<br/><br/>logits_per_image = outputs.logits_per_image<br/>probs = logits_per_image.softmax(dim=1)<br/><br/>print("图像-文本匹配概率:")<br/>for text, prob in zip(texts, probs[0]):<br/>    print(f"  {text}: {prob.item():.2%}")<br/><br/># 零样本图像分类<br/>def zero_shot_classify(image, labels):<br/>    """给定标签列表，对图像进行分类"""<br/>    inputs = processor(text=labels, images=image, return_tensors="pt", padding=True)<br/>    outputs = model(**inputs)<br/>    probs = outputs.logits_per_image.softmax(dim=1)<br/>    return {label: prob.item() for label, prob in zip(labels, probs[0])}<br/><br/># 使用<br/>labels = ["a photo of a cat", "a photo of a dog", "a photo of a bird"]<br/>result = zero_shot_classify(Image.open("animal.jpg"), labels)<br/>print(result)</code>
```

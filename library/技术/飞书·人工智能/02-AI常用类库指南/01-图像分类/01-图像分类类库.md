### 图像分类原理

```
<code>输入图像 → 卷积层(特征提取) → 池化层(降维) → 全连接层 → 分类输出<br/><br/>卷积层: 3x3/5x5卷积核滑动，提取局部特征<br/>池化层: MaxPooling/AvgPooling，减少参数<br/>全连接层: 将特征映射到类别概率<br/>Softmax: 将输出转为概率分布</code>
```

### 1. timm (PyTorch Image Models)

**特点**：收录最多预训练模型的库，1000+模型

```
<code>pip install timm</code>
```

```
<code>import timm<br/>import torch<br/>from PIL import Image<br/><br/># 加载模型<br/>model = timm.create_model('resnet50', pretrained=True)<br/>model.eval()<br/><br/># 图片预处理<br/>data_config = timm.data.resolve_model_data_config(model)<br/>transforms = timm.data.create_transform(**data_config, is_training=False)<br/><br/># 推理<br/>img = Image.open('cat.jpg').convert('RGB')<br/>tensor = transforms(img).unsqueeze(0)<br/><br/>with torch.no_grad():<br/>    output = model(tensor)<br/><br/># 获取预测类别<br/>probabilities = torch.nn.functional.softmax(output[0], dim=0)<br/>top5_prob, top5_catid = torch.topk(probabilities, 5)<br/><br/># ImageNet标签<br/>labels = timm.data.get_imagenet_labels()<br/>for i in range(5):<br/>    print(f"{labels[top5_catid[i]]}: {top5_prob[i].item():.2%}")</code>
```

### 2. torchvision

**特点**：PyTorch官方视觉库，预训练模型丰富

```
<code>pip install torchvision</code>
```

```
<code>import torchvision.models as models<br/>import torchvision.transforms as transforms<br/>import torch<br/>from PIL import Image<br/><br/># 加载ResNet50<br/>model = models.resnet50(weights=models.ResNet50_Weights.DEFAULT)<br/>model.eval()<br/><br/># 图片预处理<br/>preprocess = transforms.Compose([<br/>    transforms.Resize(256),<br/>    transforms.CenterCrop(224),<br/>    transforms.ToTensor(),<br/>    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),<br/>])<br/><br/>img = Image.open('cat.jpg')<br/>img_t = preprocess(img)<br/>batch_t = torch.unsqueeze(img_t, 0)<br/><br/># 推理<br/>with torch.no_grad():<br/>    output = model(batch_t)<br/><br/># 获取Top-5预测<br/>_, indices = torch.sort(output, descending=True)<br/>probabilities = torch.nn.functional.softmax(output[0], dim=0)<br/><br/># CATEGORIES列表需要单独加载<br/>print(f"预测类别ID: {indices[0].item()}, 概率: {probabilities[indices[0]].item():.2%}")</code>
```

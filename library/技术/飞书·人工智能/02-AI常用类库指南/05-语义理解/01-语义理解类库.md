### 语义理解原理

```
<code>文本 → 分词/编码 → Transformer编码 → 语义向量 → 相似度计算/匹配<br/><br/>核心任务：<br/>1. 语义相似度：计算两个文本的语义距离<br/>2. 文本匹配：判断两个文本是否匹配<br/>3. 语义搜索：在大量文本中找到最相关的<br/>4. 问答匹配：找到问题的最佳答案</code>
```

### 1. Sentence-Transformers

**特点**：语义向量最全、支持多语言、效果最好

```
<code>pip install sentence-transformers</code>
```

```
<code>from sentence_transformers import SentenceTransformer<br/>from sklearn.metrics.pairwise import cosine_similarity<br/>import numpy as np<br/><br/># 加载模型<br/>model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')<br/><br/># 编码单个文本<br/>embedding = model.encode("我喜欢深度学习")<br/>print(f"向量维度: {embedding.shape}")  # (384,)<br/><br/># 编码多个文本<br/>sentences = [<br/>    "人工智能将改变世界",<br/>    "机器学习是AI的核心技术",<br/>    "深度学习在图像识别上很强大",<br/>    "今天天气真好"<br/>]<br/><br/>embeddings = model.encode(sentences)<br/>print(f"向量矩阵: {embeddings.shape}")  # (4, 384)<br/><br/># 计算余弦相似度<br/>similarity = cosine_similarity([embeddings[0]], [embeddings[1]])[0][0]<br/>print(f"相似度: {similarity:.4f}")  # 0.7xx<br/><br/># 语义搜索<br/>query = "什么是机器学习？"<br/>query_emb = model.encode(query)<br/><br/># 计算与所有句子的相似度<br/>similarities = cosine_similarity([query_emb], embeddings)[0]<br/>top_idx = np.argsort(similarities)[::-1]<br/><br/>print(f"\n搜索: {query}")<br/>for idx in top_idx[:3]:<br/>    print(f"  {similarities[idx]:.4f} - {sentences[idx]}")</code>
```

<code>import numpy as np<br/>import faiss<br/><br/># 生成示例数据(10000个128维向量)<br/>dimension = 128<br/>num_vectors = 10000<br/>np.random.seed(42)<br/><br/>vectors = np.random.random((num_vectors, dimension)).astype('float32')<br/><br/># 构建索引<br/>index = faiss.IndexFlatL2(dimension)  # L2距离<br/># 或使用内积索引<br/># index = faiss.IndexFlatIP(dimension)  # 余弦相似度<br/><br/>index.add(vectors)<br/>print(f"索引中向量数: {index.ntotal}")<br/><br/># 查询<br/>query = np.random.random((5, dimension)).astype('float32')<br/>distances, indices = index.search(query, k=5)<br/><br/>print(f"\n查询5个向量，最近邻:")<br/>for i, (dists, idxs) in enumerate(zip(distances, indices)):<br/>    print(f"  Query {i}: 最近邻索引={idxs[0]}, 距离={dists[0]:.4f}")<br/><br/># IVF索引(加速)<br/>nlist = 100  # 聚类中心数<br/>quantizer = faiss.IndexFlatL2(dimension)<br/>index = faiss.IndexIVFFlat(quantizer, dimension, nlist)<br/>index.train(vectors)<br/>index.add(vectors)<br/><br/># 精确度 vs 速度<br/>index.nprobe = 10  # 搜索的聚类数<br/>distances, indices = index.search(query, k=5)</code>

### 4. Milvus

**特点**：云原生向量数据库、支持分布式

```
<code># 安装<br/># pip install pymilvus<br/><br/># 经典 ORM 式写法（存量代码常见；pymilvus 2.4+ 新项目推荐文末的 MilvusClient）<br/>from pymilvus import Collection, CollectionSchema, DataType, FieldSchema, connections<br/><br/># 连接<br/>connections.connect(host='localhost', port='19530')<br/><br/># 定义schema<br/>fields = [<br/>    FieldSchema(name="id", dtype=DataType.INT64, is_primary=True),<br/>    FieldSchema(name="embedding", dtype=DataType.FLOAT_VECTOR, dim=384),<br/>    FieldSchema(name="text", dtype=DataType.VARCHAR, max_length=65535)<br/>]<br/>schema = CollectionSchema(fields=fields, description="文档集合")<br/><br/># 创建collection<br/>collection = Collection(name="documents", schema=schema)<br/><br/># 创建索引<br/>index_params = {"index_type": "IVF_FLAT", "params": {"nlist": 128}, "metric_type": "L2"}<br/>collection.create_index(field_name="embedding", index_params=index_params)<br/><br/># 插入数据<br/>from sentence_transformers import SentenceTransformer<br/><br/>model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')<br/>texts = ["文本1", "文本2", "文本3"]<br/>embeddings = model.encode(texts).tolist()<br/><br/>data = [[1, 2, 3], embeddings, texts]<br/>collection.insert(data)<br/>collection.flush()<br/><br/># 搜索前必须先 load 到内存（易漏步骤，漏了会报集合未加载错误）<br/>collection.load()<br/><br/>query_embedding = model.encode(["查询文本"]).tolist()<br/>search_params = {"metric_type": "L2", "params": {"nprobe": 10}}<br/>results = collection.search(query_embedding, "embedding", search_params, limit=5)<br/><br/>for result in results[0]:<br/>    print(f"ID: {result.id}, 距离: {result.distance}, 文本: {result.entity.get('text')}")</code>

**现行推荐：MilvusClient（pymilvus 2.4+）**——一站式接口，同样能力更简洁（示意，承接上文的 model）：

```

语义向量检索进入生产，重点在一致性与可治理，参考 ownrag 基准工程：

- **模型一致性**：入库与查询必须用同一嵌入模型与维度，换模型 = 全量重建索引；ownrag 把嵌入参数纳入启动期配置校验，见 `ownrag/index/embedder.py` 与 `ownrag/config.py`。
- **切分质量**：向量质量的上限由切分决定，ownrag 的切分预览落盘、人工复核通过才入库，见 `ownrag/index/chunker.py` 与 `ownrag/review.py`。
- **混合检索**：纯语义召回会漏精确关键词命中，补 BM25 通道并用 RRF 名次融合，见 `ownrag/retrieve/hybrid.py`。
- **默认凭据治理**：向量库默认账号密码（如 Milvus 的 root/Milvus）上线前必须替换，密钥只走环境变量，参考 `ownrag/config.py`。
- **评测回归**：换嵌入模型或调检索参数前先建评测集（RAGAS 指标随回归跑），没有评测集不调参。

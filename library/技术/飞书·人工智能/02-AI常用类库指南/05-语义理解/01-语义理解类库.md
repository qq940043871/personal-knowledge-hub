## 一、核心概念

### 语义理解原理

```
文本 → 分词/编码 → Transformer编码 → 语义向量 → 相似度计算/匹配

核心任务：
1. 语义相似度：计算两个文本的语义距离
2. 文本匹配：判断两个文本是否匹配
3. 语义搜索：在大量文本中找到最相关的
4. 问答匹配：找到问题的最佳答案
```

## 二、常用类库

### 1. Sentence-Transformers

**特点**：语义向量最全、支持多语言、效果最好

```bash
pip install sentence-transformers
```

```python
from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity
import numpy as np

# 加载模型
model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')

# 编码单个文本
embedding = model.encode("我喜欢深度学习")
print(f"向量维度: {embedding.shape}")  # (384,)

# 编码多个文本
sentences = [
    "人工智能将改变世界",
    "机器学习是AI的核心技术",
    "深度学习在图像识别上很强大",
    "今天天气真好"
]

embeddings = model.encode(sentences)
print(f"向量矩阵: {embeddings.shape}")  # (4, 384)

# 计算余弦相似度
similarity = cosine_similarity([embeddings[0]], [embeddings[1]])[0][0]
print(f"相似度: {similarity:.4f}")  # 0.7xx

# 语义搜索
query = "什么是机器学习？"
query_emb = model.encode(query)

# 计算与所有句子的相似度
similarities = cosine_similarity([query_emb], embeddings)[0]
top_idx = np.argsort(similarities)[::-1]

print(f"\n搜索: {query}")
for idx in top_idx[:3]:
    print(f"  {similarities[idx]:.4f} - {sentences[idx]}")
```

```python
from langchain_chroma import Chroma
from langchain_community.document_loaders import TextLoader
from langchain_huggingface import HuggingFaceEmbeddings
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 加载文档
loader = TextLoader("document.txt")
documents = loader.load()

# 分割文档
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
texts = splitter.split_documents(documents)

# 创建向量数据库（persist_directory 指定后自动持久化）

# 语义检索
query = "LangChain有哪些功能？"
docs = db.similarity_search(query, k=3)

print("检索结果:")
for i, doc in enumerate(docs):
    print(f"{i+1}. {doc.page_content[:100]}...")

# 带分数的检索
results = db.similarity_search_with_score(query, k=3)
for doc, score in results:
    print(f"分数: {score:.4f}, 内容: {doc.page_content[:50]}...")

# 注意：chromadb 0.4+ 起写入即自动持久化，旧的 db.persist() 已废弃并被移除，
# 无需（也不能）再手动调用
```

### 3. FAISS (Facebook)

**特点**：高效向量检索、支持亿级向量

```bash
pip install faiss-cpu  # 或 faiss-gpu
```

```python
import numpy as np
import faiss

# 生成示例数据(10000个128维向量)
dimension = 128
num_vectors = 10000
np.random.seed(42)

vectors = np.random.random((num_vectors, dimension)).astype('float32')

# 构建索引
index = faiss.IndexFlatL2(dimension)  # L2距离
# 或使用内积索引
# index = faiss.IndexFlatIP(dimension)  # 余弦相似度

index.add(vectors)
print(f"索引中向量数: {index.ntotal}")

# 查询
query = np.random.random((5, dimension)).astype('float32')
distances, indices = index.search(query, k=5)

print(f"\n查询5个向量，最近邻:")
for i, (dists, idxs) in enumerate(zip(distances, indices)):
    print(f"  Query {i}: 最近邻索引={idxs[0]}, 距离={dists[0]:.4f}")

# IVF索引(加速)
nlist = 100  # 聚类中心数
quantizer = faiss.IndexFlatL2(dimension)
index = faiss.IndexIVFFlat(quantizer, dimension, nlist)
index.train(vectors)
index.add(vectors)

# 精确度 vs 速度
index.nprobe = 10  # 搜索的聚类数
distances, indices = index.search(query, k=5)
```

### 4. Milvus

**特点**：云原生向量数据库、支持分布式

```python
# 安装
# pip install pymilvus

# 经典 ORM 式写法（存量代码常见；pymilvus 2.4+ 新项目推荐文末的 MilvusClient）
from pymilvus import Collection, CollectionSchema, DataType, FieldSchema, connections

# 连接
connections.connect(host='localhost', port='19530')

# 定义schema
fields = [
    FieldSchema(name="id", dtype=DataType.INT64, is_primary=True),
    FieldSchema(name="embedding", dtype=DataType.FLOAT_VECTOR, dim=384),
    FieldSchema(name="text", dtype=DataType.VARCHAR, max_length=65535)
]
schema = CollectionSchema(fields=fields, description="文档集合")

# 创建collection
collection = Collection(name="documents", schema=schema)

# 创建索引
index_params = {"index_type": "IVF_FLAT", "params": {"nlist": 128}, "metric_type": "L2"}
collection.create_index(field_name="embedding", index_params=index_params)

# 插入数据
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')
texts = ["文本1", "文本2", "文本3"]
embeddings = model.encode(texts).tolist()

data = [[1, 2, 3], embeddings, texts]
collection.insert(data)
collection.flush()

# 搜索前必须先 load 到内存（易漏步骤，漏了会报集合未加载错误）
collection.load()

query_embedding = model.encode(["查询文本"]).tolist()
search_params = {"metric_type": "L2", "params": {"nprobe": 10}}
results = collection.search(query_embedding, "embedding", search_params, limit=5)

for result in results[0]:
    print(f"ID: {result.id}, 距离: {result.distance}, 文本: {result.entity.get('text')}")
```

**现行推荐：MilvusClient（pymilvus 2.4+）**——一站式接口，同样能力更简洁（示意，承接上文的 model）：

```python
# （伪代码示意，承接上文的 model/embeddings/texts；完整实现见 ownrag/harness 工程）
from pymilvus import MilvusClient

# 连接（★特殊点1 默认凭据治理：token 默认 root/Milvus，上线前必须替换并走环境变量）
client = MilvusClient(uri="http://localhost:19530", token="root:Milvus")

# 快速建集合：dimension 模式自动生成 id + vector 字段并建索引（额外的 "text"
# 字段随行写入）；与上面 ORM 建的同名集合结构不同，先清理（has_collection → drop）
client.create_collection(collection_name="documents", dimension=384)

# 插入：一行一个 dict（vector 字段承接上文的 embeddings；示意 1 行）
client.insert("documents", data=[{"id": 1, "vector": embeddings[0], "text": texts[0]}])

# 搜索（快速建集合默认创建即加载，无需手动 load）
hits = client.search("documents", data=model.encode(["查询文本"]).tolist(),
                     limit=5, output_fields=["text"])
# 结果形态：hits[0] 内 hit["id"] / hit["distance"] / hit["entity"]["text"]
```

### 企业级升级要点

语义向量检索进入生产，重点在一致性与可治理，参考 ownrag 基准工程：

- **模型一致性**：入库与查询必须用同一嵌入模型与维度，换模型 = 全量重建索引；ownrag 把嵌入参数纳入启动期配置校验，见 `ownrag/index/embedder.py` 与 `ownrag/config.py`。
- **切分质量**：向量质量的上限由切分决定，ownrag 的切分预览落盘、人工复核通过才入库，见 `ownrag/index/chunker.py` 与 `ownrag/review.py`。
- **混合检索**：纯语义召回会漏精确关键词命中，补 BM25 通道并用 RRF 名次融合，见 `ownrag/retrieve/hybrid.py`。
- **默认凭据治理**：向量库默认账号密码（如 Milvus 的 root/Milvus）上线前必须替换，密钥只走环境变量，参考 `ownrag/config.py`。
- **评测回归**：换嵌入模型或调检索参数前先建评测集（RAGAS 指标随回归跑），没有评测集不调参。

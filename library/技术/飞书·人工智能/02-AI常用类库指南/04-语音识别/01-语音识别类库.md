### 语音识别原理

```
<code>音频 → 预处理(采样/归一化) → 特征提取(MFCC/FBank) → 声学模型 → 解码器 → 文本<br/><br/>MFCC: Mel频率倒谱系数，模拟人耳听觉特性<br/>声学模型: CTC/Attention将声学特征转为音素<br/>语言模型: 结合语言知识提高准确率</code>
```

### 1. Whisper (OpenAI)

**特点**：多语言、支持中文、效果好、开源

```
<code>pip install openai-whisper</code>
```

```
<code>import whisper<br/><br/># 加载模型(base/small/medium/large)<br/>model = whisper.load_model("base")<br/><br/># 音频文件识别<br/>result = model.transcribe("audio.mp3")<br/>print(result["text"])<br/><br/># 识别并翻译<br/>result = model.transcribe("chinese_audio.mp3", language="zh", task="translate")<br/>print(result["text"])  # 英文输出<br/><br/># 实时录音识别<br/>import pyaudio<br/>import numpy as np<br/><br/>model = whisper.load_model("small")<br/>p = pyaudio.PyAudio()<br/>stream = p.open(format=pyaudio.paInt16, channels=1, rate=16000, input=True)<br/><br/>print("开始录音，按Ctrl+C停止...")<br/>frames = []<br/><br/>while True:<br/>    try:<br/>        data = stream.read(16000, exception_on_overflow=False)<br/>        frames.append(np.frombuffer(data, np.int16))<br/>    except KeyboardInterrupt:<br/>        break<br/><br/>audio = np.concatenate(frames)<br/>result = model.transcribe(audio, language="zh")<br/>print(f"识别结果: {result['text']}")<br/><br/>stream.stop_stream()<br/>stream.close()<br/>p.terminate()</code>
```

### 2. SpeechRecognition

**特点**：支持多种引擎（Google/百度/讯飞）

```
<code>pip install SpeechRecognition<br/>pip install pyaudio  # 录音</code>
```

```
<code>import speech_recognition as sr<br/><br/># 创建识别器<br/>r = sr.Recognizer()<br/><br/># 使用麦克风录音<br/>with sr.Microphone() as source:<br/>    print("请说话...")<br/>    audio = r.listen(source)<br/><br/># Google在线识别<br/>try:<br/>    text = r.recognize_google(audio, language='zh-CN')<br/>    print(f"Google识别: {text}")<br/>except sr.UnknownValueError:<br/>    print("无法识别音频")<br/>except sr.RequestError:<br/>    print("服务不可用")<br/><br/># 识别音频文件<br/>with sr.AudioFile('audio.wav') as source:<br/>    audio = r.record(source)<br/>    text = r.recognize_google(audio, language='zh-CN')<br/>    print(f"识别结果: {text}")</code>
```

### 3. Vosk

**特点**：离线识别、模型小巧、实时性好

```
<code>pip install vosk<br/># 下载模型: https://alphacephei.com/vosk/models</code>
```

```
<code>from vosk import Model, KaldiRecognizer<br/>import pyaudio<br/>import json<br/><br/># 加载模型<br/>model = Model('vosk-model-small-cn-0.3')<br/>rec = KaldiRecognizer(model, 16000)<br/><br/># 录音识别<br/>p = pyaudio.PyAudio()<br/>stream = p.open(format=pyaudio.paInt16, channels=1, rate=16000, input=True)<br/><br/>print("开始识别...")<br/>full_text = []<br/><br/>while True:<br/>    data = stream.read(16000, exception_on_overflow=False)<br/>    if len(data) == 0:<br/>        break<br/><br/>    if rec.AcceptWaveform(data):<br/>        result = json.loads(rec.Result())<br/>        if result['text']:<br/>            full_text.append(result['text'])<br/>            print(f"部分识别: {result['text']}")<br/><br/># 最终结果<br/>final = json.loads(rec.FinalResult())<br/>full_text.append(final['text'])<br/>print(f"\n最终结果: {''.join(full_text)}")<br/><br/>stream.stop_stream()<br/>stream.close()<br/>p.terminate()</code>
```

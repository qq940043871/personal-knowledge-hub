### 目标检测原理

```
<code>输入图像 → 特征提取(CNN) → 区域建议/RPN → 分类+回归 → 输出(类别, 位置)<br/><br/>检测任务：<br/>1. 分类：判断目标属于哪个类别<br/>2. 定位：输出目标的边界框(Bounding Box)<br/>3. 置信度：预测的可信程度</code>
```

### 1. Ultralytics YOLO

**特点**：速度快、部署简单、效果好

```
<code>pip install ultralytics</code>
```

```
<code>from ultralytics import YOLO<br/>import cv2<br/><br/># 加载模型(yolov8n/yolov8s/yolov8m/yolov8l/yolov8x)<br/>model = YOLO('yolov8n.pt')<br/><br/># 推理<br/>results = model('bus.jpg')<br/>results = model('video.mp4', save=True)  # 视频<br/><br/># 处理结果<br/>for r in results:<br/>    # 边界框<br/>    boxes = r.boxes<br/>    for box in boxes:<br/>        x1, y1, x2, y2 = box.xyxy[0].tolist()<br/>        confidence = box.conf[0].item()<br/>        class_id = int(box.cls[0])<br/>        class_name = model.names[class_id]<br/><br/>        print(f"{class_name}: {confidence:.2%} at [{x1:.0f},{y1:.0f},{x2:.0f},{y2:.0f}]")<br/><br/>    # 绘制结果<br/>    annotated_frame = r.plot()<br/>    cv2.imshow('YOLOv8', annotated_frame)<br/>    cv2.waitKey(0)<br/><br/># 实时检测<br/>model = YOLO('yolov8n.pt')<br/>camera = cv2.VideoCapture(0)<br/><br/>while camera.isOpened():<br/>    ret, frame = camera.read()<br/>    results = model(frame)<br/>    annotated = results[0].plot()<br/>    cv2.imshow('Camera', annotated)<br/>    if cv2.waitKey(1) &amp; 0xFF == ord('q'):<br/>        break<br/><br/>camera.release()<br/>cv2.destroyAllWindows()</code>
```

### 2. Detectron2 (Meta)

**特点**：功能强大，支持多种检测任务

```
<code>pip install detectron2<br/># 需要从源码安装<br/>python -m pip install 'git+https://github.com/facebookresearch/detectron2.git'</code>
```

```
<code>import torch, cv2<br/>from detectron2.config import get_cfg<br/>from detectron2.engine import DefaultPredictor<br/>from detectron2.model_zoo import model_zoo<br/><br/># 配置<br/>cfg = get_cfg()<br/>cfg.merge_from_file(model_zoo.get_config_file("COCO-Detection/faster_rcnn_R_50_FPN_3x.yaml"))<br/>cfg.MODEL.WEIGHTS = model_zoo.get_checkpoint_url("COCO-Detection/faster_rcnn_R_50_FPN_3x.yaml")<br/>cfg.MODEL.DEVICE = 'cuda' if torch.cuda.is_available() else 'cpu'<br/><br/>predictor = DefaultPredictor(cfg)<br/><br/># 读取图片<br/>im = cv2.imread('input.jpg')<br/>outputs = predictor(im)<br/><br/># 获取结果<br/>boxes = outputs["instances"].pred_boxes.tensor.cpu().numpy()<br/>classes = outputs["instances"].pred_classes.cpu().numpy()<br/>scores = outputs["instances"].scores.cpu().numpy()<br/><br/># 绘制<br/>for box, cls, score in zip(boxes, classes, scores):<br/>    x1, y1, x2, y2 = box<br/>    cv2.rectangle(im, (int(x1), int(y1)), (int(x2), int(y2)), (0, 255, 0), 2)<br/>    cv2.putText(im, f"Class {cls}: {score:.2f}", (int(x1), int(y1)-5), <br/>                cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 255, 0), 2)<br/><br/>cv2.imshow('Detection', im)<br/>cv2.waitKey(0)</code>
```

### 3. MMDetection

**特点**：OpenMMLab出品，模块化设计

```
<code>pip install openmim<br/>mim install mmdet</code>
```

```
<code>from mmdet.apis import init_detector, inference_detector<br/>import mmcv<br/><br/># 初始化模型<br/>config_file = 'configs/yolo/yolov3_mobilenetv2_8x24_300e_coco.py'<br/>checkpoint_file = 'checkpoints/yolov3_mobilenetv2_8x24_300e_coco_20210719_170329-6794b32c.pth'<br/>model = init_detector(config_file, checkpoint_file, device='cuda:0')<br/><br/># 推理<br/>result = inference_detector(model, 'demo.jpg')<br/><br/># 可视化<br/>model.show_result('demo.jpg', result, out_file='result.jpg')<br/><br/># 批量处理<br/>for img in mmcv.scandir('images/'):<br/>    result = inference_detector(model, img)<br/>    model.show_result(img, result, out_file=f'outputs/{img}')</code>
```

# 企业级大模型输出稳定性保障方案
## 一、核心目标
通过全流程管控，彻底解决大模型**回答幻觉、格式混乱、语气不规范、内容违规、逻辑矛盾**等问题，保证输出内容**精准、合规、格式统一、稳定可控**，完全适配企业内部办公、业务审批、知识问答等场景的标准化使用需求。

## 二、提示词工程：从源头筑牢输出稳定性
### 1. 标准化企业级提示词模板体系
+ **固定结构模板**：所有业务场景提示词统一采用「角色定位+核心任务+约束规则+格式要求+禁止行为+参考依据」六段式结构，杜绝零散、随意的提示词编写，保证指令传递清晰无歧义。
+ **场景化定制模板**：针对内部知识问答、业务流程咨询、数据汇总、公文生成等不同企业场景，单独定制专属模板，明确行业术语、内部规范、业务逻辑约束，避免通用提示词导致的输出偏差。
+ **约束性强指令编写**：摒弃模糊性表述，全部采用确定性、量化指令，明确要求大模型**仅基于提供的知识库内容作答、禁止编造信息、回答逻辑分点呈现、严禁使用非规范表述**，从源头减少幻觉与乱序问题。
+ **容错性提示优化**：加入兜底指令，如「无相关参考内容时，统一回复『未查询到对应信息，请勿轻信无关内容』」，避免大模型自行编造答案。

### 2. 提示词鲁棒性优化
+ 加入**上下文一致性约束**，要求大模型保持回答逻辑连贯、前后不矛盾，针对同一问题输出内容保持统一。
+ 限定回答篇幅、语气风格，企业内部场景统一使用正式、严谨、简洁的语气，杜绝口语化、情绪化、随意化表达。
+ 明确业务合规底线，在提示词中提前植入企业规章制度、合规要求，禁止输出违规、涉密、不符合企业规范的内容。

## 三、提示词全生命周期管理：保障长期稳定复用
### 1. 提示词集中化存储与分类
+ 搭建**企业内部提示词资产管理库**，按业务部门、使用场景、功能类型分级分类归档所有提示词，实现统一归集、一目了然。
+ 每个提示词绑定唯一标识、适用场景、编写人、更新时间、版本号，方便追溯与管理，杜绝提示词散乱、丢失、滥用。

### 2. 版本管控与迭代优化
+ 建立提示词**版本更新机制**，优化后的提示词保留历史版本，可快速回滚，避免因单次修改导致输出效果断崖式下降。
+ 定期收集业务端使用反馈，针对输出不稳定、不精准的提示词，持续迭代优化，沉淀最优版本，形成闭环管理。

### 3. 权限管控与复用规范
+ 按用户角色分配提示词使用权限，普通业务人员仅可调用标准化模板，管理员、运营人员可编辑优化提示词。
+ 制定提示词复用与编写规范，禁止业务人员随意修改核心提示词模板，如需定制化需求，走统一申请、审核流程，保证全企业提示词使用的规范性。

### 4. 效果监控与淘汰机制
+ 对所有提示词的调用效果、输出准确率、稳定性进行持续监控，建立评分机制。
+ 定期清理低效、失效提示词，保留高稳定、高精准的优质提示词，持续提升提示词整体质量。

## 四、输入层校验：拦截无效/违规请求，避免输出失控
### 1. 用户输入内容合规校验
+ 搭建**输入内容敏感词过滤引擎**，内置企业内部敏感词汇、违规提问、涉密相关关键词，用户提问触发时直接拦截，拒绝向大模型转发请求。
+ 校验输入内容合法性，拦截恶意提问、攻击指令、无关闲聊、违规指令，杜绝因异常输入导致大模型输出违规内容。

### 2. 输入格式与长度校验
+ 限定用户输入长度，拦截超长、无意义、乱码式提问，避免大模型因输入过载导致输出混乱。
+ 针对特定业务场景，校验输入格式（如工号、流程编号、关键词格式），不符合规范的输入引导用户重新输入，保证指令有效。

### 3. RAG输入层前置校验
+ 校验知识库检索结果有效性，若召回内容为空、完全不相关，直接终止大模型生成，返回标准兜底回复，避免无依据编造。
+ 校验输入内容与业务场景匹配度，非本场景业务提问，自动引导至对应模块或拒绝处理，保证输出聚焦企业业务。

### 4. 指令注入防护校验
+ 拦截提示词注入、指令破解、越狱类提问，防止用户通过恶意输入绕过规则，操控大模型输出违规、非规范内容。

## 五、输出层数据格式过滤与修复：最终保障输出合规统一
### 1. 输出内容合规二次过滤
+ 对大模型原始输出内容，再次进行敏感信息、涉密内容、违规表述、不符合企业规范内容的扫描过滤，彻底阻断违规内容下发。
+ 识别并删除编造内容、无依据推论、无关拓展内容，仅保留基于参考资料的有效回答，根治模型幻觉。

### 2. 输出格式标准化修复
+ **格式统一矫正**：自动修复乱序、分段混乱、标点错误、排版杂乱问题，按企业要求统一为分点、分段、标题层级清晰的格式。
+ **冗余内容清理**：自动删除重复表述、口语化助词、无关铺垫、多余修饰，保留简洁、正式、核心的业务内容。
+ **缺失内容补全**：针对格式残缺、逻辑不完整的输出，按预设规则自动补全标准开头、结尾、序号，保证格式完整规范。

### 3. 输出内容一致性校验
+ 建立企业标准话术库，对业务术语、专有名词、流程表述、规范用语进行校验，替换不规范表述，保证全系统输出术语统一、表述一致。
+ 校验同一类问题的输出逻辑、核心结论一致性，避免前后矛盾、答案不一。

### 4. 兜底修复与异常处理
+ 针对输出乱码、空白、逻辑完全错误的内容，自动替换为企业统一的标准兜底回复。
+ 对生成失败、超时的请求，返回友好、规范的提示语，保证用户端展示效果统一。

## 六、落地保障机制
1. 全流程日志留存：记录提示词调用、用户输入、大模型原始输出、过滤修复后的最终输出，方便复盘优化。
2. 定期抽检机制：运维/运营人员定期抽检输出结果，针对不稳定、不规范问题，反向优化提示词、校验规则、过滤策略。
3. 规则动态迭代：根据企业业务更新、内部规范调整，同步更新提示词模板、输入校验规则、输出过滤策略，持续适配企业使用需求。

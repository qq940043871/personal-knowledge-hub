# 企业离线AI Agent+RAG 完整技术选型 & 选型理由
（完全贴合你固定栈：LangChain+LangGraph、Dify、MinerU、LLMFactory、GPUStack，**面试直接背诵、逻辑闭环、贴合Java+Agent岗位**）

## 一、编排层：LangChain + LangGraph
### 选型
+ 大模型应用编排：**LangChain**
+ 多智能体/多轮状态/复杂工作流：**LangGraph**

### 选型原因
1. **生态成熟、落地成本低**
LangChain 是目前企业级AI应用最通用的开发框架，封装大模型调用、工具调用、Prompt管理、RAG基础链路，开箱即用，减少重复基建开发。
2. **组件化高、易扩展**
原生支持向量库、重排、文档加载、记忆组件、第三方工具集成，适配私有化离线改造，方便对接MinerU、向量库、微调模型。
3. **LangGraph 补足短板**
LangChain 不擅长**多轮会话状态、长流程编排、多Agent协作、分支判断、循环任务**；
LangGraph 基于状态机管理对话上下文、长短期记忆、复杂任务拆解，完美匹配岗位要求的「智能体模块开发、多场景集成」。
4. **适配业务复杂场景**
支持工具调用、任务拆解、串行/并行流程，满足各产品线智能体、客户终端复杂问答、流程化任务需求。
5. **Java后端友好**
可通过API/服务化封装，和Java微服务体系无缝对接，便于多产品线统一接入。

## 二、Agent平台底座：Dify
### 选型
私有化部署 **Dify** 作为低代码Agent应用底座

### 选型原因
1. **快速落地业务**
内置应用搭建、会话管理、权限控制、API网关、前端控制台，不用从零开发Agent管理后台，大幅缩短交付周期，支撑多产品线智能体快速上线。
2. **能力全面、开箱即用**
原生支持智能体、工作流、知识库、API调用、变量配置，满足产品侧数智化体验升级的基础诉求。
3. **开放可二次定制**
虽然原生RAG偏弱，但**支持外部RAG接口、自定义节点、外部模型接入**，可无缝对接自研增强RAG、MinerU解析、私有微调模型，不锁死架构。
4. **离线私有化友好**
完整支持内网离线部署、容器化运维，满足企业数据不出域、安全合规要求，适配政企/行业客户交付。
5. **提效工具链**
可视化编排、Prompt在线调试、应用版本管理，提升团队Agent开发与迭代效率，契合工具链提效场景。

---

## 三、文档解析层：MinerU
### 选型
专业结构化文档解析引擎 **MinerU**

### 选型原因
1. **复杂文档解析能力强**
针对企业高频的PDF、Word、扫描件、教材、仿真资料，精准识别**表格、公式、图片、层级标题、页眉页脚过滤**，解决传统文本抽取乱序、格式丢失问题。
2. **版式还原+结构化输出**
输出带层级的Markdown/结构化文本，为RAG分层切片、精准召回打下基础，从源头提升知识库质量。
3. **纯离线、国产化**
无外网依赖，完全内网运行，适配企业离线大模型落地场景，安全可控。
4. **轻量化易集成**
独立服务化部署，HTTP接口调用，可嵌入Dify知识库链路、LangChain预处理流程，改造量小。
5. **适配垂直领域**
适配教育培训、虚拟仿真等复杂图文混合文档，匹配岗位加分项的垂直领域落地需求。

## 四、模型微调层：LLMFactory
### 选型
**LLMFactory** 作为本地化大模型微调、模型管理平台

### 选型原因
1. **全流程离线微调**
支持数据标注、数据集管理、LoRA/QLoRA高效微调、模型合并、模型导出，全程内网闭环，满足私有化合规要求。
2. **降低大模型幻觉**
针对企业业务、垂直行业场景做小样本领域微调，收敛模型输出风格，强化知识库问答约束，解决RAG核心幻觉问题。
3. **模型统一管理**
集中管理通用大模型、领域微调模型、Embedding、重排模型，统一版本、发布、切换，方便多产品线按需调用。
4. **上手成本低**
可视化操作，无需深度算法背景，后端开发可快速完成微调任务落地，适配研发团队协作模式。
5. **适配行业定制**
可针对教育、虚拟仿真等垂直业务做专项优化，贴合岗位加分项要求。

## 五、GPU资源调度层：GPUStack
### 选型
**GPUStack** 作为集群GPU资源池化与调度平台

### 选型原因
1. **GPU资源统一池化**
统一管理多卡、多服务器GPU算力，实现模型分片、资源隔离、负载均衡，避免单模型独占显卡、资源浪费。
2. **多模型混合部署**
支持LLM、Embedding、Rerank、解析服务、微调任务混合调度，互不抢占资源，保障Agent平台稳定运行。
3. **离线集群运维**
适配内网私有化环境，提供监控、配额管理、任务排队、故障自愈，提升离线大模型服务的可用性。
4. **支撑高并发场景**
合理分配算力，应对多产品线同时接入、多用户并发问答，解决离线环境下推理卡顿、响应慢问题。
5. **轻量化运维**
相比K8s重度方案更简单，适合企业AI集群快速搭建、低成本运维，兼顾性能与落地成本。

整套技术栈以 **LangChain+LangGraph** 作为智能体核心编排与状态管理，Dify承担快速应用落地与平台底座，MinerU保障复杂文档结构化预处理，LLMFactory完成领域微调与幻觉优化，GPUStack统一管控离线GPU算力；

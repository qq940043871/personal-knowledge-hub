# 08 · AI 项目实战（郑大乾坤鉴）

企业级 AI 中台的真实落地记录：**文档解析改造 → RAG 知识库治理 → 多智能体调度 → 意图识别与工程化稳定输出 → 技术选型与升级方案**。全部内容出自驻场项目的实际踩坑与方案沉淀，不是教程复述；与 `07-企业落地` 的通用方法论互补——那边讲「是什么」，这里讲「我们怎么做的、卡在哪、怎么绕过去」。

**共 25 篇**，按「项目背景 → 问题拆解 → 单点方案 → 整体架构 → 前沿视野」编号。

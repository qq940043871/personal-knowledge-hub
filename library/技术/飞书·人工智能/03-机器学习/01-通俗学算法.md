# 通俗学算法

## 十大算法一句话速查：通俗原理版

| 算法/模型名称 | 一句话通俗原理 |
|-|-|
| KNN算法 | 要判断一个东西属于哪类，就看它周围最近的K个邻居大多属于哪类，它就跟着属于哪类。 |
| 逻辑回归算法 | 把线性关系的结果通过一个函数压缩到0到1之间，用来判断某个情况发生的概率大小，进而分类。 |
| 朴素贝叶斯算法 | 依据已有的经验（先验概率），结合特征之间相互独立的假设，推测出在当前特征下属于各类别的可能性，选可能性大的类别。 |
| 决策树模型 | 像走流程一样，通过对数据特征一步步提问（比如“年龄是否大于30？”），最终走到对应的类别或数值结果。 |
| 随机森林分类模型 | 很多棵不同的决策树一起投票，多数树投的类别就是最终的分类结果。 |
| 回归树模型 | 用决策树的形式，把数据分到不同组，每组用平均值作为该组数据的预测值，用于预测连续的数值。 |
| GBDT模型 | 一棵一棵决策树依次训练，每棵树都去弥补前面所有树预测的误差，逐步让预测更准确。 |
| LightGBM模型 | 是更快更高效的GBDT，用巧妙的方法选分裂点、减少计算量，还优先长好分的树枝，又快又准。 |
| 聚类算法 | 不给类别标签，让计算机自己把长得像、有关系的东西自动分成一堆一堆的。 |
| 降维算法 | 在不丢失太多关键信息的前提下，把很多很多特征的数据简化成少数几个特征的数据，方便处理。 |

## 十大算法一句话速查：核心原理版

| 算法/模型名称 | 一句话核心原理 |
|-|-|
| KNN算法 | 预测时，找到与待预测样本最近的K个邻居，根据这K个邻居的多数类别或平均数值来确定待预测样本的类别或数值。 |
| 逻辑回归算法 | 基于线性回归，通过Sigmoid函数将线性组合的结果映射到0 - 1区间，以此来估计样本属于某一类别的概率，进而进行分类。 |
| 朴素贝叶斯算法 | 基于贝叶斯定理和特征条件独立假设，利用已知的先验概率，计算在给定特征下样本属于各类别的后验概率，选择后验概率最大的类别作为预测结果。 |
| 决策树模型 | 通过对数据特征进行一系列的判断（如特征是否大于某个值），形成一棵“树”状的决策结构，从根节点到叶节点的路径对应着一条决策规则，叶节点即为样本的预测类别或数值。 |
| 随机森林分类模型 | 由多棵随机抽样、随机选择特征生成的决策树组成，对样本进行分类时，通过多棵树投票的方式确定最终类别。 |
| 回归树模型 | 是决策树的一种，用于回归任务，通过对特征的划分，将数据分到不同叶节点，叶节点的平均值作为该组数据的预测值。 |
| GBDT模型 | 以决策树为基学习器，通过梯度提升的方式，每次迭代都拟合之前模型预测的残差，逐步提升模型的预测精度。 |
| LightGBM模型 | 是高效的梯度提升树算法，采用直方图算法和单边梯度采样等技术，减少计算量，同时通过叶子节点优先分裂策略，提高模型训练效率和精度。 |
| 聚类算法 | 无需预先给定类别标签，依据数据自身的相似性（如距离、密度等），将相似的数据对象自动划分为不同的组（簇）。 |
| 降维算法 | 在尽可能保留数据关键信息的前提下，将高维度的数据空间映射到低维度空间，减少数据的特征数量，缓解“维度灾难”。 |

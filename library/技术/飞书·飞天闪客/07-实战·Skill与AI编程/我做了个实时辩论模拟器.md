# 我做了个实时辩论模拟器

## 引言：开启AI协作开发新范式

在大型语言模型（LLM）能力飞速发展的今天，编程的边界正在被重新定义。传统的“编写者”角色正逐渐向“设计者”与“指挥官”演变。

本课程将带你深入实践这一前沿的开发模式——与AI智能体进行深度协作，无需亲手编写大量代码，而是通过清晰的自然语言指令，引导AI从零开始构建一个功能完整、体验精良的互动Web应用。我们将以“互动辩论模拟器”为实战项目，你将亲身体验如何将创意转化为可运行的程序，并掌握与AI高效沟通的核心心法。这不仅是一次技术实践，更是一次关于未来工作方式的思维训练。

## 项目导论与成果展示

> 聚焦**需求描述、架构设计和与AI高效沟通**的能力培养，在AI“副驾驶”的帮助下完成从创意到落地。

### 1.1 课程引入：智能体协作开发

本课程旨在引导学习者通过一个完整的项目，掌握利用AI编程助手（如Trey IDE）与大型语言模型（LLM）协作的核心技能。我们将聚焦于**需求描述、架构设计和与AI高效沟通**的能力培养，学习如何在AI“副驾驶”的帮助下，高效地完成从创意到落地的全过程。

### 1.2 最终成果演示

课程结束后，你将独立完成一个“互动辩论模拟器”Web应用。其最终效果具有以下亮点：

- **功能概览**：

  - **AI驱动辩论**：输入任意辩题，AI自动生成完整的辩论流程（开场、各方发言、总结陈词）。
  - **用户深度参与**：用户可选择辩手立场（如反方一辩），并在轮到自己时通过麦克风语音发言，与AI辩手实时互动。
  - **多模型协同**：集成不同AI模型各司其职——用GPT模型生成犀利的辩论文稿，用MiniMax模型实现自然的语音合成。
  - **个性化视觉**：支持使用自定义手绘图片替换默认元素，打造独特的视觉主题。
- **运行展示**：
应用启动后，呈现一个完整的辩论赛场景。AI主席宣布辩题与规则，双方AI辩手依次进行逻辑严密、言辞激烈的发言。当轮到用户选择的立场时，系统会提示用户进行语音输入，真正实现“人机同台竞技”。

## 开发环境与工具准备

> 你的核心动作是**通过自然语言描述需求**，AI智能体负责分解任务、创建文件、编写代码、处理错误。

### 2.1 核心工具介绍：Trey IDE与Solo Builder模式

我们将使用**Trey IDE**作为开发环境，并采用其**Solo Builder**模式。这种模式专为与AI智能体协作设计。

- **界面讲解**：打开Trey IDE并切换至Solo模式后，界面主要分为四个区域：

  1. **任务列表**：显示AI为完成项目所规划的一系列子任务。
  2. **AI对话区**：你与AI智能体进行自然语言沟通的核心区域。
  3. **代码编辑器**：实时查看和编辑AI生成的代码。
  4. **文件管理器**：查看和管理项目生成的所有文件。
- **工作原理**：你的核心动作是**通过自然语言描述需求**。AI智能体会理解你的意图，将其分解为编程任务，自动创建文件、编写代码、处理错误，并最终启动项目。你则扮演“产品经理”和“架构师”的角色。

### 2.2 模型与API配置

与AI智能体协作和让应用本身运行，可能需要调用不同的AI模型服务，因此API密钥配置是关键一步。

1. **选择大模型**：在Trey IDE的模型选择下拉菜单中，选择支持的平台（如OpenRouter），并选择你希望用于**驱动智能体思考**的模型（例如`Claude`）。这个模型负责理解你的指令并规划项目。
2. **获取API密钥**：

   - 前往如[OpenRouter](https://openrouter.ai/)等聚合平台注册账号。
   - 在账户设置中生成API Key。
   - 将Key粘贴到Trey IDE的配置界面中。
3. **理解Key的用途**：这是一个重要概念。你需要配置**两类**密钥：

   - **开发用Key**：用于Trey IDE内部，你与智能体对话、生成和调试项目时消耗的Token。
   - **应用运行用Key**：在你的项目代码中配置的，当最终应用运行（如生成辩手发言、合成语音）时调用的Key。这两者可以相同，也可以使用不同的账户或模型以管理成本。

## 核心开发流程：从零到一

> 成功的起点在于**将模糊的想法转化为清晰、具体的指令**。

### 3.1 需求转化为提示词

成功的起点在于将模糊的想法转化为清晰、具体的指令。

- **学习如何描述**：不要只说“做一个辩论网站”。需要描述其**核心功能、交互方式、技术偏好**。例如：“请创建一个互动的辩论模拟器网站。用户输入一个辩题，应用自动生成一场辩论赛。需要包含正方、反方辩手和主持人。所有发言由AI生成，并使用语音朗读出来。”
- **让AI协助优化**：如果你不确定如何描述，可以直接问AI：“我想做一个在线辩论模拟器，请帮我优化一下这个需求提示词，使其更清晰具体，便于你执行。”

> **示例提示词（经AI优化后）**：
> “创建一个基于Web的互动辩论模拟器。功能包括：1. 用户输入辩题。2. 系统生成一场完整的辩论赛流程（开场白、正方一辩立论、反方一辩驳论...、总结陈词）。3. 辩手和主持人的所有发言内容由LLM实时生成。4. 所有发言都需要有高质量的语音合成播放。5. 界面美观，有辩论赛的舞台感。”

### 3.2 AI自主开发全过程

输入提示词后，观察AI智能体如何工作：

1. **接收指令与整体规划**：AI会分析需求，生成项目结构和实现步骤。
2. **逐步创建文件与编写代码**：它会在你指定的目录下，依次创建`index.html`, `styles.css`, `script.js`等文件，并编写实现所有功能的代码。
3. **编写、检查与调试**：AI在编写过程中会自行检查语法和逻辑。如果启动后出现错误，它通常能够自动识别错误日志，并修改代码以解决问题。
4. **启动项目**：完成开发后，AI会自动启动一个本地服务器，并提供一个`localhost`访问地址。

### 3.3 运行与测试首个版本

在AI生成地址后，用浏览器打开它。检验基础功能是否流畅：

- 能否成功生成辩论赛流程？
- AI发言的逻辑和内容是否连贯？
- 语音播放是否正常？
- 界面布局是否合理？

第一个可运行版本的诞生，标志着你已成功与AI智能体完成了首次协作。

## 项目功能迭代与优化

> 软件开发的魅力在于持续迭代——通过与AI的再次对话，不断丰富和完善应用。

### 4.1 迭代一：增加用户互动

目前，用户只是观看者。我们希望让用户能亲自下场辩论。

- **新需求描述**：“请增加用户参与功能。在辩论开始前，让用户选择一个辩手位置（如反方一辩）。当流程轮到该位置发言时，暂停AI生成，改为提示用户用麦克风发言，并将用户的语音识别为文字，作为该辩手的发言内容插入流程中。”
- **与AI协作**：输入新提示词。AI会修改前端代码，加入位置选择UI；集成Web Speech API进行语音识别；调整后端流程，在对应节点等待用户输入。观察AI如何巧妙地在现有架构中“植入”新功能。

### 4.2 迭代二：提升体验质量

基础功能实现后，我们可以追求更卓越的体验。

- **优化发言内容**：“请让AI生成的辩论言辞更加犀利、有趣，多使用反问、排比等修辞手法，并加入一些幽默或讽刺的元素。”
- **增强视觉效果**：“请用我提供的自定义手绘图片（存放在`/pic`目录下）替换页面中的默认图标和背景元素，增加界面的立体感和艺术风格。”
- **升级语音合成**：“将当前浏览器内置的TTS语音合成，替换为调用MiniMax语音合成API。请使用更生动、有特色的音色。” AI会帮你修改代码，替换API调用方式，并指导你配置新的API Key。

经过这一系列迭代，应用将从“功能完整”进化到“体验出色”。

## 总结与核心能力提炼

> 清晰的需求表达和宏观的架构视角，是最大化发挥AI工具价值的关键。

### 5.1 复盘开发旅程

回顾整个项目，与Trey智能体的协作异常流畅，AI展现出了强大的**自动解决问题**的能力。关键在于：

- **清晰的需求描述**：将“做一个辩论网站”具体化为包含流程、交互、技术细节的清晰指令。
- **宏观的架构视角**：在脑海中明确项目由**哪些模型**（对话、文本生成、语音合成）、**哪些功能模块**（前端交互、后端逻辑、API调用）构成，这是下达有效指令的前提。

### 5.2 智能体时代的能力重构

在AI成为强大“执行者”的时代，我们的核心能力需要向“上游”迁移：

- **从“编写者”到“设计者与指挥官”**：核心能力不再是编写每一行代码，而是**精准定义问题、规划系统架构、下达清晰无误的指令**。你要能想象出最终产品，并拆解成AI能理解的任务序列。
- **多模型协同思维**：一个复杂应用可能需要多个AI模型共同完成。你需要思考：哪个环节用哪个模型最擅长？如何协调它们的数据流？这将成为新的架构设计要点。

### 5.3 拓展与思考

- **本项目的可改进方向**：例如，增加多人在线辩论、引入观众投票系统、实现辩论内容的自动分析与评分等。
- **举一反三**：这种“需求描述 -> AI架构与实现 -> 测试反馈 -> 迭代优化”的协作模式，适用于绝大多数**数据驱动、逻辑清晰**的Web应用开发，如互动故事生成器、个性化学习助手、数据分析仪表盘等。
- **鼓励实践**：理论结合实践方能掌握精髓。现在，就打开Trey IDE，从你自己的第一个创意开始，尝试与AI智能体进行首次协作吧！

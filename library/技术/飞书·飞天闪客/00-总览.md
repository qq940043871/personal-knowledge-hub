# 飞天闪客 · AI 与计算机科普文稿

一句话导读：闪客（技术科普 UP 主）的视频文稿合集，共 65 篇；按「先看懂机器 → 再建立 AI 直觉 → 拆开模型内部 → 硬读论文 → 追前沿 → 动手用 Agent」九级递进编排，从零基础一路推到能自己写 Skill。

## 适用场景

- 概念听得懂单个词、串不成体系，想一次性把计算机与 AI 的骨架理顺。
- 准备啃 Transformer 或论文，先要一份「人话版」垫底。
- 已经在用 Claude Code / 扣子 / Trae 这类工具，想搞清它们底层到底在干什么。

## 四条推荐读法

1. 完全零基础：`01` 全读完 → `02` 全读完 → 挑 `03` 的张量两篇。
2. 会写代码、想懂原理：`03` → `04` → `05`，再回头补 `01` 里的 GPU 与浮点数。
3. 只想马上能用：`02` 的《100 个关键词》→ `06` 的《名词诈骗》→ `07` 全读。
4. 碎片时间：`09` 与 `05` 里的单篇，独立成篇，不需要前情。

## 阅读提示

- 文稿由飞书导出，正文里的 `![](https://feishu.cn/file/...)` 是原视频截图的外链，离线阅读器里多数打不开，不影响文字内容。
- 文件名取自原始视频标题，个别超长标题已精简（去掉重复口播与导出截断的尾巴），按关键词搜索比按目录找更快。
- 每篇开头都有一行「课程大纲 / 课程标题」，这就是该篇的摘要，先扫这一行再决定要不要读全文。

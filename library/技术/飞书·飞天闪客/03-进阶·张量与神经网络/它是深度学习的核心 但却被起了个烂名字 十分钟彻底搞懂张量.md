## 引言：揭开“张量”的神秘面纱

深度学习的核心驱动力，本质上是一系列关于**张量**的复杂计算。无论是图像识别、自然语言处理还是推荐系统，其背后流动和运算的数据单元，均是形态各异的张量。因此，深刻理解张量的概念与原理，是掌握深度学习技术的关键一步。

然而，“张量”这一术语，常因其在数学和物理学中的严谨定义而显得高深莫测，令许多初学者望而却步。本课程旨在彻底澄清这一核心概念。我们将阐明，在深度学习领域，“张量”的本质远非一个复杂的数学抽象，而是一个极其基础且直观的计算机科学概念——**多维数组**。

本文将从数据在计算机内存中的最基本表示出发，循序渐进地构建起从标量、向量到高维数组的理解框架，并最终揭示“张量”这一命名背后的真相。我们还将结合业界主流框架 PyTorch，深入剖析常见张量操作背后的内存与元信息逻辑。掌握这些内容，你将发现，深度学习的数据基石原来如此清晰明了。

## 第一部分：从数字到多维数组——构建基础

![](https://feishu.cn/file/LkxEbrp2ZonW9mxWRPWcIrdlnOh)

### 1.1 标量：零维数组

一切始于最简单的单元。一个单独的数字，例如 `0`，在编程中称为**标量**。在计算机内存中，它可以被存储在一个固定的位置（一个内存地址），并通过一个变量来引用这个地址。从数组的维度角度看，这是一个 **零维数组**，因为它不包含任何维度信息。

![](https://feishu.cn/file/JCDJbXbb9odKLdxpmZtcKr89n4e)

### 1.2 向量：一维数组

当我们需要表示一组有序数字时，例如 `[1, 2, 3, 4]`，我们就得到了一个**向量**。在计算机中，这组数据通常被顺序地存放在一块连续的内存区域里。为了管理这组数据，我们需要记录两个关键信息：

- **起始地址**：第一个元素在内存中的位置。
- **元素个数**：这组数据共有多少个元素。

这就是一个 **一维数组**。它是构建更复杂结构的基础。

![](https://feishu.cn/file/N4UEbTVVDoK3t4xylozcyaGYnKb)

### 1.3 矩阵：二维数组

更进一步，如果我们希望数据具有行列结构，例如一个3行4列的网格，这就构成了一个**矩阵**。它的逻辑结构是二维的，但在内存中，数据依然以一维线性的方式连续存储。

为了在连续的内存中表达这种二维结构，我们需要引入两个关键概念：

- **形状**：即 `shape`，它定义了每个维度的大小。对于3行4列的矩阵，`shape` 就是 `(3, 4)`。
- **步幅**：即 `stride`，它定义了在**某个维度上移动一个单位时，需要在内存中跳过多少个元素**。对于一个行优先存储的 `(3, 4)` 矩阵：

  - 在**第一维度（行）** 上移动一步，意味着要跳过整整一整行（4个元素），所以步幅为 `4`。
  - 在**第二维度（列）** 上移动一步，仅需跳过下一个紧邻的元素，所以步幅为 `1`。

**索引计算**：利用 `shape` 和 `stride`，我们可以轻松定位任意元素。例如，要找到位于第1行第2列的元素（索引通常从0开始，即 `a[1][1]`），其内存偏移量的计算公式为：
`偏移量 = 行索引 * 行步幅 + 列索引 * 列步幅 = 1 * 4 + 1 * 1 = 5`。
这个计算结果告诉我们，该元素位于起始地址之后的第5个位置。

![](https://feishu.cn/file/TNRYbeR7VowVI7xpQyAcUlOfnFh)

### 1.4 高维数组：从三维到更高维度

理解了二维数组，三维及更高维数组便是自然的延伸。以 `shape` 为 `(2, 3, 4)` 的三维数组为例。我们可以借助“**分组套娃**”的思维模型来直观理解：

1. **第一维度（大小为2）**：首先，将整个数据块视为分成**2大份**。
2. **第二维度（大小为3）**：接着，将每一大份再细分成**3小份**。
3. **第三维度（大小为4）**：最后，每一小份中包含**4个基本元素**。

尽管超过三维后难以用图形直观绘制，但其在内存中的存储和索引逻辑与二维数组完全一致：数据连续存储，通过 `shape` 定义逻辑结构，通过 `stride` 计算元素偏移。

## 第二部分：揭开“张量”的面纱——命名与本质

![](https://feishu.cn/file/ZHL9bMQZyoHHlFx4c3yctGgWnKb)

### 2.1 术语的演变

在不同的学科中，这些多维数据结构有不同的称呼：

- **数学/线性代数**：标量、向量、矩阵。更高维的通常仍用矩阵或张量称呼，但定义严格。
- **计算机/数据结构**：零维数组、一维数组、二维数组……。
- **深度学习**：为了统一表示**任意维度**的数据，深度学习社区从物理学和数学中借用了“**张量**”一词。

![](https://feishu.cn/file/THQ3bnkCCoGi9vx9g5Tc571knse)

### 2.2 核心澄清：本质是多维数组

这是理解深度学习中“张量”概念最重要的一点：**深度学习框架（如 PyTorch, TensorFlow）中所说的“张量”，其本质仅仅是多维数组。**

它与数学、物理学中定义的“张量”（一种具有特定坐标变换规则的多重线性映射）**完全不同**。在深度学习的语境下，**一维张量就是向量，二维张量就是矩阵，三维及以上张量就是高维数组**。

因此，在学习初期，**完全无需**将深度学习中的张量与复杂的数学张量概念进行关联。直接将其理解为 **“带有形状、步幅等管理信息的多维数组”** ，是最直接、最有效的认知路径。

## 第三部分：张量的内存表示与元信息

为了高效地操作多维数组，深度学习框架采用了一种精巧的内存管理策略。

![](https://feishu.cn/file/Q3MGbpcR8oU3gvxJBKacg36sncg)

### 3.1 核心存储思想：数据视图

框架在底层通常只维护 **一份连续的数据存储块**。所有对张量形状、维度顺序的变换操作（如转置、切片），**默认都不会立即复制或移动底层的原始数据**。

取而代之的是，框架为每一个张量对象附加一系列的 **“元信息”**，这些信息定义了如何将连续的、一维的原始数据“视图”解释成我们想要的多维结构。这种机制极大地提升了计算效率。

![](https://feishu.cn/file/X54db77mroYLjtxurYJcTkNRnbK)

### 3.2 关键元信息详解

以 PyTorch 为例，一个张量对象主要包含以下核心元信息：

1. **`shape`**：一个元组，定义张量在每个维度上的大小。例如，`(3, 4)` 表示一个3行4列的矩阵。这是描述张量逻辑结构最直观的属性。
2. **`stride`**：一个元组，定义在每个维度上移动一个单位，需要在**底层连续内存**中前进的元素个数。它是实现高效索引和计算的关键。

   - 对于一个行优先的 `(3, 4)` 张量，`stride` 通常是 `(4, 1)`。
   - 对于列优先或经过转置的张量，`stride` 会相应改变，例如 `(1, 3)`。
3. **`contiguous`**：一个布尔值，标记张量的**逻辑遍历顺序**是否与**底层内存存储顺序**一致。

   - `True`：表示连续。通常新创建或经过 `contiguous()` 方法处理后的张量是连续的。
   - `False`：表示不连续。例如，对一个矩阵进行转置后，其逻辑顺序（先行后列）与内存中的原始存储顺序（行优先）就不一致了。许多要求数据内存布局连续的操作（如 `view`）无法直接在不连续的张量上执行。
4. **`offset`**：一个整数，标识张量所引用的数据在**原始连续存储块**中的起始位置偏移量。当进行切片操作时，切片后的张量与原始张量共享同一份底层数据，但 `offset`、`shape`、`stride` 等元信息会被更新，从而指向数据的不同部分。

## 第四部分：PyTorch中的张量操作实战

理解了元信息的作用，我们就能看穿 PyTorch 中常见操作的本质。

![](https://feishu.cn/file/Nw5obBfsboYBxmx9zr0chi0XnTu)

### 4.1 创建张量

使用 `torch.arange(12)` 会创建一个包含 `0` 到 `11` 的一维张量。在内存中，它就是12个连续的数字。其元信息为 `shape=(12,)`, `stride=(1,)`, `contiguous=True`。

![](https://feishu.cn/file/QpBzbTmbFou9RbxCkfycyqcGnjd)

### 4.2 改变形状：`reshape` 与 `view`

```Python
t = torch.arange(12)
t_reshaped = t.reshape(3, 4) # 或 t.view(3, 4)
```

- **本质**：这两个操作**仅修改张量的元信息**（主要是 `shape` 和 `stride`），使其指向同一份底层数据。
- **前提条件**：当且仅当张量是**内存连续**时，`view` 操作才能执行。它是一个纯粹的零拷贝（零成本）操作。
- **`contiguous` 的应对**：如果张量不连续（例如经过转置），直接调用 `view` 会报错。此时可以：

  1. 调用 `.contiguous()` 方法。该方法会**检查**连续性，如果不连续，则会**复制一份数据到新的连续内存**，并返回一个连续的新张量。然后再对其调用 `view`。
  2. 直接使用 `reshape`。`reshape` 是一个更智能的操作：它会先尝试像 `view` 一样工作（零拷贝），如果遇到不连续的情况，它会自动先执行一次类似 `contiguous()` 的数据拷贝，然后再改变形状。

![](https://feishu.cn/file/FBNMbg93go1NOJx7nIQcwDcUnjb)

### 4.3 改变维度顺序：`transpose`

```Python
t_matrix = t.reshape(3, 4)
t_transposed = t_matrix.transpose(0, 1) # 交换第0维和第1维
```

- **本质**：`transpose` 操作同样是**元信息操作**。它交换 `shape` 元组和 `stride` 元组中指定维度的值。
- **后果**：转置后，张量的逻辑遍历顺序改变，与原始内存顺序不再一致，因此 `contiguous` 属性变为 `False`。

![](https://feishu.cn/file/AGEgbhjJAoNakPxSsJucnVLJnSh)

### 4.4 切片操作

```Python
t_slice = t[3:10:2] # 从索引3到10（不包含），步长为2取数据
```

- **本质**：切片是另一种**元信息操作**。它不拷贝数据，而是通过修改元信息来创建一个对原数据子集的“视图”。

  - `offset` 会更新为起始索引（如 `3`）。
  - `shape` 会更新为切片后的元素个数。
  - `stride` 会更新为切片步长与原步幅的乘积（如原 `stride=(1,)`，步长为2，则新 `stride=(2,)`）。
  - `contiguous` 通常变为 `False`（因为跳过了元素）。

## 第五部分：总结与学习建议

![](https://feishu.cn/file/I4f6bxQ0NoNrGUx94dqcULkSn0d)

### 5.1 概念总结

1. **本质澄清**：深度学习中的“张量” **=** 多维数组。这是理解一切的前提。
2. **高效之源**：张量操作的灵活性源于其 **“视图”** 机制。框架通过维护一份底层数据和一组描述结构的 **元信息**（`shape`, `stride`, `contiguous`, `offset`），实现了对多维数据的高效管理与操作。
3. **框架角色**：PyTorch、TensorFlow 等框架的核心任务之一，就是为用户封装这些底层的元信息管理细节，提供直观的 API 来进行张量的创建、变形、计算和优化。

![](https://feishu.cn/file/PPYybYn2Uo7ntrxrAHFc5LnAnHg)

### 5.2 学习建议

1. **初期建立正确认知**：牢牢抓住 **“张量即多维数组”** 这一本质。无需纠结于数学定义，从计算机数据结构的角度去理解它。
2. **进阶理解元信息**：当基础知识牢固后，主动去了解 `shape`, `stride` 等元信息。理解为什么 `view` 要求连续，而 `reshape` 可以更灵活，这能帮助你写出更高效、更不易出错的代码。
3. **避免概念混淆**：在深度学习的上下文中，请刻意区分它与数学、物理学中“张量”概念的差异。前者是用于编程的数据容器，后者是具有深刻物理和数学内涵的抽象对象。

掌握张量，便是掌握了深度学习的数据语言。从此，面对各种复杂的神经网络结构，你都能清晰地看透其背后流动和变换的，不过是一些形状各异、被精心管理的多维数组而已。

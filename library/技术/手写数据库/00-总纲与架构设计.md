## 技术选型

| 模块 | 技术选择 | 说明 |
|------|---------|------|
| 语言 | Java | 面向对象，跨平台 |
| 存储 | 自定义文件格式 | 类MySQL InnoDB页结构 |
| 索引 | B+树 | 磁盘索引结构 |
| 事务 | MVCC + 锁 | 隔离级别支持 |
| 日志 | WAL | Redo + Undo |
| 网络 | Java NIO | 高并发连接 |

## 实现里程碑

```
里程碑1：基础架构（第1-2周）
  - 项目框架搭建
  - 客户端服务端通信
  - 协议报文解析
  - SELECT单表查询

里程碑2：存储引擎（第3-4周）
  - 页结构设计
  - 行存储格式
  - 简单的文件系统

里程碑3：索引系统（第5-6周）
  - B+树实现
  - 主键索引
  - 唯一索引

里程碑4：事务支持（第7-8周）
  - 锁机制
  - MVCC
  - 隔离级别

里程碑5：日志与恢复（第9-10周）
  - Redo日志
  - Undo日志
  - 崩溃恢复

里程碑6：DDL支持（第11-12周）
  - CREATE TABLE
  - ALTER TABLE
  - DROP TABLE

里程碑7：工具完善（第13-14周）
  - 命令行客户端
  - 备份恢复
  - 性能监控
```

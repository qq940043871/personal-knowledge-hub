## 核心组件：LLMApplication 主类

主类在初始化时装载 Tokenizer、模型、记忆系统、Skill 管理、MCP 服务、函数注册表与 Agent 编排器；`chat()` 方法按以下七步串起完整请求链路：

1. 解析请求
2. 获取历史上下文
3. Skill/MCP 预处理
4. Agent 编排决策
5. 执行工具（如需要）
6. 模型推理
7. 更新记忆

```python
class LLMApplication:
    """大模型应用主类"""
    
    def __init__(self, config: AppConfig):
        # 初始化各组件
        self.tokenizer = Tokenizer(config.model_path)
        self.model = ModelLoader.load(config)
        self.memory = MemorySystem(config.memory)
        self.skill_manager = SkillManager()
        self.mcp_server = MCPServer()
        self.function_registry = FunctionRegistry()
        self.agent = AgentOrchestrator()
        
    async def chat(self, request: ChatRequest) -> ChatResponse:
        # 1. 解析请求
        session_id = request.session_id
        user_message = request.message
        
        # 2. 获取历史上下文
        history = await self.memory.get_history(session_id)
        
        # 3. Skill/MCP预处理
        context = await self.preprocess(request)
        
        # 4. Agent编排决策
        plan = await self.agent.plan(user_message, context)
        
        # 5. 执行工具（如需要）
        if plan.needs_tools:
            result = await self.execute_tools(plan.tools)
            context = self.inject_context(result)
        
        # 6. 模型推理
        response = await self.model.generate(
            messages=history + [user_message],
            context=context
        )
        
        # 7. 更新记忆
        await self.memory.add(session_id, user_message, response)
        
        return response
```

## 请求流程：从路由到记忆更新的处理链路

> 请求依次经过路由、会话管理、Skill/MCP 预处理、Agent 编排、函数调用、推理引擎，最后**更新记忆**并返回响应。

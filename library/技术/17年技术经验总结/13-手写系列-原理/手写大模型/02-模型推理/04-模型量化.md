## 量化方法：FP16 / INT8 / INT4 / GPTQ·AWQ 四种类型

> 压缩越激进显存节省越多：**INT8 减少 75%、INT4 减少 87.5%**，但精度损失也随之增大；GPTQ/AWQ 通过校准量化保持更多精度。

```
量化类型：
  1. FP16（半精度）
     - 16位浮点
     - 减少50%显存
  
  2. INT8（8位整数）
     - 激活/权重量化
     - 减少75%显存
     - 可能损失精度
  
  3. INT4（4位整数）
     - 极致压缩
     - 减少87.5%显存
     - 显著精度损失
  
  4. GPTQ/AWQ
     - 校准量化
     - 保持更多精度
```

## 量化实现：对称量化与反量化的最小实现

- `DynamicQuantizer.quantize_tensor()`：FP16 直接 `half()`；INT8 做**对称量化**——`scale = abs().max() / 127`，除以 scale 后 round、clamp 到 [-128, 127]；
- `dequantize_tensor()`：反量化只需乘回 scale；
- `QuantizedLinear`：forward 时先把 int8 权重乘 `weight_scale` 反量化回浮点，再做普通线性运算。

```python
import torch
import torch.nn as nn
from typing import Dict

class DynamicQuantizer:
    """动态量化"""
    
    @staticmethod
    def quantize_tensor(tensor: Tensor, dtype: torch.dtype) -> Tensor:
        if dtype == torch.float16:
            return tensor.half()
        elif dtype == torch.int8:
            # 对称量化
            scale = tensor.abs().max() / 127
            quantized = (tensor / scale).round().clamp(-128, 127).to(torch.int8)
            return quantized, scale
        else:
            return tensor
    
    @staticmethod
    def dequantize_tensor(tensor: Tensor, scale: Tensor, dtype: torch.dtype) -> Tensor:
        if dtype == torch.int8:
            return tensor.float() * scale
        return tensor.float()


class QuantizedLinear(nn.Module):
    """量化线性层"""
    
    def __init__(self, weight, bias, bits=8):
        super().__init__()
        self.weight = weight
        self.weight_scale = weight.abs().max() / (2**(bits-1) - 1)
        self.bias = bias
    
    def forward(self, x):
        # 反量化
        weight_fp = self.weight.float() * self.weight_scale
        return x @ weight_fp + self.bias
```

## GGML 量化：按 block 分块的 GGUF 文件量化

- 量化块大小统一为 **32**：`Q4_0 / Q4_1 / Q5_0 / Q5_1 / Q8_0` 均为 block=32；
- `quantize_file()` 只处理 `dim() > 1` 的权重矩阵，量化后保存为 GGUF 文件；
- `quantize_weight()` 对每个 block 取 `scale = block.max() / (2**4 - 1)`，量化结果连同 scales、类型一起返回。

```python
class GGUFQuantizer:
    """GGUF格式量化"""
    
    # 量化块大小
    QUANT_BLOCKS = {
        "Q4_0": 32,  # 4位，block=32
        "Q4_1": 32,
        "Q5_0": 32,
        "Q5_1": 32,
        "Q8_0": 32,
    }
    
    @classmethod
    def quantize_file(cls, input_path: str, output_path: str, quant_type: str):
        """量化模型文件"""
        model = cls.load_model(input_path)
        
        for name, param in model.named_parameters():
            if param.dim() > 1:  # 权重矩阵
                quantized = cls.quantize_weight(param, quant_type)
                model[name] = quantized
        
        cls.save_model(model, output_path)
    
    @classmethod
    def quantize_weight(cls, weight: Tensor, quant_type: str) -> Dict:
        block_size = cls.QUANT_BLOCKS[quant_type]

        scales = []
```

# 结果处理

> 模块：FunctionCalling
> 更新时间：2026-03-29

---

Function Calling 的结果处理包含两件事：把函数结果**格式化**成模型可读的文本，以及支撑**循环调用**——工具结果回填消息后再次请求 LLM，直到模型不再调用工具。

## 一、结果格式化

> `ResultFormatter` 支持三种格式化模式：**json**（`json.dumps` 缩进输出）、**text**（递归转文本）、**auto**（dict/list 走 JSON，其余 `str()`）。

```python
class ResultFormatter:
    """结果格式化"""
    
    @staticmethod
    def format(result: Any, format_type: str = "auto") -> str:
        """格式化函数结果"""
        if format_type == "json":
            return json.dumps(result, ensure_ascii=False, indent=2)
        elif format_type == "text":
            return ResultFormatter._to_text(result)
        else:  # auto
            if isinstance(result, (dict, list)):
                return json.dumps(result, ensure_ascii=False)
            return str(result)
    
    @staticmethod
    def _to_text(result: Any, indent: int = 0) -> str:
        """递归转换为文本"""
        if isinstance(result, dict):
            lines = []
            for k, v in result.items():
                lines.append(f"{k}: {ResultFormatter._to_text(v, indent+2)}")
            return "\n".join(lines)
        elif isinstance(result, list):
            return "\n".join(f"- {ResultFormatter._to_text(item, indent)}" 
                          for item in result)
        else:
            return str(result)
```

## 二、循环调用

```python
class ToolLoopExecutor:
    """工具循环执行器"""
    
    def __init__(self, executor: FunctionExecutor, 
                 max_iterations: int = 10):
        self.executor = executor
        self.max_iterations = max_iterations
    
    async def execute_loop(self, messages: List[Dict]) -> str:
        """循环执行直到不调用工具"""
        for iteration in range(self.max_iterations):
            # 1. LLM生成
            response = await llm.chat(messages)
            
            # 2. 检查是否有函数调用
            if not response.tool_calls:
                return response.content
            
            # 3. 执行所有工具调用
            tool_results = []
            for tool_call in response.tool_calls:
                result = await self.executor.execute(tool_call)
                tool_results.append({
                    "tool_call_id": tool_call["id"],
                    "result": result
                })
            
            # 4. 添加到消息
            messages.append({
                "role": "assistant",
                "content": response.content,
                "tool_calls": response.tool_calls
            })
            
            for tool_result in tool_results:
                messages.append({
                    "role": "tool",
                    "tool_call_id": tool_result["tool_call_id"],
                    "content": tool_result["result"]
                })
        
        return "Maximum iterations exceeded"
```

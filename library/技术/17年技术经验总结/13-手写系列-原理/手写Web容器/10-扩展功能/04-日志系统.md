> 模块：扩展功能

## 日志级别：TRACE 到 FATAL 六级递进

> 级别从低到高为 **TRACE < DEBUG < INFO < WARN < ERROR < FATAL**，低于 Logger 设定级别的消息会被直接过滤。

```
TRACE < DEBUG < INFO < WARN < ERROR < FATAL

TRACE：最详细的日志
DEBUG：调试信息
INFO：一般信息
WARN：警告信息
ERROR：错误信息
FATAL：致命错误
```

## 日志实现：Logger、LogRecord 与 Handler 三件套

实现由三个部分组成：

- **Logger**：持有级别阈值与 Handler 列表，`log()` 中低于阈值的记录直接 return，其余分发给所有 Handler；
- **LogRecord**：封装级别、消息、异常、时间戳，`format()` 负责拼出 `时间 [级别] 消息` 格式，异常时追加堆栈；
- **ConsoleHandler / FileHandler**：分别把格式化后的日志输出到控制台和文件（追加写入）。

```java
public class Logger {
    private String name;
    private Level level = Level.INFO;
    private List<Handler> handlers = new ArrayList<>();
    
    public Logger(String name) {
        this.name = name;
    }
    
    public void trace(String msg) {
        log(Level.TRACE, msg);
    }
    
    public void debug(String msg) {
        log(Level.DEBUG, msg);
    }
    
    public void info(String msg) {
        log(Level.INFO, msg);
    }
    
    public void warn(String msg) {
        log(Level.WARN, msg);
    }
    
    public void error(String msg, Throwable e) {
        log(Level.ERROR, msg, e);
    }
    
    private void log(Level level, String msg) {
        log(level, msg, null);
    }
    
    private void log(Level level, String msg, Throwable e) {
        if (level.getValue() < this.level.getValue()) {
            return;
        }
        
        LogRecord record = new LogRecord(level, msg, e);
        
        for (Handler handler : handlers) {
            handler.publish(record);
        }
    }
    
    public void addHandler(Handler handler) {
        handlers.add(handler);
    }
}

public class LogRecord {
    private Level level;
    private String message;
    private Throwable exception;
    private long timestamp;
    private String loggerName;
    
    public LogRecord(Level level, String message, Throwable exception) {
        this.level = level;
        this.message = message;
        this.exception = exception;
        this.timestamp = System.currentTimeMillis();
    }
    
    public String format() {
        SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
        String time = sdf.format(new Date(timestamp));
        
        StringBuilder sb = new StringBuilder();
        sb.append(time).append(" [").append(level).append("] ");
        sb.append(message);
        
        if (exception != null) {
            sb.append("\n");
            StringWriter sw = new StringWriter();
            exception.printStackTrace(new PrintWriter(sw));
            sb.append(sw.toString());
        }
        
        return sb.toString();
    }
}

public class ConsoleHandler extends Handler {
    @Override
    public void publish(LogRecord record) {
        System.out.println(record.format());
    }
}

public class FileHandler extends Handler {
    private PrintWriter writer;
    
    public FileHandler(String filename) throws IOException {
        writer = new PrintWriter(new FileWriter(filename, true), true);
    }
    
    @Override
    public void publish(LogRecord record) {
        writer.println(record.format());
    }
}
```

## 使用示例：在 Servlet 中记录请求日志

```java
public class MyServlet extends HttpServlet {
    private static final Logger logger = new Logger(MyServlet.class.getName());
    
    @Override
    protected void doGet(HttpServletRequest request, HttpServletResponse response) {
        logger.info("Received GET request: " + request.getRequestURI());
        
        try {
            // 处理请求
            response.getWriter().println("Hello World");
        } catch (Exception e) {
            logger.error("Error processing request", e);
        }
    }
}
```

## 一、常见线程模型

> 从 BIO 到主从 Reactor 逐步演进，**Reactor 多线程是主流选择**。

```
模型1：BIO模型
  - 一个连接一个线程
  - 简单但扩展性差

模型2：Reactor单线程
  - 单线程处理所有IO
  - 简单但单点瓶颈

模型3：Reactor多线程
  - 主线程接收连接
  - 工作线程处理IO
  - 主流选择

模型4：主从Reactor
  - 主Reactor接收连接
  - 从Reactor处理IO
  - 高性能场景
```

## 二、Tomcat线程模型

> Acceptor 只负责 accept，请求处理交给线程池执行。

```java
public class Acceptor implements Runnable {
    private ServerSocket serverSocket;
    private ExecutorService executor;
    
    @Override
    public void run() {
        while (running) {
            try {
                Socket socket = serverSocket.accept();
                executor.execute(new SocketProcessor(socket));
            } catch (IOException e) {
                e.printStackTrace();
            }
        }
    }
}

public class SocketProcessor implements Runnable {
    private Socket socket;
    
    public SocketProcessor(Socket socket) {
        this.socket = socket;
    }
    
    @Override
    public void run() {
        try {
            // 解析请求
            HttpRequest request = parseRequest(socket);
            // 处理请求
            HttpResponse response = process(request);
            // 返回响应
            sendResponse(socket, response);
        } catch (IOException e) {
            e.printStackTrace();
        } finally {
            try {
                socket.close();
            } catch (IOException e) {}
        }
    }
}
```

## 三、线程池配置

> 核心参数：core 10、max 200、队列 100、keepAlive 60s，拒绝策略为 CallerRunsPolicy。

```java
public class ThreadPool {
    private int corePoolSize = 10;
    private int maxPoolSize = 200;
    private int queueCapacity = 100;
    private int keepAliveSeconds = 60;
    
    public ExecutorService create() {
        return new ThreadPoolExecutor(
            corePoolSize,
            maxPoolSize,
            keepAliveSeconds,
            TimeUnit.SECONDS,
            new LinkedBlockingQueue<>(queueCapacity),
            new ThreadFactory() {
                private AtomicInteger count = new AtomicInteger(1);
                @Override
                public Thread newThread(Runnable r) {
                    Thread t = new Thread(r, "http-exec-" + count.getAndIncrement());
                    t.setDaemon(true);
                    return t;
                }
            },
            new ThreadPoolExecutor.CallerRunsPolicy()
        );
    }
}
```

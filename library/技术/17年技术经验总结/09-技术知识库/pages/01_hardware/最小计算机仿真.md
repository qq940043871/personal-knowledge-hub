# 最小计算机 — 数字电路仿真

⚡ MINIMAL COMPUTER SIM：8 位 CPU · 16 字节 RAM · 数字电路仿真。支持运行/暂停、单步执行与复位操作，时钟速度可调（默认 5 Hz），并实时显示时钟信号（CLK）与周期计数（cycles）。中央画布提供电路可视化（实时信号流）。

## CPU 寄存器组

| 寄存器 | 说明 | 初始值 |
| --- | --- | --- |
| A | 累加器 | 0x00 |
| B | 通用 | 0x00 |
| PC | 程序计数器 | 0x00 |
| SP | 栈指针 | 0x0F（十进制 15） |
| IR | 指令寄存器 | 0x00 |
| MAR | 内存地址 | 0x00 |

标志位：Z、C（进位）、N、V，复位后均为 0。

ALU — 算术逻辑单元：待机时显示"待机"，执行运算时显示算式（如 `ADD: 0x01 + 0x02 = 0x03`）。

## 指令集 (ISA)

| 指令 | 操作码 | 说明 |
| --- | --- | --- |
| LDA #n | 0x01 | 加载立即数到A |
| LDB #n | 0x02 | 加载立即数到B |
| ADD | 0x10 | A = A + B |
| SUB | 0x11 | A = A - B |
| AND | 0x12 | A = A & B |
| OR | 0x13 | A = A \| B |
| STA addr | 0x20 | 存A到内存 |
| LDA addr | 0x21 | 从内存加载A |
| JMP addr | 0x30 | 无条件跳转 |
| JZ addr | 0x31 | 零则跳转 |
| HLT | 0xFF | 停机 |

仿真代码中还定义了面板未列出的操作码：NOP=0x00、XOR=0x14、NOT=0x15、JNZ=0x32、JC=0x33、PUSH=0x40、POP=0x41。

## 内存 (16 字节 RAM)

- 共 16 个字节单元，地址 0x00–0x0F
- 程序从地址 0x00 开始装入：每条指令占 1 字节操作码，带参数的指令再跟 1 字节参数
- 点击内存单元可查看其地址与当前值

## 总线状态

- 地址总线：8 位（初始 0x00）
- 数据总线：8 位（初始 0x00）
- 控制总线：READ / WRITE / ALU / IDLE（初始 IDLE）

## 执行流程（取指—译码—执行）

1. **取指 (Fetch)**：MAR ← PC，IR ← RAM[PC]
2. PC 自增；若指令需要参数，再从内存读取 1 字节参数
3. **译码 & 执行 (Decode & Execute)**：执行指令，更新寄存器、标志位与总线状态，周期计数加 1

CPU 执行 HLT 后停机，再次运行前需先复位（提示 `CPU 已停机，请复位`）。

## 预设演示程序

仿真器内置 4 个演示程序，点击即可加载到内存：

### 1+2=3 加法演示

```text
LDA #01
LDB #02
ADD
STA 08
HLT
```

### 10-3=7 减法演示

```text
LDA #0A
LDB #03
SUB
STA 08
HLT
```

### 循环计数 (0→5)

| 地址 | 指令 | 说明 |
| --- | --- | --- |
| 0 | LDA #00 | A=0 |
| 2 | LDB #01 | B=1 |
| 4 | ADD | A=A+B |
| 5 | STA 0E | 存结果 |
| 7 | LDB #05 | B=5 |
| 9 | SUB | A-5 |
| 10 | JZ 0C | 等于5则跳 |
| 12 | LDA 0E | 重新加载A |
| 14 | LDB #01 | B=1 |
| 16 | JMP 04 | 跳回ADD |
| 18 | HLT | 停机 |

### AND 位运算

```text
LDA #CC
LDB #AA
AND
STA 08
HLT
```

## 系统日志

日志区按时间顺序记录系统信息、程序加载与每条指令的执行过程，例如：

- `加载程序: 1+2=3 加法演示`
- `写入 8 字节到 RAM[0x00..0x07]`
- `[00] LDA #01 → A=01`
- `CPU 开始运行...`

## 复位与加载

- 复位：CPU 恢复初始状态（A/B/PC/IR/MAR 清零、SP=0x0F、标志位清零、周期计数归零、总线回到 IDLE），日志提示 `CPU 复位完成`
- 加载演示程序：先复位 CPU，再清空内存并将程序从地址 0x00 顺序写入

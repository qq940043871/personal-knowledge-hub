# 硬件驱动操作系统 - 架构师学习笔记

真实主板布局模拟 - 硬件工作原理可视化。

## 主板组件布局

模拟主板上布置的硬件组件及其规格：

| 组件 | 规格/说明 |
| --- | --- |
| 电源供应 | ATX 24Pin |
| BIOS芯片 | UEFI固件 |
| 时钟发生器 | 4.0 GHz |
| 北桥芯片 | 内存控制器 |
| CPU | 8核心处理器 |
| 内存插槽1 | DDR4 8GB |
| 内存插槽2 | DDR4 8GB |
| 南桥芯片 | I/O控制器 |
| 存储控制器 | SATA/NVMe |
| 显卡 | PCIe x16 |
| 网卡 | PCIe x1 |
| USB控制器 | USB 3.2 |
| 操作系统内核 | Linux Kernel |
| 应用程序 | 用户进程 |
| 显示输出 | 显示器 |

## 工作流程说明

### 电源启动流程

1. **电源供应**：电源供应器开始供电，主板各组件获得电力。
   - `[电源] ATX电源供应器启动，提供+12V、+5V、+3.3V电压`
2. **BIOS自检**：BIOS芯片进行硬件自检和初始化。
   - `[BIOS] 系统自检开始... 检测CPU、内存、存储设备`
3. **时钟启动**：时钟发生器开始产生系统时钟信号。
   - `[时钟] 系统时钟启动，频率: 4.0 GHz`
4. **芯片组初始化**：北桥和南桥芯片组初始化。
   - `[芯片组] 北桥芯片初始化内存控制器，南桥芯片初始化I/O控制器`
5. **CPU启动**：CPU开始执行引导程序。
   - `[CPU] 处理器启动，开始执行引导程序`
6. **系统加载**：操作系统内核加载到内存。
   - `[系统] 操作系统内核加载完成，系统启动成功`

电源启动完成后，系统正常运行。

### 应用启动流程

1. **用户操作**：用户双击应用程序图标。
   - `[用户] 双击应用程序图标`
2. **进程创建**：操作系统创建新进程。
   - `[系统] 创建新进程，分配进程ID`
3. **内存分配**：为应用程序分配内存空间。
   - `[内存] 分配内存空间，加载程序代码`
4. **程序加载**：应用程序代码加载到内存。
   - `[存储] 从磁盘读取程序文件到内存`
5. **CPU执行**：CPU开始执行应用程序指令。
   - `[CPU] 开始执行应用程序指令`
6. **显示输出**：应用程序界面显示到屏幕。
   - `[显示] 应用程序界面渲染完成`

应用程序启动完成。注意：若系统尚未上电，应用启动会报错 `[错误] 系统未启动，请先启动电源`。

# 新手学习路线

> 返回 [投资与交易总纲](<README.md>)

如果从头再学一遍交易，按这个顺序走：

1. **入门**：新手炒股 8 讲（088-095）——选股、买卖点、仓位、跟庄、解套
2. **筑基**：《什么是真正的交易》17 讲（096-112）——性格、趋势/反转、交易体系
3. **进阶**：《像证券交易员一样思考和行动》6 讲（113-119）——理解市场、绝招、纪律
4. **开胃**：三个汉堡经济学、慢慢变富（底层逻辑 001/002/108）

学完再回 02/03 册深化，别在第一步恋战。

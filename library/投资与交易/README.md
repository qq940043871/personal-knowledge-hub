## 三、使用说明

1. **链接指向归档区**：MOC 里所有链接形如 `../../语雀备份/...`，在 VS Code / Obsidian / Typora 等编辑器里可直接点开；知识库网页预览（index.html）只能浏览本目录内的 md，跳转归档请在文件系统里操作。
2. **原文只读**：发现某篇值得深挖，把提炼写进本目录（或对应主题文件），**不要改归档原件**。
3. **新增笔记**：今后投资类新笔记直接写在本目录，不再进备份区。
4. **更新索引**：归档区若有新增，改 `tools/gen_invest_moc.py` 的 RULES 后重跑即可重新生成 7 册 MOC（脚本自带防漏印/防重复/链接存在性三重校验）。

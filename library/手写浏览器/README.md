## 各模块概述

| 模块 | 核心内容 | 文件数 |
|------|---------|--------|
| **00-总纲** | 整体架构设计 | 1 |
| **01-网络层** | DNS解析、TCP连接、HTTP请求响应 | 4 |
| **02-URL解析** | URL解析、资源加载、缓存策略 | 3 |
| **03-HTML解析器** | 词法分析、DOM树构建、容错处理 | 3 |

| **06-渲染引擎** | 绘制、图层管理、GPU加速 | 3 |

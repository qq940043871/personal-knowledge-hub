# 放量下跌

放巨量下跌的股票不能一概而论能否买入，**核心看股价位置、放量成因、基本面、量能持续性**，且必须配合严格仓位与止损，避免"接飞刀"。

## 一、先分场景定方向

- **高位放量下跌**（近3个月涨幅50%+、估值高位）：大概率主力出货，风险极高，禁止买入，持股者立即减仓/清仓。数据显示3天内续跌概率超82%，平均跌4.3个点。
- **低位放量下跌**（前期跌幅30%+、估值低位、横盘后）：或为恐慌洗盘，抛压释放后可能止跌反弹，可小仓位试错，等缩量企稳再分批加仓。
- **基本面恶化/突发利空**（业绩暴雷、违规、行业逻辑崩坏）：放量下跌是价值回归，坚决不买，持股者果断止损。
- **大盘/板块系统性杀跌**：先看指数是否企稳，个股若基本面没问题，可等缩量止跌后再布局。

## 二、操作要点（可买入时）

1. **量能确认**：看巨量是否为短期脉冲（如比前5日均值放50%+），次日快速缩量（地量）、股价不创新低，才是企稳信号。

2. **入场时机**：尾盘轻仓试探；等缩量企稳、出现阳包阴或回踩关键支撑（10日线/前期低点）再加仓。

3. **仓位与止损**：总仓位≤5成，单票≤2成；止损设放量下跌低点或跌幅8%-10%，破位立即离场。

4. **辅助验证**：查龙虎榜/主力资金流向、业绩与行业逻辑，确保非基本面崩塌导致的放量。

## 三、实战步骤（低位+基本面无坏）

1. **巨量下跌当日**：尾盘小仓（总资金5%-10%）试探，不追单。

2. **次日-3日**：缩量企稳且不创新低，再加10%-15%；若续跌且放量，止损离场。

3. **反弹阶段**：回踩支撑有效再加仓，反弹至压力位（如20日线）分批止盈。

## 四、结论与提醒

- **结论**：高位放量跌坚决不买；低位+基本面扎实+缩量企稳可小仓试错；基本面差一律不碰。
- **提醒**：普通投资者优先回避"放量下跌抄底"，更适合等明确止跌信号再入场，保住本金比赚快钱更重要。

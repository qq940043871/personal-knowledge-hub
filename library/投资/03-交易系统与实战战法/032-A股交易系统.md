| **系统模块**|**核心维度**|**具体规则/标准**|**适用场景**|**风险控制要点** |
| --- | --- | --- | --- | --- |
| **一、标的筛选系统** | 1. 行业选择 | - 优先选择“政策支持+高景气”行业：如新能源（储能/光伏）、高端制造（半导体设备）、消费升级（必选消费/医疗消费）、硬科技（AI/机器人）   - 规避“政策抑制+低景气”行业：如高污染行业、产能过剩传统制造业、受宏观政策收缩影响的强周期行业 | 建仓前行业赛道判断 | - 单一行业配置不超过组合总资产的30%，避免行业黑天鹅冲击   - 定期（每季度）更新行业景气度数据，动态调整行业权重 |
|  | 2. 个股基本面筛选 | - 盈利能力：近3年归母净利润复合增速≥15%，ROE（加权）≥12%，毛利率≥25%（非金融类）   - 财务健康：资产负债率≤60%，经营性现金流净额与净利润比值≥0.8，应收账款周转天数≤行业均值   - 成长潜力：研发投入占比≥5%（科技类）/≥2%（消费类），近2年营收增速≥10%   - 股东回报：近3年现金分红比例≥30%，无实控人大额减持（近1年减持≤2%） | 个股初筛、核心标的锁定 | - 排除近3年被出具非标准审计意见、存在资金占用/违规担保的公司   - 警惕“存贷双高”（货币资金≥5亿且有息负债≥10亿）标的 |
|  | 3. 估值安全边际 | - 市盈率（TTM）：低于近5年历史60%分位，且低于同行业龙头公司估值20%以内   - 市净率（PB）：低于近5年历史50%分位（重资产行业）/40%分位（轻资产行业）   - PEG（动态）：≤1.2（成长股）、≤0.8（价值股） | 确定个股是否具备买入估值条件 | - 不买入估值超近5年90%分位的标的，避免“高估值站岗”   - 动态跟踪估值变化，若估值回归至历史80%分位以上，启动减仓评估 |
| **二、仓位管理系统** | 1. 总仓位控制 | - 市场环境分档：   - 牛市（沪深300市盈率≥近5年80%分位）：总仓位60%-70%   - 震荡市（沪深300市盈率30%-80%分位）：总仓位40%-60%   - 熊市（沪深300市盈率≤近5年30%分位）：总仓位20%-40%   - 单一个股仓位：不超过总资产10%，核心标的（基本面+估值双优）可放宽至15% | 全市场仓位中枢设定 | - 禁止满仓（100%仓位），始终保留至少10%现金应对极端行情   - 若单一个股仓位被动超15%（如股价暴涨），5个交易日内降至15%以内 |
|  | 2. 建仓节奏 | - 首次建仓：单只标的建仓占目标仓位的30%（如目标仓位10%，首次买入3%）   - 补仓条件：股价较首次买入价下跌10%-15%（基本面无恶化），补仓比例为目标仓位的20%   - 满仓时机：分3-4批建仓，完成满仓不超过3个月，避免“一次性抄底” | 新标的买入过程 | - 补仓前需重新验证基本面（如是否发布业绩预警、行业政策是否变化）   - 单只标的补仓不超过2次，避免越跌越补导致仓位失控 |
|  | 3. 减仓/清仓触发仓位 | - 部分减仓：单只标的收益达30%-50%（成长股）/20%-30%（价值股），减仓50%（如从10%仓位降至5%）   - 清仓触发：单只标的收益达80%以上（且估值超历史90%分位），或基本面恶化（如净利润增速降至5%以下），立即清仓 | 标的盈利兑现、风险预警时 | - 减仓/清仓需分1-2批完成（尤其是流动性差的标的），避免单次交易冲击股价   - 清仓后需记录“清仓理由”，用于后续复盘 |
| **三、交易时机系统** | 1. 买入时机 | - 基本面时机：业绩预告/年报超市场预期（如净利润增速高于一致预期20%以上）、重大研发突破（如专利落地、产品量产）、行业政策利好（如补贴加码、需求放量）   - 技术面时机：股价回调至20日均线/60日均线且缩量企稳（成交量较5日均量萎缩30%以上）、MACD底背离（股价创新低，MACD不创新低） | 建仓、补仓时点选择 | - 不追涨“涨停股”“连板股”（除非有明确基本面支撑）   - 避免在大盘单日涨幅超2%、市场情绪过热时集中买入 |
|  | 2. 卖出时机 | - 止盈时机：达到目标收益（如单只标的年化收益20%以上）、估值触及历史高位（如PE超近5年90%分位）、行业景气度下滑（如需求增速降至5%以下）   - 止损时机：股价较买入成本下跌15%（基本面无恶化）、较买入成本下跌10%且基本面恶化（如业绩变脸、违规被查）、触发退市预警（如股价低于1元、净资产为负） | 盈利兑现、风险止损 | - 止损需严格执行，禁止“扛单”（如股价下跌后等待反弹而不止损）   - 止盈不“贪心”，避免因等待更高收益导致利润回吐 |
|  | 3. 回避时机 | - 市场层面：大盘处于“政策利空密集期”（如加息、收紧监管）、成交量持续萎缩（沪深两市日成交额＜6000亿元）、主要指数（如创业板指）破位下跌（跌破年线且无企稳信号）   - 个股层面：标的停牌前（无明确利好）、业绩披露窗口期（年报/季报前10天，避免业绩雷）、董监高集中减持期 | 暂停交易、规避风险 | - 回避时机内禁止新开仓，仅处理已持仓标的的止损/止盈   - 若持仓标的处于回避场景，需提高跟踪频率（如每日查看公告） |
| **四、风控合规系统** | 1. 风险预警指标 | - 组合层面：最大回撤≥20%（需暂停建仓，复盘风险来源）、单一行业亏损超15%（需减仓该行业标的）   - 个股层面：净利润同比下滑超30%、毛利率下滑超5个百分点、被交易所问询/立案调查（需启动清仓评估） | 组合风险监控、个股风险排查 | - 每日收盘后查看“风险预警指标”，每周生成《风险监控报告》   - 若触发预警，24小时内制定应对方案（如减仓、清仓、补充调研） |
|  | 2. 合规交易要求 | - 禁止行为：使用他人账户交易、内幕交易（如利用未公开信息买卖）、短线交易（上市公司董监高亲属6个月内反向交易）、操纵股价（如集中资金拉抬/打压）   - 交易记录：每笔交易后24小时内记录《交易日志》（含买卖理由、价格、数量、仓位变化） | 合规交易执行、交易记录留存 | - 定期（每月）自查合规情况，避免触碰监管红线   - 保存交易记录（至少3年），以备监管核查或复盘使用 |
|  | 3. 应急处理机制 | - 极端行情（如熔断、股灾）：立即暂停手动交易，启用“预设止损指令”（如个股下跌15%自动触发止损），现金仓位提升至30%以上   - 个股突发黑天鹅（如财务造假坐实）：1小时内完成清仓（流动性允许情况下），若无法立即清仓，后续每下跌5%补清仓1次，直至清仓完毕 | 极端行情、突发风险应对 | - 预设“应急联系人”（如券商客户经理），突发情况可快速沟通   - 定期（每季度）测试应急处理流程，确保机制有效 |
| **五、复盘优化系统** | 1. 每日复盘 | - 核心内容：当日持仓标的涨跌原因（基本面/消息面/资金面）、市场风格变化（如价值/成长轮动、大小盘切换）、交易执行情况（是否按规则买入/卖出）   - 输出：《每日复盘笔记》，重点标注“未按规则交易”“超预期涨跌”的标的 | 每日交易总结、短期策略调整 | - 每日复盘时间不低于30分钟，避免“只交易不总结”   - 对“未按规则交易”的情况，分析原因（如情绪干扰、规则漏洞），24小时内制定改进措施 |
|  | 2. 月度复盘 | - 核心内容：组合月度收益率（与沪深300/行业指数对比）、仓位控制效果（是否符合市场环境分档要求）、标的筛选准确率（买入标的中盈利标的占比≥60%为合格）、风控指标达标情况（最大回撤是否≤预设值）   - 输出：《月度复盘报告》，含“亮点”“问题”“改进计划” | 组合业绩评估、系统规则优化 | - 月度复盘需邀请“外部顾问”（如资深投资者、分析师）参与，提供客观建议   - 若月度收益率跑输基准10%以上，需深度复盘（如行业选择、标的筛选、时机判断是否存在问题） |
|  | 3. 年度优化 | - 核心内容：全年业绩复盘（年化收益率、最大回撤、夏普比率）、交易系统有效性评估（如标的筛选标准准确率、仓位管理对收益的贡献）、市场环境变化（如政策导向、经济周期）对系统的影响   - 输出：《年度系统优化方案》，调整“筛选标准”“仓位分档”“时机规则”等核心要素 | 交易系统迭代、长期策略升级 | - 年度优化需结合宏观经济展望（如GDP增速、货币政策），避免系统与市场脱节   - 优化后的规则需先在“模拟盘”测试1个月，验证有效后再应用于实盘 |

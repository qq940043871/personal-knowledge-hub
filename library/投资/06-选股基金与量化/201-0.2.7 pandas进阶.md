### 三、数据规整

Pandas提供了大量的方法能够轻松的对Series，DataFrame和Panel对象进行各种符合各种逻辑关系的合并操作，主要介绍三个常用操作。

| **操作方式** | **释义** |
| :--- | :--- |
| concat | 可以沿一条轴将多个对象堆叠到一起。 |
| append | 将一行连接到一个DataFrame上 |
| duplicated | 移除重复数据 |

# 后疫情时代消费行业新趋势（1）

## 一、消费品牌护城河 00:00

### 1. 做终端的思路 00:26
- 终端思维特征：特斯拉通过降价策略快速占领市场份额，每辆车可赚$1万美金，上海超级工厂年产能150万辆，具备充足利润空间支撑降价策略。
- 品牌思维对比：传统品牌（如LV、巴宝莉）会销毁滞销产品维护品牌价值，而终端思维允许通过低价获取用户后在其他环节变现。
- 行业应对策略：比亚迪推出仰望U8（售价百万级）走潮牌路线，与特斯拉形成差异化竞争，股价在行业普跌时保持坚挺。
- 关键区别：
    - 终端模式：低价获客→规模效应→其他变现（如特斯拉通过车载服务盈利）
    - 品牌模式：维护溢价→限量供应→心智占领（如茅台控量保价）

### 2. 茅台的经营 05:20
- 产能扩张：投资155亿扩建1.8万吨基酒产能，五年后总产能提升35%，明牌承诺业绩增长。
- 品牌护城河：
    - 配方独特性（酱香工艺无法复制）
    - 心智锚定（"国酒"地位）
    - 控量策略（年产约5万吨，供需失衡）
- 分析框架：
    - 纵轴：品牌溢价能力（茅台、苹果、仰望在顶端）
    - 横轴：供应链效率（特斯拉、比亚迪在中段）

### 3. 消费品的品牌护城河 06:30
- 无护城河品类：
    - 功能饮料（宝矿力、外星人）
    - 乳制品（旺仔牛奶年销100亿 vs 蒙牛/伊利千亿规模）
    - 关键差异：蒙牛/伊利每年砸重金占位"两大品牌"心智
- 护城河构建方法：
    - 持续品牌投入（伊利2022年回购3.03亿股）
    - 独特产品体验（茅台酒体勾兑工艺）
    - 生态闭环（苹果iOS圈住7.3亿高净值用户）

### 4. 政策解读 10:14
- 政策信号：
    - 郭树清提出"将当期总收入最大可能转化为消费"
    - 重点支持住房/汽车等大宗消费
    - 强化教育/文化等服务消费金融支持

#### 1）消费品牌护城河案例 11:54
- 苹果护城河：
    - 全球7.3亿iOS用户（相当于世界第三人口大国）
    - 中国2.3亿高净值用户
    - 系统级控制（旧机型降速策略延长换机周期）
    - 滚动市盈率仅20倍（消费电子低谷期估值优势）

## 二、消费品的选择 14:32
- 选择标准：
    - 右端品牌：茅台/苹果/仰望（强定价权）
    - 左端供应链：果链代工厂（面临产能转移风险）
    - 中间陷阱：旺旺等（品牌投入不足+配方无壁垒）
- 核心指标：
    - 敢回购：牧原（10-20亿）/温氏（9-18亿）回购计划
    - 高毛利：特斯拉单车利润$1万 vs 比亚迪￥5000
    - 政策契合：2023年消费股为政策主线

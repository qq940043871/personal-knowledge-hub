## 二、板块选择决策表（波段可操作版）

下面是一个你 **每天 / 每几天** 检查板块潜力的决策表。你可以根据这个表格做筛选，决定是否跟进入某个板块。

| 检查维度 | 检查内容 | 是 / 否 / 有条件 | 操作建议（波段） |
| --- | --- | --- | --- |
| **宏观** | 当前利率趋势：宽松还是收紧？ |  | 若宽松 → 成长 /科技 /基础设施板块有利； 若收紧 → 防御 /周期为主线 |
| **资金面** | 最近 3–5 天该板块是否有明显资金流入（主力 /公募 /机构）？ |  | 若是：继续关注且可能入场。若否：谨慎，观望或打小仓。 |
| **政策** | 有无新的政策利好或重大规划（五年规划、新基建、能源转型等）？ |  | 若有：作为中长期支撑；波段可考虑关键事件前后建仓。若无：不主动重仓。 |
| **景气度 /基本面** | 行业核心景气指标是否在改善？（价格、订单、成本、利润） |  | 若改善：趋势有望继续，可波段介入。若不确定：等待数据进一步确认。 |
| **技术面 /轮动** | 板块是否处于“启动期”或“中途回调期”？ | 启动期 / 回调期 / 高位期 | 启动期和中途回调期是波段的重点建仓窗口。高位期谨慎追高。 |
| **龙头确认** | 板块里是否有明显的龙头股在率先启动（量能、涨幅、换手）？ |  | 有龙头：优先考虑龙头做波段标的。没有龙头：可分散小仓或等待更明确信号。 |
| **风险管理** | 当前板块是否有政策、市场、技术等明显风险？ |  | 若风险较大：建议设置较紧止损 /分批建仓。若中性或小风险：常规波段操作。 |

## 三、为波段风格定制的板块筛选策略

结合你是 **波段投资者**，我为你定制下面这套策略：

1. **核心关注板块**：优先关注 “新能源（光伏 +风）、储能、电力基础设施、AI 基础设施” 这四个板块。
    - 这些板块既有中长期确定性（政策 +景气），又有波段机会（启动 +回调）。
    - 半导体 /新能源车可作为次级机会，根据资金与技术节奏参与。
2. **建仓节奏**：
    - **分批建仓**：不要一次全上。用三步建仓法：启动阶段 +第一轮确认 +波段调整。
    - **加码时机**：当资金流明确 +行业基本面持续向上 +龙头开始发力时加码。
    - **止盈 /止损**：设中短期止盈点 +较紧的止损（特别是政策 /技术风险较大的板块）。
3. **信息捕捉机制**：
    - 每周重点看政策公告（政府文件、新基建规划、能源政策）
    - 每月关注研报（分析机构对行业景气度、订单、价格等的跟踪）
    - 每天/每几天用上面的 **决策表** 检查板块是否有启动信号
4. **组合构建建议**（波段组合示例）：
    - **主战仓（60–70%）**：新能源 + 储能 +电力基础设施板块里的龙头或高潜力个股
    - **辅助仓（20–30%）**：AI 基础设施 + 半导体标的，用于捕捉技术 +资金结构性机会
    - **防守仓（10–20%）**：一些稳健现金 /防御型股票或 ETF，以防波段出错、市场快速波动
5. **风险控制**：
    - 定期复盘波段表现：每 1–2 周复看你板块判断 +实际表现是否匹配
    - 严格止损：波段交易最重要的是保本金 +锁部分利润
    - 分散风险：不要把所有资金压在一个板块里，即使它是最看好的那个

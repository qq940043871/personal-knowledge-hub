# 后疫情时代消费行业新趋势（2）

## 一、消费行业趋势分析 00:00

### 1. 东方财富分析 00:02
- 业务模式：主要收入来自天天基金等平台，属于典型的逆周期公司。当市场行情好时，老百姓会大量购买基金，但公司业绩会延迟反应。
- 投资逻辑：
    - 买入时机：应在市场冷清、投资者犹豫不决时买入
    - 卖出时机：当市场特别火爆时就应该考虑离场
    - 典型案例：像张坤、葛兰的基金在市场火爆时被追捧，冷清时无人问津

### 2. 宁德分析 01:19
- 市场地位：在动力电池领域具有极强议价权，下游电动汽车公司相对弱小
- 财务表现：预计利润增长383%-98%，主要来自对上下游的压榨
- 估值分析：
    - 20倍PE在牛市环境下被认为合理
    - 行业竞争格局：国轩高科、中航新航等竞争对手目前都不赚钱

### 3. 新东方在线分析 02:37
- 短期风险：
    - 大量主播宣称对新东方在线上涨负责，显示市场过热
    - 董宇辉直播间人数出现下滑迹象（从10万+降至9万+）
- 商业模式：
    - 本质是寄生在抖音平台上的MCN机构
    - 通过不断扩品类（如美妆、腔镜游）寻求增长
    - 流量获取方式与传统线下教育点不同，存在分配问题

### 4. 东方甄选分析 05:36
- 运营数据：
    - 2000多万粉丝，复购率极高
    - 依靠董宇辉等超头部主播的个人魅力
- 财务表现：毛利高达40%，被质疑"坑粉丝"
- 生命周期担忧：
    - 市场已反映极高增长预期（假设年增长40%）
    - 主播个人IP能否持续吸引粉丝存疑
    - 董宇辉通过强调单身等人设维持热度

### 5. 消费板块分析 09:08

#### 1）茅台分析 09:16
- 核心优势：
    - 世界稀缺的快消奢侈品
    - 政策压制消除（增持15-30亿股票计划）
- 市场表现：
    - 外资持续买入（与五粮液合计149亿）
    - 春节动销表现强劲
- 行业评价：某白酒公司董事长私下购买酒鬼酒股票，被视为行业最高认可

#### 2）餐饮行业分析 12:24
- 消费复苏：
    - 北京聚宝源等餐厅出现多年未见的人山人海
    - 服务跟不上需求（排号系统混乱、包间不开放）
- 行业变迁：
    - 全聚德等老字号因油大、咸味重不再符合现代需求
    - 大董、盛永兴等新品牌崛起
- 预制菜趋势：
    - 人均200元以下餐厅基本使用预制菜
    - 上菜速度显著提升（从一道道上变为同时上）
    - 部分餐厅的"现包"场景可能只是表演

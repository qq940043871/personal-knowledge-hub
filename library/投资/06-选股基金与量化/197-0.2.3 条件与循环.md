# 条件与循环

## 第三节：条件与循环

### 一、if语句

注意两点：一是**缩进**，Python是用缩进来标识出哪一段属于本循环；二是**条件后面有冒号**：

In [1]:

```plain
j=2.67
if j<3:
    print('j<3')
```

```plain
j<3
```

对于多条件，要写成**elif**，标准格式为：

```plain
if 条件1:
执行语句1
elif 条件2:
执行语句2
else:
执行语句3
```

注意**if…elif…else三个是并列的，不能有缩进**：

In [2]:

```plain
t=3
if t<3:
    print('t<3')
elif t==3:
    print('t=3')
else:
    print('t>3')
```

```plain
t=3
```

### 二、while true/break语句

该语句的格式为：

```plain
while true即条件为真:
执行语句
if中断语句条件 : break
```

看个例子：

In [4]:

```plain
a=3
while a<10:
    a=a+1
    print(a)
    if a==8: break
```

```plain
4
5
6
7
8
```

虽然while后面的条件是a < 10，即a小于10的时候一直执行，但是**if条件中规定了a为8时就break掉**，因此，输出只能输到8。

### 三、for语句

可以遍历一个序列/字典等。

In [5]:

```plain
a=[1,2,3,4,5]
for i in a:
    print(i)
```

```plain
1
2
3
4
5
```

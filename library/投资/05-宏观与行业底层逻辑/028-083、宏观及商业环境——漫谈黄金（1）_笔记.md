# 漫谈黄金（1）

## 一、美国宏观政策如何影响金价及我们对金价的看法（00:05）

### 1. 全球影响（00:57）

- **就业市场表现**：3月美国大非农报告显示就业岗位上涨，私营和公共部门需求同步增长，薪资水平提升，劳动力参与率上升，失业率和通胀率保持稳定且略有降低
- **货币政策预期**：强劲数据导致市场对美联储降息预期减弱，认为当前通胀走低情况下已无继续降息必要
- **全球资产联动**：该政策变化对黄金、比特币、美股等资产产生显著影响。其中美股在国债利率高企的利空预期下仍保持强劲走势，主要由超级科技股引领

>（原文此处有配图，导出未附）

- **市场异常现象**：出现**美债强势、股市走强、黄金创新高、比特币突破历史记录的四重多头格局**，这种多资产同步走强在历史上非常罕见
- **背离逻辑**：理论上强劲就业数据应利空股市，但实际表现为：黄金突破2350（摩根大通预测将冲击2500），比特币创新高，国内金店挂牌价普遍突破700元/克（2024年4月价格）

### 2. 盛世收藏乱世黄金（04:31）

>（原文此处有配图，导出未附）

- **历史回报率**：过去10-20年黄金年化回报率仅8.5%，职业投资人认为其无法跑赢通胀，属于守财工具而非增值资产
- **投资时点选择**：专业做法是**在美联储降息周期买入，加息周期卖出**，与股票、基金等主流投资品操作逻辑不同
- **文化心理因素**：当前市场形成"黄金恒久远，一颗永流传"的共识，将黄金视为穿越周期的稳定锚，反映普遍避险情绪

### 3. 美元与黄金（06:12）

>（原文此处有配图，导出未附）

- **货币锚定变迁**：布雷顿森林体系时期美元与黄金挂钩（脱钩后黄金上涨50倍），后转为石油锚定，现今以信用为锚
- **当代困境**：全球对美元信用产生质疑，中国作为贸易顺差大国（占全球1/4），人民币在金砖货币中具有升值潜力
- **美债风险**：美国债务率预计十年内突破110%，媒体普遍认为其债务轨道不可持续，助推黄金"传宗接代"的避险叙事

### 4. 是否购买金条的观点（10:28）

- **短期风险**：当前价位（2350美元/盎司）存在强烈回调压力，从经济学原理看应与美元走势负相关，现呈现逻辑背离
- **长期配置**：若判断全球经济将长期处于地缘政治动荡、经济萧条状态，黄金和比特币均可作为配置选项
- **操作建议**：
    - 偏好实物可等待回调后购买金条
    - 流动性需求可选择黄金ETF
    - 需警惕短期30%以上的回调风险

>（原文此处有配图，导出未附）

- **核心原则**：黄金价格最终仍将回归**与经济繁荣负相关、与萧条正相关**的基本规律，需持续关注全球货币政策、地缘政治等变量
- **专业认知**：黄金是经济波动的晴雨表之一，但非唯一指标，职业投资人更倾向选择股票、基金等能跑赢通胀的资产

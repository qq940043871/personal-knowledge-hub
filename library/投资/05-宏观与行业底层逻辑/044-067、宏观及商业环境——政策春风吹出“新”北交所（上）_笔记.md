# 政策春风吹出“新”北交所（上）

## 一、政策春风吹出"新"北交所（00:28）

>（原文此处有配图，导出未附）

- **历史背景**：北交所在宣布成立前一周已有预测，早期参与者获得第一波红利
- **现状问题**：上市公司质量普遍不高，导致前期关注度下降

### 1. 北交所股票表现（01:46）

>（原文此处有配图，导出未附）

- **涨停机制**：北交所采用30%涨跌幅限制，与A股不同
- **近期表现**：232只股票全部上涨，30多只股票涨停，进入"非常牛"状态
- **投资争议**：市场对北交所投资价值存在分歧，投机与投资属性争议较大

### 2. 北交所换手率（02:06）

- **换手数据**：整体换手率超过35%，部分个股超过40%
- **市场特征**：达到"死亡换手"标准，显示极端博弈和投机状态
- **质疑声音**：普遍认为上市公司质量差，存在较多"骗子公司"

### 3. 封闭基金回本（03:56）

- **基金表现**：8只北交所封闭基金经历大幅下跌后即将回本
- **投资启示**：两年期表现跑赢市场理财产品和A股投资
- **核心观点**：**长期持有可能获得超预期回报，体现投资真谛**

### 4. 北交所成交情况（05:25）

#### 1）投机成分（05:31）

- **资金流向**：大量资金转向北交所，需分析背后深层原因
- **门槛限制**：50万开户门槛下仍吸引资金流入
- **市场对比**：原被认为比A股更差的北交所现成为市场焦点

#### 2）A股上市情况（05:46）

>（原文此处有配图，导出未附）

- **政策限制**：A股为保护特定行业限制上市，导致大量公司无法IPO
- **排队问题**：审核拖延导致上市排队时间长
- **行业影响**：消费类等非重点行业上市受阻

#### 3）A股上市公司情况（06:28）

- **资金困境**：限制上市为避免市场资金被"吸干"
- **政策逻辑**：虽存在争议，但为提振股市采取的特殊措施
- **法治考量**：依法不能直接劝退，采取拖延策略

#### 4）A股套牢族情况（07:15）

- **亏损数据**：今年股民平均亏损达25%
- **基金表现**：头部基金易方达蓝筹亏损15%已是行业最佳
- **市场情绪**：投资者普遍陷入悲观情绪

#### 5）A股的资金套牢情况（08:36）

- **财富蓄水池**：房市和股市是中国人主要财富载体
- **政策目标**：提振股市成为提升民众幸福感的重要途径
- **时间节点**：6月牛市预期虽未实现，但政策方向明确

#### 6）A股幸福感源泉（09:11）

- **社会影响**：股市低迷导致消费降级和安全感缺失
- **政策优先级**：激活房市和股市成为当务之急
- **历史经验**：多次强调该政策方向的重要性

#### 7）A股的新公司上市情况（09:22）

- **替代渠道**：A股受限公司转向北交所上市
- **质量变化**：北交所开始吸引原A股优质公司
- **政策转变**：12月启动北交所试点，接受A股无法上市企业

#### 8）A股与北交所的关系（10:10）

>（原文此处有配图，导出未附）

- **战略统筹**：北交所崛起是国家统一金融战略部署
- **筛选机制**：6月起各地证监局通过券商推荐企业
- **企业类型**：重点吸纳专精特新"小巨人"企业
- **机构参与**：中金、中信等头部券商积极推荐企业

# 工业软件分类

工业软件是支撑工业领域研发设计、生产制造、经营管理、运维服务等全流程数字化的核心工具，其分类需结合工业场景的实际需求与技术逻辑。目前行业内普遍按照**"工业生命周期"和"功能属性"**两大维度交叉划分，核心可分为以下六大类，每类包含具体细分领域及典型应用场景：

## 一、研发设计类软件（PLM核心组成，决定"产品如何设计"）

研发设计类软件是工业产品创新的源头，覆盖从概念设计到详细工程设计的全流程，直接决定产品的性能、成本与可制造性。其核心价值是通过数字化手段缩短研发周期、降低试验成本、提升设计精度。

| 细分领域 | 核心功能 | 典型场景/工具举例 |
| --- | --- | --- |
| 计算机辅助设计（CAD） | 二维绘图、三维建模（参数化/自由曲面）、装配设计、工程图纸生成 | 机械零件建模（SolidWorks、AutoCAD）、汽车车身设计（CATIA） |
| 计算机辅助工程（CAE） | 仿真分析（结构强度、流体力学、热力学、电磁兼容等）、性能优化、虚拟试验 | 汽车碰撞仿真（LS-DYNA）、飞机气动分析（ANSYS Fluent） |
| 计算机辅助制造（CAM） | 将CAD模型转化为数控（NC）加工代码、规划刀具路径、模拟加工过程 | 模具铣削加工（UG NX CAM）、3D打印路径规划（Materialise Magics） |
| 产品数据管理（PDM） | 管理产品全生命周期的设计数据（图纸、模型、BOM表）、版本控制、权限协同 | 企业级图纸归档与协同（Siemens Teamcenter） |
| 概念设计与仿真 | 早期方案选型、拓扑优化、多学科协同仿真（MDO） | 航天器结构拓扑优化（Altair OptiStruct） |

## 二、生产制造类软件（MES为核心，解决"产品如何生产"）

生产制造类软件聚焦车间层的"执行环节"，连接上层计划（ERP）与下层设备（PLC），实现生产过程的实时监控、调度优化、质量追溯与资源管理，是"智能制造"的核心载体。

| 细分领域 | 核心功能 | 典型场景/工具举例 |
| --- | --- | --- |
| 制造执行系统（MES） | 生产排程、工单管理、设备状态监控、质量检验（IQC/IPQC）、物料追溯、OEE计算 | 汽车焊装车间生产调度（SAP MES）、电子厂SMT工序追溯 |
| 过程控制系统（PCS） | 实时采集生产过程数据（温度、压力、流量）、闭环控制、异常报警 | 化工反应釜温度控制（Emerson DeltaV）、钢铁轧机张力控制 |
| 可编程逻辑控制器（PLC） | 接收传感器信号、执行逻辑运算、驱动执行器（电机、阀门），实现设备自动化 | 流水线传送带控制（Siemens S7-1200）、机床动作控制 |
| 数字孪生/虚拟工厂 | 构建车间物理设备的数字镜像，模拟生产流程、预测设备故障 | 宝马沈阳工厂虚拟调试（Siemens Process Simulate） |

## 三、经营管理类软件（ERP为核心，统筹"企业资源如何配置"）

经营管理类软件聚焦企业层的"资源协同"，覆盖财务、采购、销售、库存、人力等核心环节，通过数据整合实现业务流程标准化与决策科学化，是企业数字化运营的"中枢神经"。

| 细分领域 | 核心功能 | 典型场景/工具举例 |
| --- | --- | --- |
| 企业资源计划（ERP） | 整合财务、供应链、生产计划、人力资源数据，生成经营报表（如资产负债表） | 家电企业产销协同（SAP S/4HANA、用友U9 Cloud） |
| 供应链管理（SCM） | 供应商寻源、采购订单管理、物流跟踪、库存优化、需求预测 | 快消品企业原材料补货（Kinaxis RapidResponse） |
| 客户关系管理（CRM） | 客户信息管理、销售线索跟踪、订单管理、售后服务记录，支撑客户精准运营 | 汽车经销商客户跟进（Salesforce CRM） |
| 财务管理软件 | 总账核算、应收/应付账款、成本核算、税务申报、资金管理 | 集团企业多币种财务核算（Oracle Fusion Financials） |

## 四、运维服务类软件（服务化转型核心，解决"产品如何运维"）

运维服务类软件聚焦产品交付后的"全生命周期服务"，通过物联网（IoT）采集设备运行数据，实现预测性维护、远程监控与增值服务，是工业企业从"卖产品"向"卖服务"转型的关键工具。

| 细分领域 | 核心功能 | 典型场景/工具举例 |
| --- | --- | --- |
| 产品服务系统（PSS） | 整合设备IoT数据、维护记录、备件库存，提供预测性维护与远程运维服务 | 西门子燃气轮机远程健康监控（Siemens Digital Services） |
| 资产管理系统（EAM） | 管理企业固定资产（如机床、生产线）的台账、维护计划、维修成本 | 矿山企业设备维护（IBM Maximo） |
| 远程监控与诊断系统 | 实时采集设备运行参数（如转速、温度），异常时自动报警并推送诊断报告 | 三一重工挖掘机远程运维（三一智能云平台） |

## 五、嵌入式工业软件（设备"大脑"，控制"硬件如何运行"）

嵌入式工业软件是嵌入在工业设备（如机床、传感器、工业机器人）中的"底层控制软件"，直接与硬件交互，实现设备的核心功能逻辑，是工业设备智能化的"灵魂"。这类软件通常与硬件深度绑定，不单独销售。

| 细分领域 | 核心功能 | 典型场景/工具举例 |
| --- | --- | --- |
| 设备控制固件 | 实现设备基础动作逻辑（如电机启停、传感器数据采集），运行在嵌入式芯片上 | 工业机器人关节电机控制固件（ABB RobotWare） |
| 实时操作系统（RTOS） | 为嵌入式软件提供实时调度、内存管理、硬件驱动支持，确保控制响应时效性 | 数控系统实时任务调度（VxWorks、RTX） |
| 工业传感器软件 | 处理传感器采集的原始数据（如滤波、校准），输出标准化信号（如4-20mA） | 温度传感器数据校准软件（Bosch Sensor Software） |

## 六、工业互联网平台（跨层级协同载体，打通"数据孤岛"）

工业互联网平台是连接"设备、软件、企业"的核心枢纽，通过云原生技术实现工业数据的汇聚、存储、分析与应用开发，支撑跨企业、跨领域的资源协同（如共享制造、产业链协同），是工业软件的"新一代载体"。

| 细分领域 | 核心功能 | 典型场景/工具举例 |
| --- | --- | --- |
| 边缘计算平台 | 在设备侧（边缘端）实现数据预处理、实时分析与本地控制，降低云端传输压力 | 风电场站边缘数据处理（华为FusionEdge） |
| 工业PaaS平台 | 提供工业级开发工具（如低代码平台、AI算法库），支持第三方应用快速开发 | 海尔卡奥斯平台（COSMOPlat）、阿里云supET工业互联网平台 |
| 工业数据中台 | 整合多源工业数据（MES、IoT、ERP），提供数据清洗、建模、查询服务 | 某汽车集团生产数据中台（自研+开源组件） |

## 补充：工业软件的"国产化替代"重点领域

由于工业软件长期被欧美企业主导（如CAD领域的达索、CAE领域的ANSYS、ERP领域的SAP），目前国内替代重点集中在**研发设计类（CAD/CAE）、生产制造类（MES）、经营管理类（中高端ERP）**，涌现出中望软件（CAD）、安世亚太（CAE）、宝信软件（MES）、用友/金蝶（ERP）等企业。

# 90%散户股市亏损的真正原因

年轻人总是想要通过在交易市场里面快速致富

这种想法是十分危险的

年轻人应该好好的把自己的事业规划一下，

事业和工作才是你最好的最快的致富方式

你现在小打小闹不说，不经吧自己的时间浪费在交易当中了。

你年轻的时候本来应该把你的时间花在你的事业，花在你的学习，花在你的工作中。

但是你却把你最宝贵的青春浪费在和庄家都在斗争中。

有些事业比较成功的人，通过自己事业，有了很多闲钱，衣食无忧。

多出来钱不知道做什么。拿钱来股市闯荡一番。

他们总觉得自己的在事业都能成功，在股市也是一样。但是在这个市场上，他们都如同一个婴儿

在这个市场上和几十年的老庄家抢饭吃。

**先把资金和心思放在事业和工作上**

- 年轻人一定是要以自己的收入为目标。工资能达到当前所处地区的房价才达到及格，人生很长，我们不要急于求成，慢慢来。
- 给自己目标，每年获得一小步提升，复利效应在人的身上会更加显著。

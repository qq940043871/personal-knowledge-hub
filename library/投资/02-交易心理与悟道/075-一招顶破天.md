# 一招顶破天

1、人的一生很短暂，不需要懂太多，也不需要学太多。

人不是做的越多越好，而是做的越好越好。

人要的是简单，简单的一个卖点，唯一的一个卖点，可以卖一辈子，而且是合法的卖。这个点就可以卖一辈子

2、人最怕的是到处换项目，换项目就没有复利效应，没有积累，也不好做矩阵。

只做一件唯一的事情，不再贪图其他任何多余的东西

3、人的贫穷，大概都是贪婪，总是喜新厌旧总是喜欢创新，总是以为其他项目更好。总是想换。自己拥有的已经很多了。练自己这块资源耕种好，就能产生很大的效益了。不要那么贪婪，不要那么喜欢创新。不要那么喜欢创新我们不哗众取宠，是我们自己的性格，自己的道到内求，而不是外求。

6、人的一生，不要那么贪婪，做小的事情，做唯一的事极情，做一辈子，求少。

—少的抓住了，多的就抓住了。如果求多，多的弄不到手，结果少的也没有致

8、任何人都可以把技艺练到炉火纯青，大家能不能有耐心，只做唯一的一件事。

9、所有伟大的企业，真正的成功，就是做好了一件事，彻底把这件事做到了极致。而我们要做到极致的，就是不要哗众取宠，不要以为其招他地方更好。别以为其他地方好，《到处都是坑》我就做好这件事。也是我的唯一性。

这就是我们的唯一性，除此之外，全部放弃。

11、抓住了唯一性系统，就要一辈子不动摇，无论任何情况，皆不动摇，不要有动摇的心思。

唯一唯一，再唯一。动摇了，就不唯一了。

精诚所至金石为开。坚定的执行一辈子唯一性系统。这是信仰，信仰才是真正的成功

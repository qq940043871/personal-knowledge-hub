# 交易盈利之道

- 轻仓、顺势、积累、加仓、止损、持仓、明德。

-  永远不要相信猜测。

-  猜测的主观偏见太多，猜测是虚幻的将来，猜测是恐惧的集中地，猜测实际上也代表着不准确，所以不要相信任何分析。

-  非上即下的价格运动，规定了你应该学会非多即空的交易行为。

-  记住、你不是来开辟道路的，误打误撞而达到目的地、而是你看到已经存在的道路、然后沿着道路走、才能到达目的地。下单交易，就是先看到行情、并跟随行情。

-  行情能走多远？不知道。

-  持仓和时间无关，持仓也和你的耐心、个人情绪、包括期待或者疑虑等心理活动无关。

-  好好思考如何走路、不会思考、那就开始上路。边走边思考。不要着急而过早迈步、也不要前怕狼后怕虎。跟随趋势、不要被已有思维所禁锢。船大难掉头、自古是此问题。

-  交易者一定要清楚、持仓和交易无关。

-  盈亏的本质，根本就和心理活动无关、所以不要自己给自己加那么多戏。无需这么辛苦的努力、只要放弃你的想法、简单你的行为、按比例轻仓，跟随趋势而动、自然而然就是交易了。

-  持仓是无为而为。

-  多易必多难、欲速则不达，任何事情发展的过程必然有先后的诸多条件决定和影响，快则有害。所以最慢的积累就是你最快的盈利方式。而且要相信、复利的力量是巨大的。

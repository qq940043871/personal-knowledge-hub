# 幸运者偏差

你遇到的这种情况，是**绝大多数投资者都会经历的共性问题**，心态受影响并非“心理素质差”，而是人类进化形成的认知偏误、投资场景的损失厌恶机制，以及市场本身的随机性共同作用的结果。背后的核心原因可以从**认知偏差、心理机制、市场本质**三个层面拆解，每个层面都能对应到具体的行为逻辑：

1. **认知层面：三大偏误让你“放大遗憾、忽视真相”**
    - **确认偏误+事后诸葛亮效应**：当你看好的股票大涨时，会**自动强化“我当初判断对了”的正面认知**，甚至忽略当初没买的真实原因（比如当时担心风险、犹豫仓位），反而沉浸在“如果买了能赚多少”的幻想中；

同时会把“没买到”的结果归因为“自己的犹豫失误”，而不是市场的随机性。

反之，自己持有的股票横盘时，会**放大“我选错了”的负面判断**，忘记当初买入的核心逻辑（比如基本面支撑、长期趋势），甚至把正常的震荡当成“自己决策失误的证据”。

    - **可得性偏误**：大涨的股票往往伴随股价异动、行情推送、身边人讨论，**信息曝光度极高**，会持续刺激你的感官，让你反复关注；

而自己持有的股票“半死不活”，缺乏话题性和波动，信息存在感低，反而容易让你盯着“不涨”这个缺点不放。这种“高频刺激vs低频平淡”的对比，会进一步加剧心理失衡。

    - **锚定效应**：你会不自觉地把“看好却没买的股票涨幅”当成**锚点**，用来衡量自己持仓的“收益性价比”。

比如没买的股票涨了20%，就会觉得自己持仓涨2%“毫无意义”，哪怕持仓本身跑赢了大盘或行业指数，也会因为锚定了更高的涨幅，产生强烈的落差感。

2. **心理层面：损失厌恶+自我认同绑定，放大情绪波动**
    - **损失厌恶：“没赚到”比“亏了”更难受**：行为经济学的核心理论之一是“损失厌恶”，人对**损失的痛苦感受，是同等收益快乐感受的2-2.5倍**。

而“看好没买导致踏空”属于“**潜在收益的损失**”，在心理上和实际亏损的感受几乎等价——你会把“本该赚到的钱”当成“自己已经失去的钱”，这种“错失恐惧”（FOMO）带来的焦虑，远超过持仓平淡的麻木。

    - **自我认同与投资决策深度绑定**：很多投资者会把投资结果和“自我能力”挂钩：买对了=我聪明、判断准；踏空或持仓不涨=我愚笨、决策错。

当看好的股票大涨而自己没买时，本质上是**自我能力受到了“隐性否定”**；而持仓不涨则是“自我判断”被持续质疑，两种情况叠加，会引发挫败感、自责感，心态自然失控。

    - **注意力资源稀缺：负面情绪更易占据心智**：人的注意力是有限的，投资中的“遗憾”“后悔”属于强烈的负面情绪，会优先占据你的心智。

你会不自觉地反复复盘“当初为什么没买”，陷入“如果当初…就好了”的反事实思维中，这种反复纠结会让负面情绪不断放大，进而影响对当前持仓的理性判断。

3. **市场层面：随机性+幸存者偏差，制造“别人的股票都在涨”的假象**
    - **股票涨跌的随机性，必然导致“踏空常态化”**：A股市场有数千只股票，任何时候都有部分股票大涨（比如受政策、资金、消息刺激），而大部分股票处于震荡或下跌状态，这是**市场的正常分布**。

你看好的股票恰好大涨，本质是“你关注的标的刚好命中了少数上涨样本”，但因为你对自己关注的标的有情感投入，会把这种“随机事件”当成“自己错过的确定性机会”。

    - **幸存者偏差：你只看到“大涨的错过股”，没看到“大跌的错过股”**：你会牢牢记住那些“看好没买却大涨”的股票，但会**自动忽略那些“看好没买反而大跌”的情况**。

比如你上个月看好3只股票没买，1只大涨、2只大跌，但你只会盯着大涨的那只反复遗憾，而忘记另外两只帮你规避了风险，这种选择性记忆会让你产生“我总是错过好机会”的错觉。

    - **持仓的“摩擦成本”被无限放大**：自己持有的股票，你会每天关注它的波动、计算浮盈浮亏，甚至因为它不涨而产生“时间成本”焦虑（觉得“拿着它耽误了买其他牛股的机会”）；

而没买的股票，你只看到它的“结果涨幅”，却忽略了如果当初买入，可能要承受的波动、回调等风险，这种“只看收益不看风险”的对比，会让持仓显得更加“不值”。

## 结尾提议
你可以试试**复盘记录法**：把每次“看好没买的股票”和“当前持仓的股票”分别记录下买入/不买的理由、后续走势，每周汇总一次，看看“错过的大涨股”和“持仓的平淡股”各自的胜率和盈亏情况。这样能直观看到自己的判断偏差，减少情绪对决策的干扰。

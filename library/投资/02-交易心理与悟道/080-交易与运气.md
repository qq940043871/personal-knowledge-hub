# 交易与运气

**交易既然成熟，摆脱的就是对运气的依赖。**

靠运气得到的行情，和自己的交易理念还有什么关系。

成熟的交易者遵循的是不以人的意志为转移的市场规律，这个规律的背后运行逻辑完全是理性的，客观的，是脱离[神道主义](https://www.zhihu.com/search?q=%E7%A5%9E%E9%81%93%E4%B8%BB%E4%B9%89&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3296320405%7D)的。

交易就是老老实实，一笔一笔的去下单买卖，每笔单子遵守规矩，打破就止损，盈利到位置就出局，你的理念只要正确，越努力就越接近成功，这是客观规律，而不是把自己交给未知，运气就是未知。

交易就是把握好当下，观照好情绪，不跟着贪欲跑，做符合规律的事情。

运气也是自己经营出来的。只有正确的理念才能不断创造更好的运气。

交易就是做自己的主宰，市场永远在那里，市场不会偏爱谁，市场就是天地不仁，以万物为刍狗。

反过来，成熟的交易者就是圣人不仁，以万物为刍狗。

成熟的交易者看待每一个[标地](https://www.zhihu.com/search?q=%E6%A0%87%E5%9C%B0&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3296320405%7D)都是极度冷静不带私人感情，符合我的买点就干，干了不对就严格止损，趋势行情启动就坚定持有，盈利到什么阶段就主动止盈，同样的买点有的进入止损，有的没有进去却一直涨，内心一点也不遗憾，就当没有发生过一样。

我只要保证我自己的正确性，市场的随机性我不能控制，但是我可以确定的是我一定会遇到大的行情，因为我不是一天两天的交易，我是经常在交易，市场也不是只有一次行情，市场会经常有行情。理念只要正确，只要你看见的有趋势的行情总会有你上车的时候。

交易就是明明白白，做自己能力范围的事情，不要怕错过，该认的要认，该做的要做，认知到了，学会接受不属于自己的东西，你才能老实的在市场里面做到不动心，隔壁涨到天上也不影响你，不是你的你不要急，你把自己做好，你做正确的事情，做正确的交易，就是在积累自己的运气。

运气还是你自己一点一点创造出来的，运气是你的心里生出来的，不是你去依赖运气，你去依赖运气就是把自己搞的被动了。你是运气的主人，关系不能错乱，这本身还是认知。

你们觉得我们的伟大的MZX带领红军[四渡赤水](https://www.zhihu.com/search?q=%E5%9B%9B%E6%B8%A1%E8%B5%A4%E6%B0%B4&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3296320405%7D)，长征，建立新中国靠的是运气吗？靠的是深入人民群众实地调查，靠的是遵循大势，遵循客观实际发展的规律，明明白白的预见，按照这个预见老老实实的经营。

你觉得是老天爷帮助他吗？老天爷帮助他是因为他帮助了人民，人民就是老天爷。所以运气是自己创造出来的，大家不要糊涂。

稳扎稳打，如果还在靠运气，就是不自信啊，没有那个勇气相信自己。市场不好的时候可以休息啊，可以尊重市场去学习啊，非要跟市场对干，挣一笔证明自己厉害吗，这种认知混乱的交易即使有了盈利也是致命的。

要做正确的事，正确的交易理念，要把握当下。要学会面对困境。

市场最不缺的就是机会，机会就是运气，缺的是你有没有能力识别机会，把握机会的能力，错过一两次行情就怪自己运气不好，既然这样还做什么交易，去买彩票好了，彩票是检验运气最好的方式。

认知正确，落实到位，越努力，越幸运。

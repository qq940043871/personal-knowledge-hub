## 三、使用说明

1. **链接指向六库**：MOC 里所有链接形如 `../投资/0X-*/...`，编辑器与文件系统可直接点开。
2. **原文只读**：发现某篇值得深挖，把提炼写进本目录（或对应主题文件），**不要改归档原件**。
3. **新增笔记**：今后投资类新笔记直接写在本目录，不再进备份区。
4. **更新索引**：七册 MOC 为静态产物——原生成脚本 `tools/gen_invest_moc.py` 已因四源重组弃用（源目录"语雀备份/"已不存在，不可再跑），新增笔记请手工同步对应册 MOC 的分组与计数，并核对链接无死链。

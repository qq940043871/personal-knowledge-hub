# 投资知识库排版规范（2026-11 重排版统一标准）

> 本规范适用于 `library/投资/` 下 01~07 分册的全部文章。
> 目标：标题层级清晰、段落结构分明、关键结论突出、必要处补示意图。
> 铁律：**内容零丢失**——原文的观点、数据、结论、比喻、图片，一个都不能少。

## 一、排版规范

### 1.1 标题
- 每篇有且仅有一个 `# ` 一级标题，作为文章题目（用文件名去掉序号前缀后的题名，如 `046-股票账户.md` → `# 股票账户`；文件名含日期的可保留日期）。
- 正文按内容逻辑划分 `## ` 二级小节，小节多的可在二级下再加 `### `。
- 小节标题必须是**有信息量的短句**（如「二、止损为什么总是执行不了」），禁止用「第一部分」「内容」这类空标题。
- 原文已有正确层级的，保留原层级，只做整洁化（统一空行、修正层级跳跃）。

### 1.2 段落与强调
- 口语转写稿：把大段口语墙拆成 2~5 句一段；删除纯语气词（"啊""呢""就是说什么呢"）和明显重复的口头禅，但**句子主干照抄原文，不重写、不概括**；意思含糊处保留原样，不要替作者下结论。
- 每个二级小节开头，如该节有明确结论，可用一行 `> ` 引用块点题（从原文原句中挑选或极轻度压缩，禁止编造）。
- 关键词、核心结论用 `**加粗**`；连续的要点（3 条及以上）改写成 `- ` 列表。
- 原文的表格、代码块、图片引用**原样保留**，只允许调整前后空行。

### 1.3 禁止事项
- 禁止删减任何观点、案例、数字、股票名、日期。
- 禁止添加原文没有的新观点、新数据（导读句只能从原文提炼）。
- 禁止改动 `images/...` 图片引用的路径和顺序。
- 篇幅很短（<15 行）的日记型/记录型文章：只补 H1 标题和必要的段落空行，**不要**强行加小节、加图。

### 1.4 文末元信息
文章末尾统一追加一行：

```
---
> 🏷️ 本文属《投资知识库 · <分册名>》，重排于 2026-11。
```

其中 `<分册名>` 为该文件所在目录名（如 `02-交易心理与悟道`）。空行隔开，不与正文混排。

## 二、补图规范（内联 SVG）

### 2.1 什么时候补图
- 文章讲**流程/步骤/体系/战法**（如选股流程、复盘步骤、止损纪律）→ 补 1 张流程图。
- 文章讲**分类/对比/要素拆解**（如四要素、多空对比、散户 vs 机构）→ 补 1 张结构图。
- 文章讲**层级/金字塔/资金链条**（如收割链、仓位管理）→ 补 1 张层级图。
- 纯日记、纯情绪记录、已有实盘截图的文章 → **不补**。
- 一篇文章最多 2 张 SVG，宁缺毋滥；全篇加起来预计 1/3 左右的文章配图。

### 2.2 SVG 模板（严格遵守）
- 插入位置：相关小节末尾或全文导语之后；SVG 前后各空一行。
- 尺寸：`viewBox="0 0 720 H"`，H 按内容 180~420；高度按节点行数计算，节点间留足间距。
- 字体统一：`font-family="'Microsoft YaHei','PingFang SC',sans-serif"`。
- 配色（与库 README 一致）：
  - 普通节点：`fill="#eff6ff" stroke="#2563eb" stroke-width="1.5"`，文字 `#1e293b`
  - 强调节点（核心结论/危险动作）：`fill="#fef2f2" stroke="#dc2626"` 或 `fill="#fffbeb" stroke="#d97706"`
  - 结果/正向节点：`fill="#f0fdf4" stroke="#16a34a"`
  - 次要说明文字：`fill="#475569"`
  - 箭头连线：`stroke="#94a3b8" stroke-width="1.5"`，`marker-end` 用灰色三角
- 文字 13~15px，标题类 16px bold；每个节点文字居中（`text-anchor="middle"`）。
- 必须写 `xmlns="http://www.w3.org/2000/svg"`；SVG 内文字必须转义 `<` `>` `&`。
- SVG 上方加一行斜体图题：`*图：xxx（示意）*`。

## 三、工作流程

1. 逐个处理分配到的文件：Read 全文 → 按本规范重构 → Write 覆写原路径。
2. 拿不准是否该删/改的句子，一律保留原文。
3. 完成后输出逐文件一行报告：`文件名 | H1标题 | 二级小节数 | 补图:0/1/2 | 备注`。
